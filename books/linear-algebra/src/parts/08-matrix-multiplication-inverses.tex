\chapter{Matrix Multiplication and Inverses}

In the last chapter, Gaussian elimination gave us a systematic way to solve
$\mat{A}\vec{x} = \vec{b}$. We treated the matrix $\mat{A}$ as a table of equation coefficients,
using row operations to simplify the system until we could read off the unknown vector
$\vec{x}$. Chapter~5 gave a second picture of the same matrix: a \emph{machine}.
Feed in a vector $\vec{x}$, and the matrix moves it somewhere new, giving out
$\mat{A}\vec{x}$.

This chapter answers two questions about these machines.

First: what happens if you run a vector through \emph{two} machines in a row? Push
$\vec{x}$ through $\mat{B}$, then push the result through $\mat{A}$. You get
$\mat{A}(\mat{B}\vec{x})$. Chapter~5 showed that a single matrix, called
$\mat{A}\mat{B}$, performs both steps in one go. Finding that
matrix \emph{is} matrix multiplication. Every part of the multiplication rule,
including the parts that look arbitrary the first time you see them, follows from
the requirement $(\mat{A}\mat{B})\vec{x} = \mat{A}(\mat{B}\vec{x})$.

Second: can we ever \emph{undo} a machine? If $\mat{A}$ sent $\vec{x}$ to $\vec{b}$,
is there a machine that takes $\vec{b}$ back to $\vec{x}$? That machine, when it exists,
is the \emph{inverse} of $\mat{A}$, written $\mat{A}\inv$. We will see exactly when it
exists, what it means geometrically, and how to compute it with the same elimination
you already know.

Later chapters lean on both ideas constantly. Many of them write a complicated matrix
as a product of simpler ones, which says ``this machine is these simpler machines,
run one after another.''

\section{Where Matrix Multiplication Comes From}
\label{ch08:origin}

\subsection{Composition forces the rule}

\begin{intuitionbox}
A matrix is a machine that transforms vectors. If $\mat{B}$ is one machine and
$\mat{A}$ is another, then doing $\mat{B}$ \emph{first} and $\mat{A}$ \emph{second}
is itself some transformation. \textbf{Matrix multiplication is the name of that
combined transformation.} The product $\mat{A}\mat{B}$ is defined to be the single
matrix that produces $\mat{A}(\mat{B}\vec{x})$ for every $\vec{x}$.
\end{intuitionbox}

The order looks backwards: $\mat{B}$ acts first but is written on the
right, next to the $\vec{x}$ it touches first. This comes from how we write
function composition (doing one function after another): $f(g(x))$ applies $g$ first,
and $g$ sits on the inside, closest to $x$. Matrices follow the same rule.

Here is a concrete case in two dimensions. Take

\[
\mat{B} = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}
\qquad\text{(stretch horizontally by }2\text{)},
\]
\[
\mat{A} = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}
\qquad\text{(rotate by }90^\circ\text{ counterclockwise)}.
\]

Take a test vector $\vec{x} = \colvec{1 \\ 1}$. Run it through $\mat{B}$ first:

\[
\mat{B}\vec{x} = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}\colvec{1 \\ 1}
= \colvec{2 \\ 1}.
\]

Now run \emph{that} through $\mat{A}$:

\[
\mat{A}(\mat{B}\vec{x}) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\colvec{2 \\ 1}
= \colvec{-1 \\ 2}.
\]

So the two-step trip sends $\colvec{1 \\ 1}$ to $\colvec{-1 \\ 2}$. Can we find a
\emph{single} matrix $\mat{C}$ that does this directly? Yes, and Chapter~5 gives the
method. A matrix is completely determined by what it does to the
basis vectors $\vec{e}_1 = \colvec{1 \\ 0}$ and $\vec{e}_2 = \colvec{0 \\ 1}$, because
the columns of any matrix \emph{are} the images (outputs) of the basis vectors. So push
$\vec{e}_1$ and $\vec{e}_2$ through both machines and collect the answers as
columns.

\[
\mat{B}\vec{e}_1 = \colvec{2 \\ 0},\qquad
\mat{A}(\mat{B}\vec{e}_1) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\colvec{2\\0}
= \colvec{0 \\ 2}.
\]
\[
\mat{B}\vec{e}_2 = \colvec{0 \\ 1},\qquad
\mat{A}(\mat{B}\vec{e}_2) = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\colvec{0\\1}
= \colvec{-1 \\ 0}.
\]

Stack those two images as columns:

\[
\mat{C} = \mat{A}\mat{B} = \begin{bmatrix} 0 & -1 \\ 2 & 0 \end{bmatrix}.
\]

Check it on the test vector:
\[
\mat{C}\colvec{1\\1} = \colvec{0\cdot1 + (-1)\cdot1 \\ 2\cdot1 + 0\cdot1} = \colvec{-1 \\ 2},
\]
the same as the two-step answer. Figure~\ref{ch08:pipeline} shows the trip: the single
machine $\mat{C}$ does ``stretch, then rotate'' in one step.

\begin{focusbox}
To build $\mat{A}\mat{B}$, send each column of $\mat{B}$ through $\mat{A}$. The
$j$-th column of $\mat{A}\mat{B}$ is $\mat{A}$ times the $j$-th column of $\mat{B}$.
In symbols, if $\mat{B} = [\,\vec{b}_1 \ \vec{b}_2 \ \cdots \ \vec{b}_n\,]$, then
\[
\mat{A}\mat{B} = [\,\mat{A}\vec{b}_1 \ \ \mat{A}\vec{b}_2 \ \ \cdots \ \ \mat{A}\vec{b}_n\,].
\]
This is the most useful way to think about a matrix product.
\end{focusbox}

\subsection{Why the shapes have to match}

For $\mat{A}\mat{B}$ to make sense, the output of $\mat{B}$ must be a legal input for
$\mat{A}$. If $\mat{B}$ produces vectors in $\R^m$ (it has $m$ rows), then $\mat{A}$
must accept vectors in $\R^m$ (it has $m$ columns). That gives the shape rule
(a $p\times m$ matrix has $p$ rows and $m$ columns):

\[
\underbrace{\mat{A}}_{p \times m}\ \underbrace{\mat{B}}_{m \times n}
\;=\; \underbrace{\mat{A}\mat{B}}_{p \times n}.
\]

The inner dimensions ($m$ and $m$) must agree and they cancel; the outer dimensions
($p$ and $n$) survive as the shape of the product (Figure~\ref{ch08:shaperule}).
You do not need to memorize this if you remember the machines: $\mat{B}$ maps
$\R^n \to \R^m$, $\mat{A}$ maps $\R^m \to \R^p$, so doing both maps $\R^n \to \R^p$.

\begin{trapbox}
``$\mat{A}\mat{B}$ exists'' does \emph{not} mean ``$\mat{B}\mat{A}$ exists.'' If
$\mat{A}$ is $2\times 3$ and $\mat{B}$ is $3\times 4$, then $\mat{A}\mat{B}$ is
$2\times 4$, but $\mat{B}\mat{A}$ asks a $3\times4$ to feed a $2\times3$,
and $4 \ne 2$, so it is undefined. Order matters before we even get to the values.
\end{trapbox}

\begin{recoverybox}
\textbf{Pause and think:} Suppose $\mat{A}$ is $3\times 4$ and $\mat{B}$ is $4\times 3$.
Does $\mat{A}\mat{B}$ exist? Does $\mat{B}\mat{A}$ exist? What are their shapes?
Take a moment to predict both before checking.

\emph{Answer:} Both exist. The inner dimensions match in both orders ($4=4$ for
$\mat{A}\mat{B}$, and $3=3$ for $\mat{B}\mat{A}$). But their shapes are
different: $\mat{A}\mat{B}$ is $3\times 3$, while $\mat{B}\mat{A}$ is $4\times 4$,
so they cannot be equal.
\end{recoverybox}

\section{Four Views of the Same Product}
\label{ch08:fourviews}

There is one product $\mat{A}\mat{B}$, but four ways to see it. Different later
chapters use different views, so we walk through all four with the same small example.
Throughout this section let

\[
\mat{A} = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix},
\qquad
\mat{B} = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}.
\]

We will compute $\mat{A}\mat{B}$ four times and get the same answer each time:

\[
\mat{A}\mat{B} = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}.
\]

\subsection{View 1: the dot-product (entry) view}

This is the entry-by-entry formula most people use by hand. The entry in row $i$,
column $j$ of $\mat{A}\mat{B}$ is the dot product of row $i$ of $\mat{A}$ with column
$j$ of $\mat{B}$:

\[
(\mat{A}\mat{B})_{ij} = \sum_{k=1}^{m} \mat{A}_{ik}\,\mat{B}_{kj}
= (\text{row } i \text{ of } \mat{A}) \cdot (\text{column } j \text{ of } \mat{B}).
\]

Here $\mat{A}_{ik}$ is the entry of $\mat{A}$ in row $i$ and column $k$, and the sum
runs over $k = 1, \dots, m$, where $m$ is the shared inner dimension (the number of
columns of $\mat{A}$, which equals the number of rows of $\mat{B}$).
Figure~\ref{ch08:entryview} shows one entry being built. Here are all four entries
of our example, writing each row of $\mat{A}$ as a column vector so we can take its
dot product:

\begin{align*}
(\mat{A}\mat{B})_{11} &= \colvec{1 \\ 2}\cdot\colvec{5 \\ 7} = 1\cdot5 + 2\cdot7 = 5+14 = 19,\\
(\mat{A}\mat{B})_{12} &= \colvec{1 \\ 2}\cdot\colvec{6 \\ 8} = 1\cdot6 + 2\cdot8 = 6+16 = 22,\\
(\mat{A}\mat{B})_{21} &= \colvec{3 \\ 4}\cdot\colvec{5 \\ 7} = 3\cdot5 + 4\cdot7 = 15+28 = 43,\\
(\mat{A}\mat{B})_{22} &= \colvec{3 \\ 4}\cdot\colvec{6 \\ 8} = 3\cdot6 + 4\cdot8 = 18+32 = 50.
\end{align*}

\begin{intuitionbox}
``Row $i$ dotted with column $j$.'' To find a single entry you reach across the row of
the left matrix and down the column of the right matrix, multiply pairwise, and add.
It is the most mechanical view, good for hand computation but bad for
\emph{understanding}, because it hides the geometry. The next three views show the meaning.
\end{intuitionbox}

\begin{marginnotebox}
\textbf{The cost.} This view also lets us count the work. Multiplying a $p\times m$ by an
$m\times n$ matrix fills $p\,n$ entries, and each entry is a dot product of length $m$:
about $m$ multiplications and $m$ additions. So a full product costs about
$p\,m\,n$ multiply--adds (one multiplication followed by one addition), and for two
$n\times n$ matrices that is roughly $n^3$ operations, or $O(n^3)$ in the big-O notation
of Chapter~4. Keep that $n^3$ in mind: it is why the order in which you multiply a
long chain matters, and why breaking a matrix into simpler pieces (as in View~4 below)
can save work.
\end{marginnotebox}

\subsection{View 2: the column view (combinations of $\mat{A}$'s columns)}

This is the view from Section~\ref{ch08:origin}: each column of $\mat{A}\mat{B}$ is
$\mat{A}$ acting on the corresponding column of $\mat{B}$. And $\mat{A}$
times a vector is a \emph{linear combination of the columns of $\mat{A}$},
with weights given by the entries of that vector (Chapter~3).

Write $\mat{A} = [\,\vec{a}_1 \ \vec{a}_2\,]$ with $\vec{a}_1 = \colvec{1\\3}$,
$\vec{a}_2 = \colvec{2\\4}$. Column $1$ of $\mat{B}$ is $\colvec{5\\7}$, so:

\[
\text{col 1 of } \mat{A}\mat{B} \;=\; 5\,\vec{a}_1 + 7\,\vec{a}_2
= 5\colvec{1\\3} + 7\colvec{2\\4}
= \colvec{5\\15} + \colvec{14\\28} = \colvec{19\\43}.
\]

And column $2$ of $\mat{B}$ is $\colvec{6\\8}$, so:

\[
\text{col 2 of } \mat{A}\mat{B} \;=\; 6\,\vec{a}_1 + 8\,\vec{a}_2
= 6\colvec{1\\3} + 8\colvec{2\\4}
= \colvec{6\\18} + \colvec{16\\32} = \colvec{22\\50}.
\]

Same matrix $\begin{bmatrix}19 & 22\\ 43 & 50\end{bmatrix}$, built column by column.

\begin{focusbox}
\textbf{Every column of $\mat{A}\mat{B}$ lives in the column space of $\mat{A}$.}
The \emph{column space} $\col(\mat{A})$ is the set of all vectors you can reach
by taking linear combinations of $\mat{A}$'s columns (Chapter~3). The \emph{rank} of
$\mat{A}$ (Chapter~7: its number of pivots) equals the number of independent directions
among its columns, that is, how many different directions the matrix can output.

Because each column of $\mat{A}\mat{B}$ is built only from $\mat{A}$'s columns, the
product cannot reach any direction that $\mat{A}$ could not already reach on its own.
In symbols, $\col(\mat{A}\mat{B}) \subseteq \col(\mat{A})$, where $\subseteq$ means
``is contained in''. So the number of independent output directions cannot increase:
$\rank(\mat{A}\mat{B}) \le \rank(\mat{A})$. Multiplying on the right never creates new
directions.
\end{focusbox}

\subsection{View 3: the row view (combinations of $\mat{B}$'s rows)}

In the same way, each \emph{row} of $\mat{A}\mat{B}$ is a combination of the
\emph{rows} of $\mat{B}$, with weights from the corresponding row of $\mat{A}$.

Row $1$ of $\mat{A}$ is $[\,1 \ \ 2\,]$. Rows of $\mat{B}$ are
$\vec{r}_1 = [\,5 \ \ 6\,]$ and $\vec{r}_2 = [\,7 \ \ 8\,]$:

\[
\text{row 1 of } \mat{A}\mat{B} = 1\cdot[\,5 \ 6\,] + 2\cdot[\,7\ 8\,]
= [\,5\ 6\,] + [\,14\ 16\,] = [\,19\ \ 22\,].
\]

Row $2$ of $\mat{A}$ is $[\,3\ \ 4\,]$:

\[
\text{row 2 of } \mat{A}\mat{B} = 3\cdot[\,5\ 6\,] + 4\cdot[\,7\ 8\,]
= [\,15\ 18\,] + [\,28\ 32\,] = [\,43\ \ 50\,].
\]

\begin{focusbox}
Mirror image of View 2: \textbf{every row of $\mat{A}\mat{B}$ lives in the row space
of $\mat{B}$.} The \emph{row space} $\row(\mat{B})$ is the span of $\mat{B}$'s rows.
Multiplying on the \emph{left} by $\mat{A}$ only mixes together the existing rows of
$\mat{B}$, so it cannot create new row directions either:
$\rank(\mat{A}\mat{B}) \le \rank(\mat{B})$.

Combining both views gives a limit on every product:
\[
\rank(\mat{A}\mat{B}) \le \min\bigl(\rank(\mat{A}),\,\rank(\mat{B})\bigr).
\]
A product can never have more independent output directions than either of its factors.
\end{focusbox}

\subsection{View 4: the outer-product (sum-of-rank-one) view}

This view looks the strangest, and later chapters use it the most. Instead of building
the answer entry by entry, build it as a \emph{sum of whole matrices}. Multiply column
$k$ of $\mat{A}$ by row $k$ of $\mat{B}$ (a column times a row is a full matrix, called an
\emph{outer product}) and add up over $k$:

\[
\mat{A}\mat{B} = \sum_{k} (\text{col } k \text{ of } \mat{A})(\text{row } k \text{ of } \mat{B}).
\]

A column times a row, like $\colvec{1\\3}[\,5 \ 6\,]$, fills out a whole matrix:

\[
\colvec{1\\3}\,[\,5\ \ 6\,] = \begin{bmatrix} 1\cdot5 & 1\cdot6 \\ 3\cdot5 & 3\cdot6 \end{bmatrix}
= \begin{bmatrix} 5 & 6 \\ 15 & 18 \end{bmatrix}.
\]

Each entry is (an entry of the column) times (an entry of the row).
This matrix has \emph{rank one}: every row is a multiple of
$[\,5\ 6\,]$, and every column is a multiple of $\colvec{1\\3}$, so it has only one
independent direction. Geometrically, a nonzero rank-one matrix is the simplest linear
machine there is: it squashes the entire plane onto a single line. Now form the second
one from column $2$ of $\mat{A}$ and row $2$ of $\mat{B}$:

\[
\colvec{2\\4}\,[\,7\ \ 8\,] = \begin{bmatrix} 14 & 16 \\ 28 & 32 \end{bmatrix}.
\]

Add the two rank-one pieces:

\[
\mat{A}\mat{B} = \begin{bmatrix} 5 & 6 \\ 15 & 18 \end{bmatrix}
+ \begin{bmatrix} 14 & 16 \\ 28 & 32 \end{bmatrix}
= \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}.
\]

Same answer, fourth time. The product is a \emph{sum of rank-one matrices}, one for
each value of $k$ (Figure~\ref{ch08:outerprod}).

\begin{applicationbox}
\textbf{Low-rank approximation and recommender systems.} The outer-product view leads
to one of the most used ideas in data science: a big matrix can often be
\emph{well approximated} (closely matched) by a short sum of rank-one layers. The singular value
decomposition (SVD, Chapter~29) writes any matrix as
$\mat{A} = \sum_k \sigma_k\, \vec{u}_k \vec{v}_k\T$. Here $\vec{u}_k$ is a column,
$\vec{v}_k\T$ is a row (the superscript $\T$, read ``transpose'' as in Chapter~2, turns a
column into a row), and the \emph{singular values} $\sigma_k$ are nonnegative numbers that say how much
each layer contributes. Keeping only the few terms with the largest $\sigma_k$ gives the
closest possible matrix of that low rank. A recommender system (a program that suggests
films or songs) can model the giant users-by-films table of ratings as a short sum of
such layers: a few hidden ``taste'' columns $\vec{u}_k$ times a few ``genre'' rows
$\vec{v}_k\T$. Image compression and parts of search engines and language models use
the same idea.
\end{applicationbox}

\begin{walkbox}
On a walk, think about why all four views must agree. They split up the same calculation:
the entries $(\mat{A}\mat{B})_{ij} = \sum_k \mat{A}_{ik}\mat{B}_{kj}$ share the same
sum over $k$. If you fix $j$ and collect all $i$, you get columns (View 2). If you fix
$i$ and collect all $j$, you get rows (View 3). And if you pull out one $k$ at a time across all $i,j$ at
once, you get the rank-one layers (View 4). Four views, one shared sum, grouped
differently.
\end{walkbox}

\section{The Algebra of Multiplication}
\label{ch08:algebra}

Now that we know what the product \emph{is}, what rules does it obey? Most of the
familiar rules of arithmetic hold; one does not.

\subsection{It is associative (and the reason is composition)}

\begin{theorem}[Associativity]
\label{ch08:assoc}
For any matrices of compatible shapes (shapes for which the products are defined),
\[
(\mat{A}\mat{B})\mat{C} = \mat{A}(\mat{B}\mat{C}).
\]
\end{theorem}

You can prove this by expanding both sides into double sums of entries, but that
hides why it is true. The reason is composition. Each matrix represents a function.
$\mat{A}\mat{B}\mat{C}$ means ``apply $\mat{C}$, then $\mat{B}$, then $\mat{A}$,'' and that
sequence does not depend on how you group it. Grouping the first two or the last two
does not change which transformation acts when. Associativity of matrix multiplication is
associativity of function composition.

\begin{formalbox}
\textbf{Why composition is associative.} Write $f\circ g$ for the composition ``apply $g$,
then $f$'', so $(f\circ g)(x) = f(g(x))$. Then
\begin{align*}
((f\circ g)\circ h)(x) &= (f\circ g)(h(x)) = f(g(h(x))),\\
(f\circ(g\circ h))(x) &= f((g\circ h)(x)) = f(g(h(x))).
\end{align*}
Both equal $f(g(h(x)))$. A matrix is the function
$\vec{x}\mapsto \mat{A}\vec{x}$ (``$\vec{x}$ goes to $\mat{A}\vec{x}$''), and the matrix
product is composition, so matrix multiplication is associative too.
\end{formalbox}

\begin{aestheticbox}
Associativity is the reason a chain like $\mat{A}\mat{B}\mat{C}\mat{D}$ needs no
brackets, so writing a matrix as a product of several factors (as later chapters do)
makes sense. It is also the reason you can choose the
\emph{cheapest order} to multiply a long chain. For $n\times n$ matrices, computing
$\mat{A}(\mat{B}\vec{x})$ as two matrix-times-vector steps costs about $2n^2$
multiply--adds, while forming $\mat{A}\mat{B}$ first costs about $n^3$. Neural networks
and other large computations rely on this choice of order.
\end{aestheticbox}

\subsection{It is NOT commutative}

\begin{theorem}[Order matters]
In general $\mat{A}\mat{B} \ne \mat{B}\mat{A}$.
\end{theorem}

One example is enough to prove it, and our opening machines provide one. Rotating then
stretching is different from stretching then rotating. Let

\[
\mat{A} = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}\ (\text{rotate } 90^\circ),
\qquad
\mat{B} = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}\ (\text{stretch horizontally by } 2).
\]

We already found $\mat{A}\mat{B} = \begin{bmatrix} 0 & -1 \\ 2 & 0 \end{bmatrix}$.
Now the other order:

\[
\mat{B}\mat{A} = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}
\begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}
= \begin{bmatrix} 0 & -2 \\ 1 & 0 \end{bmatrix}.
\]

These are different matrices. Watch them act on $\vec{e}_1 = \colvec{1\\0}$. With
$\mat{A}\mat{B}$: stretch $\vec{e}_1$ to $\colvec{2\\0}$, then rotate to $\colvec{0\\2}$.
With $\mat{B}\mat{A}$: rotate $\vec{e}_1$ to $\colvec{0\\1}$, then stretch the
\emph{x}-coordinate (which is already $0$) to get $\colvec{0\\1}$. One ends at
$\colvec{0\\2}$, the other at $\colvec{0\\1}$ (Figure~\ref{ch08:noncommute}). The
stretch acts on a different direction depending on whether the rotation happened
before or after it.

\begin{trapbox}
Because $\mat{A}\mat{B} \ne \mat{B}\mat{A}$, ordinary algebra identities can fail. For
matrices,
\[
(\mat{A}+\mat{B})^2 = \mat{A}^2 + \mat{A}\mat{B} + \mat{B}\mat{A} + \mat{B}^2,
\]
\emph{not} $\mat{A}^2 + 2\mat{A}\mat{B} + \mat{B}^2$, because you may not merge
$\mat{A}\mat{B}$ with $\mat{B}\mat{A}$. Likewise $(\mat{A}\mat{B})^2 = \mat{A}\mat{B}\mat{A}\mat{B}$, which you cannot rearrange into $\mat{A}^2\mat{B}^2$. When you find
yourself ``swapping factors,'' stop and check that those two matrices commute.
\end{trapbox}

\begin{recoverybox}
\textbf{Pause and think:} Why is $(\mat{A}+\mat{B})(\mat{A}-\mat{B})$ almost never equal to
$\mat{A}^2 - \mat{B}^2$?

\emph{Answer:} Expand carefully using the distributive laws:
\[
(\mat{A}+\mat{B})(\mat{A}-\mat{B}) = \mat{A}^2 - \mat{A}\mat{B} + \mat{B}\mat{A} - \mat{B}^2.
\]
In scalar arithmetic, the cross terms $-ab + ba$ cancel to zero. But for matrices,
$-\mat{A}\mat{B} + \mat{B}\mat{A}$ cancels \emph{only} when $\mat{A}\mat{B} = \mat{B}\mat{A}$.
When order matters, the familiar difference-of-squares formula breaks down.
\end{recoverybox}

\subsection{The rules that DO hold}

Multiplication is still well behaved in every way except commuting. For compatible
shapes and any scalar $c$:

\begin{itemize}
\item \textbf{Distributive (left):} $\ \mat{A}(\mat{B}+\mat{C}) = \mat{A}\mat{B} + \mat{A}\mat{C}$.
\item \textbf{Distributive (right):} $\ (\mat{A}+\mat{B})\mat{C} = \mat{A}\mat{C} + \mat{B}\mat{C}$.
\item \textbf{Scalars slide:} $\ c(\mat{A}\mat{B}) = (c\mat{A})\mat{B} = \mat{A}(c\mat{B})$.
\item \textbf{Associative:} $\ (\mat{A}\mat{B})\mat{C} = \mat{A}(\mat{B}\mat{C})$.
\end{itemize}

Each follows because the entries are built from sums and products of real numbers, where
these laws already hold; the matrix versions package many number identities at once.
Keep both distributive laws separate in your mind: since matrices do not commute,
multiplying on the left and multiplying on the right are different operations.

\section{The Identity: the Machine That Does Nothing}
\label{ch08:identity}

Ordinary multiplication has a number $1$ that changes nothing: $1\cdot a = a$. For
$n\times n$ matrices the same role is played by the \emph{identity matrix} $\mat{I}$
(or $\mat{I}_n$ when we want to show the size), with ones on the diagonal and zeros
elsewhere:

\[
\mat{I}_2 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix},
\qquad
\mat{I}_3 = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix}.
\]

\begin{intuitionbox}
$\mat{I}$ is the machine that leaves every vector exactly where it is: $\mat{I}\vec{x} = \vec{x}$ for all $\vec{x}$. Its columns are the basis vectors $\vec{e}_1,\dots,\vec{e}_n$
sitting in their home positions. Geometrically it does nothing at all, and that is
why it acts as the ``$1$'' of matrix multiplication.
\end{intuitionbox}

For any matrix $\mat{A}$ of the right shape, $\mat{I}\mat{A} = \mat{A}$ and
$\mat{A}\mat{I} = \mat{A}$. Quick check via the column view: the $j$-th column of
$\mat{A}\mat{I}$ is $\mat{A}$ times the $j$-th column of $\mat{I}$, which is
$\mat{A}\vec{e}_j$, which is the $j$-th column of $\mat{A}$.
So $\mat{A}\mat{I}$ has the same columns as $\mat{A}$.

\begin{remark}
$\mat{I}$ commutes with \emph{every} square matrix of its size: $\mat{A}\mat{I} = \mat{I}\mat{A} = \mat{A}$. So does any scalar multiple $c\mat{I}$ (a uniform scaling).
For most other pairs, two matrices do not commute.
\end{remark}

\section{The Inverse: Undoing a Machine}
\label{ch08:inverse}

Now the chapter's second question. The machine $\mat{A}$ sends $\vec{x}$
to $\mat{A}\vec{x}$. Is there a machine that sends it back?

\begin{definition}[Inverse matrix]
\label{ch08:inv-def}
A square matrix $\mat{A}$ is \emph{invertible} (or \emph{nonsingular}) if there is a
square matrix $\mat{A}\inv$ of the same size with
\[
\mat{A}\inv \mat{A} = \mat{I} \qquad\text{and}\qquad \mat{A}\,\mat{A}\inv = \mat{I}.
\]
If no such matrix exists, $\mat{A}$ is \emph{singular}.
\end{definition}

\begin{intuitionbox}
$\mat{A}\inv$ is the ``rewind'' machine. Run $\vec{x}$ forward through $\mat{A}$ to get
$\vec{b} = \mat{A}\vec{x}$; run $\vec{b}$ through $\mat{A}\inv$ and you are back at
$\vec{x}$, because $\mat{A}\inv\vec{b} = \mat{A}\inv\mat{A}\vec{x} = \mat{I}\vec{x} = \vec{x}$. The inverse exists exactly when the forward machine loses no information,
that is, when you can always tell from the output what the input must have been.
\end{intuitionbox}

This information-loss picture tells us \emph{when} an inverse exists. If
$\mat{A}$ ever sends two different inputs to the same output, the rewind is impossible:
seeing the output, you cannot know which input it came from. So $\mat{A}$ is invertible
exactly when it is \emph{one-to-one} (different inputs always give different outputs).
For a square matrix, being one-to-one is equivalent to several other conditions:
every target $\vec{b}$ can be reached, the columns are linearly independent, and the
determinant is nonzero.

Recall from Chapter~6 that the \emph{determinant}, written $\det\mat{A}$, is a single number
that measures the factor by which $\mat{A}$ stretches or shrinks area (in two dimensions)
or volume (in higher dimensions). If $\det\mat{A} = 0$, space is flattened into a lower
dimension, information is destroyed, and no inverse can exist. Chapter~21
(Section~\ref{ch21:unit-box}) treats determinants in full; in two dimensions the formula
is short.

\subsection{The $2\times2$ formula}

In two dimensions there is a direct formula, which you derived in Chapter~6.

\begin{theorem}[Inverse of a $2\times2$]
\label{ch08:2x2inv}
Let $\mat{A} = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$. The area-scaling factor
of $\mat{A}$ is its $2\times 2$ determinant,
\[
\det\mat{A} = ad - bc.
\]
If $\det\mat{A}\ne 0$, then $\mat{A}$ is invertible and
\[
\mat{A}\inv = \frac{1}{ad-bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}.
\]
If $ad - bc = 0$, then $\mat{A}$ has no inverse.
\end{theorem}

\begin{proof}
Multiply and see. Let $\mat{M} = \begin{bmatrix} d & -b \\ -c & a \end{bmatrix}$. Then
\[
\mat{A}\mat{M} = \begin{bmatrix} a & b \\ c & d \end{bmatrix}
\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}
= \begin{bmatrix} ad - bc & -ab + ab \\ cd - dc & -bc + ad \end{bmatrix}
= (ad-bc)\,\mat{I}.
\]
The same calculation gives $\mat{M}\mat{A} = (ad-bc)\,\mat{I}$.
So if $ad-bc \ne 0$ we may divide by it, and $\frac{1}{ad-bc}\mat{M}$ is the inverse.

Now suppose $ad - bc = 0$, so $\mat{A}\mat{M} = \mat{0}$ (the zero matrix). If
$\mat{A} = \mat{0}$, it sends everything to $\vec{0}$ and has no inverse.
Otherwise $\mat{M}\ne\mat{0}$, since $\mat{M}$ has the same entries as $\mat{A}$
(rearranged, some with signs changed). If $\mat{A}$ had an inverse, multiplying
$\mat{A}\mat{M} = \mat{0}$ on the left by $\mat{A}\inv$ would give $\mat{M}=\mat{0}$,
a contradiction. So $\mat{A}$ cannot be invertible.
\end{proof}

\begin{labbox}
Invert $\mat{A} = \begin{bmatrix} 4 & 7 \\ 2 & 6 \end{bmatrix}$ by the formula. The
determinant is $4\cdot6 - 7\cdot2 = 24 - 14 = 10$. Swap the diagonal, negate the
off-diagonal, divide by $10$:
\[
\mat{A}\inv = \frac{1}{10}\begin{bmatrix} 6 & -7 \\ -2 & 4 \end{bmatrix}
= \begin{bmatrix} 0.6 & -0.7 \\ -0.2 & 0.4 \end{bmatrix}.
\]
Now \emph{check it} (always check):
\[
\mat{A}\mat{A}\inv = \frac{1}{10}\begin{bmatrix} 4 & 7 \\ 2 & 6 \end{bmatrix}
\begin{bmatrix} 6 & -7 \\ -2 & 4 \end{bmatrix}
= \frac{1}{10}\begin{bmatrix} 24-14 & -28+28 \\ 12-12 & -14+24 \end{bmatrix}
= \frac{1}{10}\begin{bmatrix} 10 & 0 \\ 0 & 10 \end{bmatrix} = \mat{I}.\ \checkmark
\]
\end{labbox}

\subsection{The geometry of singular: area collapse}

Why is $\det\mat{A} = ad - bc$ the deciding number? Because, as Chapter~6 showed and
Chapter~21 proves in general, $\abs{\det\mat{A}}$ is the \emph{area} of the parallelogram
that $\mat{A}$ makes from the unit square (the square with corners $(0,0)$, $(1,0)$,
$(0,1)$, $(1,1)$), which is the factor by which $\mat{A}$ scales area.
Figure~\ref{ch08:areacollapse} compares the two cases.

one point to many. \textbf{Zero determinant means lost information, which means no inverse.}
That is the geometry behind ``singular.''
\end{intuitionbox}

\subsection{The big equivalence (collect everything)}

For square matrices, a long list of statements all say the same thing. You have met some
already; the rest are explained fully in the chapters on subspaces, rank, and determinants.

\begin{theorem}[The Invertible Matrix Theorem, first installment]
\label{ch08:imt}
For a square matrix $\mat{A}$ of size $n\times n$, the following are equivalent (all
true together or all false together):
\begin{enumerate}
\item $\mat{A}$ is invertible.
\item $\mat{A}\vec{x} = \vec{b}$ has exactly one solution for every $\vec{b}$.
\item $\mat{A}\vec{x} = \vec{0}$ has only the \emph{trivial} (all-zero) solution $\vec{x} = \vec{0}$.
\item The columns of $\mat{A}$ are linearly independent.
\item The columns of $\mat{A}$ span all of $\R^n$.
\item $\mat{A}$ row-reduces to the identity $\mat{I}$ (it has $n$ pivots).
\item $\det\mat{A} \ne 0$.
\end{enumerate}
\end{theorem}

We will not prove the whole chain here, since several links need later chapters, but
the central idea is the rewind picture. Invertibility (1) is ``no information lost,''
which is exactly ``nothing nonzero gets crushed to zero'' (3), which is exactly
``independent columns'' (4). The other statements connect to these.

\begin{strangbox}
Strang's course keeps coming back to this list, adding a new equivalent statement
each time a new idea appears (pivots, rank, the nullspace, eigenvalues, singular
values; the last three are explained in later chapters). \textbf{Before Strang:} read
this list as seven ways of saying ``the machine is reversible.'' \textbf{After Strang:}
you will be able to prove every link, and you will have added ``$0$ is not an eigenvalue''
and ``all singular values are positive'' to the bottom of the list.
\end{strangbox}

\section{Computing the Inverse with Gauss--Jordan}
\label{ch08:gaussjordan}

The $2\times2$ formula does not scale: the corresponding $3\times3$ formula is already
long, and for larger sizes it is impractical. We need an algorithm. It is elimination
again, with extra bookkeeping.

\subsection{The idea: solve $n$ systems at once}

Think about the columns of the inverse. Call them $\vec{x}_1,\dots,\vec{x}_n$. They must satisfy

\[
\mat{A}\vec{x}_1 = \vec{e}_1,\quad
\mat{A}\vec{x}_2 = \vec{e}_2,\quad \dots,\quad
\mat{A}\vec{x}_n = \vec{e}_n,
\]

because then $\mat{A}[\,\vec{x}_1\ \cdots\ \vec{x}_n\,] = [\,\vec{e}_1\ \cdots\ \vec{e}_n\,]
= \mat{I}$, which says exactly that $[\,\vec{x}_1\ \cdots\ \vec{x}_n\,] = \mat{A}\inv$.
So finding the inverse is the same as solving $n$ linear systems that share the same
left-hand side $\mat{A}$. Since elimination on $\mat{A}$ is identical across all $n$
systems, we do it once on all the right-hand sides simultaneously.

\begin{focusbox}
\textbf{The Gauss--Jordan recipe.} Form the wide \emph{augmented matrix}
$[\,\mat{A}\mid\mat{I}\,]$ ($\mat{A}$ with $\mat{I}$ written next to it). Row-reduce until
the left block becomes $\mat{I}$. Whatever the right block has become is $\mat{A}\inv$:
\[
[\,\mat{A}\mid \mat{I}\,] \ \xrightarrow{\text{row operations}}\ [\,\mat{I}\mid \mat{A}\inv\,].
\]
If the left block cannot be reduced to $\mat{I}$ (a zero row appears), then $\mat{A}$ is
singular and has no inverse.
\end{focusbox}

Figure~\ref{ch08:gaussjordan-flow} shows the two stages. The name records both:
the downward sweep is ordinary Gaussian elimination, and the extra upward sweep
is credited to Wilhelm Jordan, a German surveyor.

Why does the right block come out as $\mat{A}\inv$? Every row operation is
multiplication on the left by an elementary matrix (Chapter~7: the matrix you get by
doing that row operation to $\mat{I}$). If the full sequence of these is
$\mat{E} = \mat{E}_k\cdots\mat{E}_2\mat{E}_1$, then reducing the left block to $\mat{I}$
means $\mat{E}\mat{A} = \mat{I}$, so $\mat{E} = \mat{A}\inv$. But the \emph{same}
$\mat{E}$ acts on the right block, turning $\mat{I}$ into $\mat{E}\mat{I} = \mat{E} =
\mat{A}\inv$. The row operations together multiply both blocks by $\mat{A}\inv$; the
right block shows what that does to the identity.

\subsection{A full $3\times3$ worked example}

We invert

\[
\mat{A} = \begin{bmatrix} 2 & 1 & 1 \\ 1 & 3 & 2 \\ 1 & 0 & 0 \end{bmatrix}.
\]

Start by augmenting with $\mat{I}$:

\[
\left[\begin{array}{ccc|ccc}
2 & 1 & 1 & 1 & 0 & 0 \\
1 & 3 & 2 & 0 & 1 & 0 \\
1 & 0 & 0 & 0 & 0 & 1
\end{array}\right].
\]

Here $R_i$ stands for row $i$. \textbf{Step 1.} The bottom row is the simplest, so swap
rows $1$ and $3$ to put a pivot equal to $1$ in the top-left ($R_1 \leftrightarrow R_3$):

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
1 & 3 & 2 & 0 & 1 & 0 \\
2 & 1 & 1 & 1 & 0 & 0
\end{array}\right].
\]

\textbf{Step 2.} Clear the rest of column $1$. Replace $R_2 \to R_2 - R_1$ and
$R_3 \to R_3 - 2R_1$:

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
0 & 3 & 2 & 0 & 1 & -1 \\
0 & 1 & 1 & 1 & 0 & -2
\end{array}\right].
\]

\textbf{Step 3.} A pivot equal to $1$ in column $2$ avoids fractions. Row $3$ has a $1$ there, so swap
$R_2 \leftrightarrow R_3$:

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
0 & 1 & 1 & 1 & 0 & -2 \\
0 & 3 & 2 & 0 & 1 & -1
\end{array}\right].
\]

\textbf{Step 4.} Clear below the second pivot: $R_3 \to R_3 - 3R_2$:

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
0 & 1 & 1 & 1 & 0 & -2 \\
0 & 0 & -1 & -3 & 1 & 5
\end{array}\right].
\]

\textbf{Step 5.} Make the third pivot $+1$: $R_3 \to -R_3$:

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
0 & 1 & 1 & 1 & 0 & -2 \\
0 & 0 & 1 & 3 & -1 & -5
\end{array}\right].
\]

\textbf{Step 6.} Now eliminate \emph{upward} to clear above the third pivot. Only $R_2$
has an entry there: $R_2 \to R_2 - R_3$:

\[
\left[\begin{array}{ccc|ccc}
1 & 0 & 0 & 0 & 0 & 1 \\
0 & 1 & 0 & -2 & 1 & 3 \\
0 & 0 & 1 & 3 & -1 & -5
\end{array}\right].
\]

The left block is now $\mat{I}$ (column $1$ was already clean above the pivot). Read off
the right block:

\[
\mat{A}\inv = \begin{bmatrix} 0 & 0 & 1 \\ -2 & 1 & 3 \\ 3 & -1 & -5 \end{bmatrix}.
\]

\textbf{Always verify.} Multiply $\mat{A}\mat{A}\inv$ and demand $\mat{I}$:

\[
\begin{bmatrix} 2 & 1 & 1 \\ 1 & 3 & 2 \\ 1 & 0 & 0 \end{bmatrix}
\begin{bmatrix} 0 & 0 & 1 \\ -2 & 1 & 3 \\ 3 & -1 & -5 \end{bmatrix}.
\]
Row by row:
\begin{align*}
\text{row 1:}\quad & \bigl(2\cdot0 + 1\cdot(-2) + 1\cdot3,\ \ 2\cdot0 + 1\cdot1 + 1\cdot(-1),\ \
2\cdot1 + 1\cdot3 + 1\cdot(-5)\bigr) = (1,0,0),\\
\text{row 2:}\quad & \bigl(0 - 6 + 6,\ \ 0 + 3 - 2,\ \ 1 + 9 - 10\bigr) = (0,1,0),\\
\text{row 3:}\quad & \bigl(0 + 0 + 0,\ \ 0 + 0 + 0,\ \ 1 + 0 + 0\bigr) = (0,0,1).
\end{align*}
Together that is $\mat{I}$. $\checkmark$

\begin{trapbox}
Two common Gauss--Jordan slips. First, \textbf{do the row operation to the whole row}:
both blocks, every time. It is easy to update the left and forget the right.
Second, watch your \textbf{direction}: ordinary elimination only clears \emph{below} each
pivot (giving an upper-triangular $\mat{U}$); for the inverse you must also clear
\emph{above}, all the way to a clean $\mat{I}$. ``Gauss'' goes down; ``Jordan'' adds the
trip back up.
\end{trapbox}

\begin{labbox}
Your turn, by hand. Invert
\[
\mat{A} = \begin{bmatrix} 1 & 2 & 0 \\ 0 & 1 & 1 \\ 0 & 0 & 1 \end{bmatrix}
\]
with $[\,\mat{A}\mid\mat{I}\,]$. It is upper triangular, so you only ever
clear upward; no row swaps are needed. Answer (check it):
\[
\mat{A}\inv = \begin{bmatrix} 1 & -2 & 2 \\ 0 & 1 & -1 \\ 0 & 0 & 1 \end{bmatrix}.
\]
\end{labbox}

\subsection{What singular looks like in the algorithm}

If $\mat{A}$ is singular, elimination cannot manufacture a missing pivot. Somewhere a
row of the left block becomes all zeros. The moment that happens, stop: there is no
inverse. Try it on $\mat{A} = \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}$ (row
$2$ is twice row $1$, so $\det\mat{A} = 4 - 4 = 0$):

\[
\left[\begin{array}{cc|cc}
1 & 2 & 1 & 0 \\ 2 & 4 & 0 & 1
\end{array}\right]
\xrightarrow{R_2 \to R_2 - 2R_1}
\left[\begin{array}{cc|cc}
1 & 2 & 1 & 0 \\ 0 & 0 & -2 & 1
\end{array}\right].
\]

The left block has a zero row; it can never become $\mat{I}$. The algorithm itself
\emph{detects} that the matrix is singular, so you do not need to compute a determinant
first. The collapse you saw geometrically (the two columns $\colvec{1\\2}$ and $\colvec{2\\4}$ are
parallel, so the unit square flattens onto a line) shows up as that zero row.

\section{The Inverse of a Product: Socks and Shoes}
\label{ch08:product-inverse}

We close with an identity you will use often, together with a way to remember it.

\begin{theorem}[Inverse of a product]
\label{ch08:abinv}
If $\mat{A}$ and $\mat{B}$ are both invertible (and the same size), then $\mat{A}\mat{B}$
is invertible and
\[
(\mat{A}\mat{B})\inv = \mat{B}\inv \mat{A}\inv.
\]
The order reverses.
\end{theorem}

\begin{proof}
Multiply the proposed inverse by $\mat{A}\mat{B}$, using associativity to regroup:
\begin{align*}
(\mat{A}\mat{B})(\mat{B}\inv\mat{A}\inv)
&= \mat{A}(\mat{B}\mat{B}\inv)\mat{A}\inv && \text{(associativity)}\\
&= \mat{A}\,\mat{I}\,\mat{A}\inv\\
&= \mat{A}\mat{A}\inv = \mat{I}.
\end{align*}
The same cancellation from the other side gives
$(\mat{B}\inv\mat{A}\inv)(\mat{A}\mat{B}) = \mat{I}$. By
Definition~\ref{ch08:inv-def}, $\mat{B}\inv\mat{A}\inv$ is the inverse of $\mat{A}\mat{B}$.
\end{proof}

\begin{intuitionbox}
\textbf{Socks and shoes.} In the morning you put on socks ($\mat{B}$), then shoes
($\mat{A}$). To undo it at night you cannot take off the socks first, because the shoes
are in the way. You reverse the order: shoes off ($\mat{A}\inv$), then socks off ($\mat{B}\inv$).
To undo a composition, undo the \emph{last} thing first. That is exactly
$(\mat{A}\mat{B})\inv = \mat{B}\inv\mat{A}\inv$. Figure~\ref{ch08:socksshoes} draws it.
\end{intuitionbox}

\begin{figure}[H]
\centering
\begin{tikzpicture}[node distance=8mm and 16mm,>=Stealth,font=\small]
\node (x) {$\vec{x}$};
\node[right=of x] (bx) {$\mat{B}\vec{x}$};
\node[right=of bx] (abx) {$\mat{A}\mat{B}\vec{x}$};
\draw[->,thick] (x)--(bx) node[midway,above]{$\mat{B}$};
\draw[->,thick] (bx)--(abx) node[midway,above]{$\mat{A}$};
\draw[->,thick,vecred,bend left=38] (abx) to node[midway,below]{$\mat{A}\inv$} (bx);
\draw[->,thick,vecred,bend left=38] (bx) to node[midway,below]{$\mat{B}\inv$} (x);
\end{tikzpicture}
\caption{Forward (black) you apply $\mat{B}$ then $\mat{A}$. To rewind (red) you must
peel them off in reverse: $\mat{A}\inv$ first, then $\mat{B}\inv$. Hence
$(\mat{A}\mat{B})\inv = \mat{B}\inv\mat{A}\inv$.}
\label{ch08:socksshoes}
\end{figure}

The pattern extends to any chain: reverse the whole order,
\[
(\mat{A}\mat{B}\mat{C})\inv = \mat{C}\inv\mat{B}\inv\mat{A}\inv.
\]
The same reversal holds for transposes (the \emph{transpose} $\mat{A}\T$ is $\mat{A}$
flipped across its main diagonal: row $i$ of $\mat{A}$ becomes column $i$ of $\mat{A}\T$): $(\mat{A}\mat{B})\T = \mat{B}\T\mat{A}\T$, which Chapter~10
explains.

\begin{connectionbox}
\textbf{Groups.} A \emph{group} is a set with a way of combining two elements that obeys
four basic rules (its \emph{axioms}). The invertible $n\times n$ matrices, combined by
multiplication, form a group called the \emph{general linear group} $GL_n(\R)$. The four
rules are what this chapter established: the product of two invertible matrices is
invertible, with $(\mat{A}\mat{B})\inv = \mat{B}\inv\mat{A}\inv$; multiplication is
associative (Theorem~\ref{ch08:assoc}); there is an identity $\mat{I}$; and every
element has an inverse. The order-reversing inverse rule holds in every group, not
only for matrices: it holds for the symmetries of a cube, for shuffles of a deck of
cards, and for rotations of space. Physicists describe the symmetries of physical laws
with groups, and groups of matrices such as the rotations are the main examples.
\end{connectionbox}

\begin{remark}[A useful shortcut you have earned]
To \emph{prove} a square matrix $\mat{C}$ is invertible with inverse $\mat{D}$, you do
not have to check both $\mat{C}\mat{D}=\mat{I}$ and $\mat{D}\mat{C}=\mat{I}$. For square
matrices, either one alone implies the other (a fact that follows from the equivalence in
Theorem~\ref{ch08:imt}). So in the proof above, the first check alone would have been
enough. Be careful, though: this shortcut is for \emph{square} matrices only. A
non-square matrix can have a one-sided inverse (on the left or on the right) but never
both at once.
\end{remark}

\section*{Looking Back, Looking Ahead}

Two questions, two answers. \emph{What is two machines in a row?} A single matrix
$\mat{A}\mat{B}$, best understood through the four views (entries, columns, rows, and
rank-one layers), and obeying every algebra rule except commuting. \emph{Can we undo a
machine?} Only when it loses no information; then the rewind is $\mat{A}\inv$, computed
by Gauss--Jordan, and products rewind in reverse order.

\begin{focusbox}
\textbf{Cost and intuition, side by side.} The dot-product view tells you the
\emph{price}: an $n\times n$ product is about $n^3$ multiply--adds, and inverting an
$n\times n$ matrix by Gauss--Jordan is the same $n^3$ order of work (elimination on $n$
right-hand sides at once). The other three views tell you the \emph{meaning}: columns of
$\mat{A}\mat{B}$ live in $\col(\mat{A})$, rows live in $\row(\mat{B})$, and the whole
product is a sum of rank-one layers. The price comes from View~1; the understanding,
and many of the ways to save work, come from Views 2--4.
\end{focusbox}

Many of the next chapters \emph{factor} a matrix: they write it as a product of
simpler matrices. The next chapter writes elimination itself as a product
$\mat{A} = \mat{L}\mat{U}$ of a lower-triangular and an upper-triangular matrix.
Later, $\mat{A} = \mat{Q}\mat{R}$ splits a matrix into a rotation-like part and a
triangular part, and the singular value decomposition
$\mat{A} = \mat{U}\mat{\Sigma}\mat{V}\T$ shows that \emph{every} matrix is a rotation,
followed by stretching along the axes, followed by another rotation (where
``rotation'' may include a reflection). Each of these is read using the rules of
this chapter.

\begin{historybox}
The algebraic language of matrix multiplication and inversion was developed by Arthur Cayley in his
1858 paper \emph{A Memoir on the Theory of Matrices}. Cayley was dealing with a practical problem:
\emph{linear substitutions}. In the geometry and algebra of the 1850s, mathematicians often changed
coordinate systems by substituting one set of linear equations into another. Doing two substitutions in succession
meant pages of tedious, error-prone expansion of coefficients by hand. Cayley saw that if you pack
the coefficients of each substitution into a rectangular grid, the two-step substitution becomes
a single product of two grids.

Before Cayley, mathematicians already worked with \emph{determinants} (used a century earlier by Gabriel
Cramer and Colin Maclaurin to solve systems of equations). James Joseph Sylvester had coined
the word ``matrix'' in 1850 for a rectangular table of numbers from which smaller determinants could be taken;
Cayley turned the table itself into an algebraic object with addition,
multiplication, and inverses ($\mat{A}\mat{A}\inv = \mat{I}$).

The new algebra broke a rule that arithmetic had always obeyed: that order does not matter ($ab = ba$).
Cayley's product does not commute: $\mat{A}\mat{B} \ne \mat{B}\mat{A}$ in general. For decades, matrices
were treated as a specialist topic in pure algebra.

Physics changed that. In 1925, Werner Heisenberg built a new quantum mechanics from tables of numbers
describing energy jumps in atoms, with a multiplication rule that did not commute. Max Born recognized
that Heisenberg's tables were matrices and his rule was Cayley's matrix product. The resulting theory,
\emph{matrix mechanics}, is one of the two original forms of quantum mechanics.

A second change came with digital computers. Generations of textbooks had taught
Cramer's 1750 determinant rule for solving $\mat{A}\vec{x} = \vec{b}$: $x_i = \det(\mat{A}_i) / \det(\mat{A})$,
where $\mat{A}_i$ is $\mat{A}$ with column $i$ replaced by $\vec{b}$.
The rule is short on paper but very slow to compute: evaluating $n+1$ determinants by expansion takes
about $(n+1)!$ arithmetic operations. For a $25\times 25$ system that is about $4\times 10^{26}$ operations;
a computer doing a billion operations per second would need roughly the age of the universe. When early
programmers abandoned Cramer's rule, many fell into the opposite trap: they computed $\mat{A}\inv$ explicitly and then
$\vec{x} = \mat{A}\inv\vec{b}$. In the 1960s, the numerical analysts George Forsythe and Cleve Moler argued against
this habit. Computing $\mat{A}\inv$ takes about three times as many operations as elimination, is usually less
accurate because of rounding errors, and destroys \emph{sparsity}. In engineering simulations (heat flow, power grids,
building structures), matrices often have millions of entries that are almost all zeros. Such \emph{sparse} matrices
need little memory, because only the nonzero entries are stored. But the inverse $\mat{A}\inv$ is usually
\emph{dense}: almost every entry is nonzero, and storing it can exhaust the computer's memory.

One question is still open: how fast can matrices be multiplied? For over a century, people assumed
multiplying two $n\times n$ matrices needed roughly $n^3$ operations (the count from View~1). In 1969,
Volker Strassen showed that two $2\times 2$ matrices can be multiplied with
only $7$ multiplications of numbers instead of $8$. Applied to big matrices split into blocks, this gives an
algorithm taking $O(n^{2.807})$ operations, so $n^3$ is not a law of nature. Write $\omega$ (omega) for the smallest
exponent that can be achieved, so that multiplication takes about $n^{\omega}$ operations. A long series of
improvements, most recently by Josh Alman, Virginia Vassilevska Williams, Ran Duan, and others, has pushed the best
known bound below $\omega < 2.372$. Whether $\omega = 2$, meaning that multiplying two $n\times n$ matrices costs
little more than reading their $n^2$ entries, is a major open problem in mathematics
and theoretical computer science.
\end{historybox}

\section{Exercises}
\label{ch08:exercises}

\begin{exercise}[Warm-up by hand]
Compute $\mat{A}\mat{B}$ and $\mat{B}\mat{A}$ for
$\mat{A} = \begin{bmatrix} 1 & 2 \\ 0 & 1 \end{bmatrix}$,
$\mat{B} = \begin{bmatrix} 1 & 0 \\ 3 & 1 \end{bmatrix}$. Confirm they are different, and
say in one sentence why two shears in different orders give different results.
\end{exercise}

\begin{exercise}[All four views]
For $\mat{A} = \begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix}$ and
$\mat{B} = \begin{bmatrix} 1 & 4 \\ 2 & 0 \end{bmatrix}$, compute $\mat{A}\mat{B}$
\emph{four ways}: (a) entry by entry (dot products), (b) as combinations of $\mat{A}$'s
columns, (c) as combinations of $\mat{B}$'s rows, (d) as a sum of two outer products.
Verify all four agree.
\end{exercise}

\begin{exercise}[Shapes]
$\mat{A}$ is $3\times 2$, $\mat{B}$ is $2\times 5$, $\mat{C}$ is $5\times 3$. Which of
$\mat{A}\mat{B}$, $\mat{B}\mat{C}$, $\mat{C}\mat{A}$, $\mat{A}\mat{B}\mat{C}$,
$\mat{C}\mat{A}\mat{B}$ are defined, and what is each one's shape? Which products
$\mat{X}\mat{Y}$ from this list are square?
\end{exercise}

\begin{exercise}[$2\times2$ inverse]
Use the formula to invert $\mat{A} = \begin{bmatrix} 3 & 5 \\ 1 & 2 \end{bmatrix}$, then
check $\mat{A}\mat{A}\inv = \mat{I}$. What is $\det\mat{A}$, and how does it appear in the
answer?
\end{exercise}

\begin{exercise}[Gauss--Jordan]
Invert $\mat{A} = \begin{bmatrix} 1 & 1 & 1 \\ 0 & 2 & 1 \\ 1 & 0 & 1 \end{bmatrix}$ by
augmenting with $\mat{I}$ and row-reducing to $[\,\mat{I}\mid\mat{A}\inv\,]$. Show every
step, and verify your answer.
\end{exercise}

\begin{exercise}[Detecting singular]
Run Gauss--Jordan on $\mat{A} = \begin{bmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 0 & 1 & 1 \end{bmatrix}$ far enough to show it is singular. Identify the row that forces the
collapse, and describe geometrically what $\mat{A}$ does to the unit cube.
\end{exercise}

\begin{exercise}[Socks and shoes, with numbers]
Let $\mat{A} = \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix}$ and
$\mat{B} = \begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$. Compute $\mat{A}\inv$,
$\mat{B}\inv$, and $\mat{A}\mat{B}$. Verify directly that $(\mat{A}\mat{B})\inv =
\mat{B}\inv\mat{A}\inv$, and check that $\mat{A}\inv\mat{B}\inv$ gives the \emph{wrong}
answer (it is not the inverse of $\mat{A}\mat{B}$).
\end{exercise}

\begin{exercise}[Rank cannot grow]
Using the column view, explain why every column of $\mat{A}\mat{B}$ is a linear
combination of the columns of $\mat{A}$. Conclude that $\rank(\mat{A}\mat{B}) \le
\rank(\mat{A})$. Then give a $2\times2$ example where $\mat{A}\ne\mat{0}$, $\mat{B}\ne
\mat{0}$, yet $\mat{A}\mat{B} = \mat{0}$ --- so rank can \emph{drop} all the way to zero.
\end{exercise}

\begin{exercise}[Inverse of a diagonal matrix]
Let $\mat{D} = \diag(d_1,\dots,d_n)$. Show that $\mat{D}$ is invertible if and only if
every $d_i \ne 0$, and that then $\mat{D}\inv = \diag(1/d_1,\dots,1/d_n)$. What goes
wrong, geometrically and in Gauss--Jordan, if some $d_i = 0$?
\end{exercise}

\begin{exercise}[Proof: inverses are unique]
Suppose $\mat{B}$ and $\mat{C}$ both satisfy $\mat{B}\mat{A} = \mat{I}$ and
$\mat{A}\mat{C} = \mat{I}$. Prove $\mat{B} = \mat{C}$. (Hint: simplify the product
$\mat{B}\mat{A}\mat{C}$ in two ways, using associativity.) Conclude that a matrix has at
most one inverse.
\end{exercise}

\begin{exercise}[Challenge: a $2\times2$ identity]
For an invertible $2\times2$ matrix $\mat{A} = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$, prove that
\[
\mat{A}\inv = \frac{1}{\det\mat{A}}\bigl((\tr\mat{A})\,\mat{I} - \mat{A}\bigr),
\]
where $\tr\mat{A} = a + d$ is the \emph{trace} (the sum of the diagonal entries). (This
is the $2\times2$ case of the Cayley--Hamilton theorem, which you will meet after
eigenvalues. Expand both sides.)
\end{exercise}

\begin{exercise}[Challenge: commuting with everything]
Prove that if a square matrix $\mat{M}$ satisfies $\mat{M}\mat{A} = \mat{A}\mat{M}$ for
\emph{every} matrix $\mat{A}$ of the same size, then $\mat{M} = c\mat{I}$ for some scalar
$c$. (Hint: try the outer product $\mat{A} = \vec{e}_i\vec{e}_j\T$, the matrix with a single $1$ in
position $(i,j)$, and see what commuting forces on the entries of $\mat{M}$.)
\end{exercise}
