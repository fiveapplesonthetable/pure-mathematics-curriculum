\section{Countability and the First Shock of Infinity}
\chapterline

For centuries, mathematicians thought of infinity as one thing: an endless process, written with the symbol $\infty$.

Then, in the 1870s, Georg Cantor asked:
\begin{center}
\emph{Can one infinity be strictly larger than another?}
\end{center}

We cannot answer this by counting an infinite set to its end, because the counting never ends. Cantor compared sets instead by \textbf{pairing} their elements, using the bijections (one-to-one pairings) of the chapter on injective, surjective and bijective functions.

\begin{historybox}
In 1874, Georg Cantor published a paper proving that the algebraic numbers (numbers that are roots of polynomials with integer coefficients, such as $\sqrt{2}$, a root of $x^2 - 2$) can be paired one-to-one with the natural numbers $\N$, but the real numbers $\R$ cannot. This had an unexpected consequence: the transcendental numbers (real numbers that are not algebraic, such as $\pi$ and $e$) are not rare exceptions. They make up almost all of the real line, as we will see at the end of this chapter.

Cantor's work met strong resistance at first. Leopold Kronecker, who accepted only mathematical objects that can be built from the integers in finitely many steps, remarked ``God made the integers, all else is human work,'' and distrusted Cantor's completed infinite sets. Henri Poincar\'e also expressed reservations about Cantor's theory of infinite sizes.

In 1891, Cantor introduced his diagonal argument (the method behind this chapter's main proof) and used it to prove that every set $S$ is strictly smaller than its power set $\pow(S)$, the set of all subsets of $S$: $|S| < |\pow(S)|$. David Hilbert later championed Cantor's work, declaring in 1926: ``No one shall expel us from the paradise that Cantor has created for us.''
\end{historybox}

\subsection{Measuring Size Without Counting}

Imagine a theater filled with spectators and seats. If every person is sitting in exactly one seat, and no seats are empty, you know that the number of spectators equals the number of seats. You do not need to count whether there are $50$ people or $50{,}000$: the pairing of people with seats is a bijection, and that alone proves the two numbers match.

Cantor applied this exact principle to infinite sets:

\begin{definition}[Equinumerosity and Countability]
Two sets $A$ and $B$ have the \textbf{same cardinality} (written $|A| = |B|$) if there exists a bijection $f: A \to B$. We say $A$ and $B$ are \textbf{equinumerous}.

A set $S$ is \textbf{countably infinite} if there exists a bijection $f: \N \to S$. A set is \textbf{countable} if it is either finite or countably infinite. A set that is not countable is called \textbf{uncountable}.
\end{definition}

\emph{Cardinality} is the mathematician's name for the size of a set, measured by pairing; $|A|$ is read ``the cardinality of $A$'', and for a finite set it is the number of elements. In plain terms, a countably infinite set is one whose elements you can line up in an infinite queue
\[
s_1, \; s_2, \; s_3, \; s_4, \; \dots
\]
(here $s_n$ stands for $f(n)$, and $\N = \{1, 2, 3, \dots\}$) such that every member of the set appears at some finite position in the list.

\begin{recoverybox}
\textbf{Mental Check:} If someone claims a set $S$ is countably infinite, what concrete mathematical object are they obligated to produce?
\par\vspace{0.3em}
\emph{Answer:} An infinite numbered list $s_1, s_2, s_3, \dots$ that contains every element of $S$ at some finite position $n \in \N$, with no omissions and no duplicates.
\end{recoverybox}

\subsection{Galileo's Paradox: The Evens Match the Naturals}

In 1638, in his final work \emph{Discorsi e dimostrazioni matematiche intorno a due nuove scienze}, Galileo Galilei pointed out a puzzle about infinite collections. Consider the set of all positive even integers:
\[
2\N = \{2, 4, 6, 8, 10, \dots\}.
\]
Look at them laid out on the number line. Between every two even numbers sits an odd number that was skipped. Our spatial intuition insists there are only half as many even numbers as natural numbers $\N = \{1, 2, 3, \dots\}$.

Now compare the two sets by pairing instead. Consider the function
\[
f: \N \to 2\N, \quad f(n) = 2n.
\]
\begin{itemize}
\item If $2a = 2b$, then dividing by $2$ gives $a = b$ (injective: no two different counting numbers share the same even partner).
\item Every even integer $2k \in 2\N$ has an input $k \in \N$ where $f(k) = 2k$ (surjective: every even number is claimed).
\end{itemize}
The function $f$ is a bijection. Despite omitting all odd integers, the set of even numbers has the same cardinality as the set of all natural numbers:
\[
|2\N| = |\N|.
\]
Figure~\ref{19:fig-stadium-galileo} sets the two views side by side.

For infinite sets, Euclid's old rule ``the whole is greater than the part'' fails. Richard Dedekind made this failure the definition of the infinite: \emph{a set $S$ is infinite if and only if it can be placed in one-to-one correspondence with a proper subset of itself} (a subset that leaves out at least one element of $S$). For a finite set, the Pigeonhole Principle guarantees that removing an element makes the set strictly smaller; from an infinite set, you can remove infinitely many elements and still have just as many left over.

\begin{recoverybox}
\textbf{Mental Check:} Can you construct an explicit bijection between the natural numbers $\N$ and the positive \emph{odd} integers $\{1, 3, 5, 7, \dots\}$?
\par\vspace{0.3em}
\emph{Answer:} Yes. The function $g(n) = 2n - 1$ sends $1 \mapsto 1$, $2 \mapsto 3$, $3 \mapsto 5$, pairing every natural number with a unique odd number.
\end{recoverybox}

\subsection{The Integers are Countable}

What about the set of all integers $\Z = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$? 

Unlike $\N$, which begins cleanly at $1$, the integers stretch endlessly in two opposite directions. If you tried to count them by walking out along $0, 1, 2, 3, \dots$, you would walk forever and never reach $-1$. 

The fix is to alternate between positive and negative values, zigzagging outward from $0$, as Figure~\ref{19:fig-integers-spiral} shows.

The explicit bijection $f: \N \to \Z$ is:
\[
f(n) = \begin{cases} \frac{n}{2} & \text{if } n \text{ is even}, \\ -\frac{n-1}{2} & \text{if } n \text{ is odd}. \end{cases}
\]
To check that this is a bijection, we write down its inverse $f^{-1}: \Z \to \N$, a function that undoes $f$ in both directions ($f^{-1}(f(n)) = n$ and $f(f^{-1}(z)) = z$); a function with an inverse is a bijection. Given any integer $z$, the inverse tells you its position $n$ in the list:
\[
f^{-1}(z) = \begin{cases} 2z & \text{if } z > 0, \\ 1 - 2z & \text{if } z \le 0. \end{cases}
\]
Indeed, if $z > 0$, then $2z$ is even; if $z \le 0$, then $1 - 2z \ge 1$ is odd. Applying the matching rule for $f$ gives back $z$ in both cases:
\begin{align*}
z > 0: \qquad f(2z) &= \frac{2z}{2} = z, \\
z \le 0: \qquad f(1 - 2z) &= -\frac{(1 - 2z) - 1}{2} = -\frac{-2z}{2} = z.
\end{align*}
Similarly $f^{-1}(f(n)) = n$ for both even and odd $n$. For example, $-3$ appears at index $1 - 2(-3) = 7$, matching Figure~\ref{19:fig-integers-spiral}. Every integer appears at a finite position, so $|\Z| = |\N|$: the line that runs forever in both directions has no more elements than the ray that runs forever in one.

\subsection{The Rationals are Countable: Cantor's Snake}

The rational numbers $\Q$ seem much larger than the integers. Between any two integers lies an infinite collection of fractions. Worse, between any two fractions $a < b$ you can always find another fraction, for instance their midpoint $(a+b)/2$; between that midpoint and either end there are still more fractions, and so on forever. 

Unlike the integers, where $4$ is followed immediately by $5$ with nothing in between, the rationals have no ``next-door neighbor.'' If you stand at $1/2$, what is the next rational number? There is no such thing. Mathematicians say the rational numbers are \textbf{dense} on the real line: between any two of them lies another. Figure~\ref{19:fig-rationals-dense} shows why no fraction can be the one right after $1/2$.

If you try to list the rationals in increasing numerical order, there are infinitely many fractions between $0$ and $1$, so you would never even reach $2$.

But density describes how the numbers are arranged along the line, not how many there are. The rationals are countable.

To list them, Cantor gave up ordering by size. Start with the positive rationals, written $\Q^+$. Arrange all pairs of positive integers $(p, q)$ in an infinite grid with one row for each numerator $p$ and one column for each denominator $q$, so the entry in row $p$ and column $q$ is the fraction $p/q$. Then walk through the grid one \emph{diagonal} at a time, where a diagonal is the set of entries with the same value of $p + q$. Figure~\ref{19:fig-cantor-snake} shows the path.

Because each diagonal $p + q = k$ contains only $k - 1$ entries (a finite number), the snake reaches any chosen fraction $p/q$ after a finite number of steps. For instance, the fraction $355/113$ sits on diagonal $355 + 113 = 468$; because all previous $466$ diagonals together contain only finitely many fractions, the snake arrives at $355/113$ after finitely many steps.

By omitting duplicate fractions that are not in lowest terms (such as $2/2 = 1/1$, $4/2 = 2/1$, or $2/4 = 1/2$), each positive rational number is visited exactly once. This establishes an explicit bijection between $\N$ and the positive rationals $\Q^+$.

Just as we did with the integers, we can now interleave the positive rationals with their negative counterparts and insert $0$ at the very front:
\[
0, \; \frac{1}{1}, \; -\frac{1}{1}, \; \frac{1}{2}, \; -\frac{1}{2}, \; \frac{2}{1}, \; -\frac{2}{1}, \; \frac{3}{1}, \; -\frac{3}{1}, \; \frac{1}{3}, \; -\frac{1}{3}, \; \dots.
\]
Every rational number appears at a definite, finite position. Therefore:
\[
|\Q| = |\N|.
\]

\begin{recoverybox}
\textbf{Mental Check:} Why can't we count the grid by reading row 1 all the way across: $1/1, 1/2, 1/3, 1/4, \dots$?
\par\vspace{0.3em}
\emph{Answer:} Because row 1 is infinite. If you tried to finish row 1 before moving to row 2, you would walk forever along row 1 and never reach $2/1$. The diagonal snake works because every diagonal is finite.
\end{recoverybox}

\subsection{The Shock: The Real Numbers are Uncountable}

At this point, one might wonder: is \emph{every} infinite set countable? If both the integers and the dense set of rational numbers can be arranged into sequences, could it be that all infinite sets have the same cardinality?

Cantor showed that the answer is no: the real numbers cannot be listed in an infinite sequence.

\begin{theorem}[Cantor's Diagonal Theorem]
The open interval of real numbers $(0, 1)$ is uncountable.
\end{theorem}

\begin{proof}
We argue by contradiction. Suppose that $(0, 1)$ were countable. 
Then there exists a bijection from $\N$ to $(0, 1)$, meaning we can write down a complete, numbered list of every real number in $(0, 1)$:
\[
r_1, \; r_2, \; r_3, \; r_4, \; \dots.
\]
Write each number as an infinite decimal:
\begin{align*}
r_1 &= 0.\mathbf{d_{11}} d_{12} d_{13} d_{14} \dots \\
r_2 &= 0.d_{21} \mathbf{d_{22}} d_{23} d_{24} \dots \\
r_3 &= 0.d_{31} d_{32} \mathbf{d_{33}} d_{34} \dots \\
r_4 &= 0.d_{41} d_{42} d_{43} \mathbf{d_{44}} \dots
\end{align*}
where $d_{ij} \in \{0, 1, \dots, 9\}$ is the $j$-th decimal digit of $r_i$.

We now construct a real number $d = 0.c_1 c_2 c_3 c_4 \dots$ that differs from every number on the list. For each integer $n \ge 1$, we look at the diagonal digit $d_{nn}$ and choose $c_n$ by the rule
\[
c_n = \begin{cases} 5 & \text{if } d_{nn} = 4, \\ 4 & \text{if } d_{nn} \neq 4. \end{cases}
\]
Figure~\ref{19:fig-cantor-diagonal} shows this rule applied to a sample list. The number $d$ has three properties:
\begin{enumerate}[label=\arabic*.]
\item Because every digit $c_n$ is either $4$ or $5$, $d$ lies between $0.444\ldots$ and $0.555\ldots$, so $0 < d < 1$. Thus $d \in (0, 1)$.
\item The decimal expansion of $d$ contains only $4$s and $5$s, so it does not end in an endless run of $0$s or of $9$s. Therefore $d$ has only one decimal expansion (see the warning box after the proof).
\item Compare $d$ to any number $r_n$ on the list: their $n$-th decimal digits differ by construction ($c_n \neq d_{nn}$). Because $d$ has only one decimal expansion, $r_n$ cannot be $d$ written in a different form, so differing at digit $n$ guarantees that they are unequal as real numbers:
\[
d \neq r_n \quad \text{for every integer } n \ge 1.
\]
\end{enumerate}

This is a direct contradiction: the list $r_1, r_2, \dots$ was assumed to contain \emph{every} real number in $(0, 1)$, yet the number $d$ lives in $(0, 1)$ and appears nowhere on the list.

Therefore, our initial assumption was false. The interval $(0, 1)$ cannot be listed in a sequence, and is uncountable.
\end{proof}

\begin{trapbox}
\textbf{The Trap of Dual Decimal Expansions}

Why did we use only the digits $4$ and $5$? Why not set $c_n = d_{nn} + 1$, with $9$ wrapping around to $0$?

Because in base 10, some numbers have \emph{two} different decimal expansions:
\[
0.49999\dots = 0.50000\dots
\]
If our construction produced a number ending in an endless run of $9$s (or of $0$s), then $d$ could equal a listed number written in its other form. For example, $d = 0.4999\dots$ could appear on the list as $0.5000\dots$, which differs from $d$ at every digit and yet is the same number. Figure~\ref{19:fig-dual-decimal} shows why $0.4999\dots$ and $0.5$ are the same point.

Because every digit $c_n$ is $4$ or $5$, the number $d$ never ends in a run of $9$s or $0$s. Its decimal expansion is unique, so differing digits do mean $d \neq r_n$.
\end{trapbox}

\subsection{What Cardinality Explains, Its Limits, and What Comes Next}

Cantor's way of comparing sizes has consequences far beyond counting:
\begin{itemize}
\item \textbf{Existence without an example:} An \emph{algebraic number} is any real root of a polynomial with integer coefficients (such as $\sqrt{2}$, a root of $x^2 - 2$, or $-3/5$, a root of $5x + 3$). A polynomial of degree $n$ (highest power $x^n$) has at most $n$ roots, and there are only countably many polynomials with integer coefficients (each one is described by a finite list of integers), so the set of algebraic numbers is countable (compare Exercise~3). A \emph{transcendental number} is a real number that is not algebraic, such as $\pi$ or $e$. If the transcendental numbers were countable, $\R$ would be the union of two countable sets and so would be countable (list the two sets alternately, as we did for $\Z$). Since $\R$ is uncountable, the transcendental numbers are uncountable: all but countably many real numbers are transcendental. Cantor's argument proves this without exhibiting a single transcendental number; a proof of this kind is called \emph{non-constructive}.
\item \textbf{Limits of computing:} A computer program is a finite string of characters from a finite alphabet, so (as in Exercise~1(a)) there are only countably many programs. A yes/no question about natural numbers, such as ``is $n$ prime?'', is a function from $\N$ to $\{0, 1\}$ that sends $n$ to $1$ for ``yes'' and $0$ for ``no''. There are uncountably many such functions (each is an infinite sequence of $0$s and $1$s; see Exercise~1(b)). So most yes/no questions cannot be answered by any program. In 1936, Alan Turing used a diagonal argument to name a specific one: the \emph{Halting Problem}, which asks whether a given program eventually stops when run on a given input, cannot be decided by any program.
\item \textbf{No largest infinity:} Cantor proved that for \emph{any} set $S$, the power set $\pow(S)$ has strictly greater cardinality than $S$: $|S| < |\pow(S)|$ (Exercise~4). Taking power sets again and again gives an endless chain of larger and larger infinities,
\[
|\N| < |\pow(\N)| < |\pow(\pow(\N))| < \cdots,
\]
so there is no largest one. Cantor wrote $\aleph_0$ (read ``aleph-null''; $\aleph$ is the first letter of the Hebrew alphabet) for $|\N|$. Since a finite set $A$ has $2^{|A|}$ subsets, he wrote $2^{\aleph_0}$ for $|\pow(\N)|$, and one can show that this equals $|\R|$. In this notation the chain reads
\[
\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}} < \cdots.
\]
\end{itemize}

Cardinality only asks whether a pairing exists. It ignores distance, shape and dimension. Cantor discovered that
\[
|(0, 1)| = |\R| = |\R^2| = |\R^{100}|,
\]
where $\R^2$ is the plane (all pairs of real numbers) and $\R^{100}$ is the set of all lists of $100$ real numbers. An interval, the real line, a two-dimensional plane, and a $100$-dimensional space all have the same cardinality. In 1877 Cantor paired the points of a line segment with the points of a square by interleaving digits. Roughly, the point of the square with coordinates $x = 0.a_1a_2a_3\ldots$ and $y = 0.b_1b_2b_3\ldots$ goes to the point
\[
(0.a_1a_2a_3\ldots,\; 0.b_1b_2b_3\ldots) \;\longmapsto\; 0.a_1b_1a_2b_2a_3b_3\ldots
\]
on the segment, as Figure~\ref{19:fig-interleave} shows. He wrote to Richard Dedekind:
\begin{center}
\emph{``Je le vois, mais je ne le crois pas!''} (``I see it, but I do not believe it!'')
\end{center}

Yet a plane and a line are different as shapes. Cantor's pairing of a segment with a square has to scramble nearness: points that are close together on the segment can land far apart in the square. Cardinality cannot see distance, so it cannot tell whether a function is continuous (has no sudden jumps) or whether a sequence of points converges (gets closer and closer to a limit).

Calculus needs exactly these notions, so we must give the real numbers a notion of distance and limits. The next chapter, \textbf{Real Analysis Preview: Epsilon as a Contract}, shows how Cauchy and Weierstrass defined limits precisely using quantifiers.

\subsection{Exercises}

\begin{enumerate}
\item \textbf{Mental Check: Finite Strings vs Infinite Sequences.}
Let $\Sigma = \{0, 1\}$, an alphabet of two symbols.
\begin{enumerate}[label=(\alph*)]
\item Prove that the set of all \emph{finite} binary strings $\Sigma^*$ (strings of length $0, 1, 2, \dots$) is countably infinite. (Hint: List the empty string, then strings of length $1$, then strings of length $2$, and so on.)
\item Prove that the set of all \emph{infinite} binary sequences $\Sigma^\omega = \{(b_1, b_2, b_3, \dots) : b_i \in \{0, 1\}\}$ is uncountable by adapting Cantor's diagonal argument.
\end{enumerate}

\item \textbf{Rescaling the Real Line.}
\begin{enumerate}[label=(\alph*)]
\item For any two real numbers $a < b$, construct an explicit linear bijection $f: (0, 1) \to (a, b)$, proving that all open intervals have the same cardinality regardless of their length.
\item Using the tangent function, construct an explicit bijection $g: (-\pi/2, \pi/2) \to \R$, proving that a finite interval of length $\pi$ has the exact same cardinality as the entire infinite real line.
\end{enumerate}

\item \textbf{Countable Union of Countable Sets.}
Suppose $\{A_n\}_{n=1}^\infty$ is a countably infinite collection of sets, where each set $A_n = \{a_{n,1}, a_{n,2}, a_{n,3}, \dots\}$ is countably infinite. Prove that their union:
\[
A = \bigcup_{n=1}^\infty A_n
\]
is countably infinite. (Hint: Arrange the elements into a two-dimensional grid where row $n$ lists the elements of $A_n$, adapt Cantor's diagonal snake traversal, and skip any element that has already appeared earlier if the sets $A_n$ overlap.)

\item \textbf{Cantor's General Theorem: Diagonalization in the Abstract.}
Prove that for \emph{any} set $S$ (finite or infinite), there is no surjective function from $S$ to its power set $\pow(S)$. (The map $x \mapsto \{x\}$ is an injection from $S$ into $\pow(S)$, so $|S| \le |\pow(S)|$; with this exercise, $|S| < |\pow(S)|$.)
\begin{enumerate}[label=(\alph*)]
\item Suppose towards a contradiction that $f: S \to \pow(S)$ is surjective. Define the subset:
\[
D = \{x \in S : x \notin f(x)\}.
\]
\item Because $f$ is surjective and $D \in \pow(S)$, there must exist an element $d \in S$ such that $f(d) = D$.
\item Ask: is $d \in D$? Show that $d \in D \implies d \notin D$, and $d \notin D \implies d \in D$, producing a contradiction.
\item Reflect: How is the definition of $D$ related to Cantor's diagonal number $d$, Russell's paradox, and the Halting Problem?
\end{enumerate}

\item \textbf{A Glimpse of Hilbert's Hotel on an Interval.}
Hilbert's Hotel is a story about a full hotel with infinitely many rooms $1, 2, 3, \dots$ that still makes room for a new guest: every guest moves from room $n$ to room $n + 1$, freeing room $1$ (Figure~\ref{19:fig-hilbert-hotel}). Use the same trick here.
Prove that the half-open interval $(0, 1]$ (which includes $1$) has the same cardinality as the open interval $(0, 1)$ by constructing an explicit bijection $h: (0, 1] \to (0, 1)$.
\par\vspace{0.2em}
\emph{Hint:} Isolate a countable sequence in $(0, 1]$, say $S = \{1, 1/2, 1/4, \dots, 1/2^k, \dots\}$. Shift each element of $S$ to the next power of $2$ ($1 \mapsto 1/2$, $1/2 \mapsto 1/4$, $\dots$), and leave every other real number $x \notin S$ exactly where it is.
\end{enumerate}
