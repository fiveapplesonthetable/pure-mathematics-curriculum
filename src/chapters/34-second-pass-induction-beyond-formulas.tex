\section{Second Pass: Induction Beyond Formulas}
\chapterline

In Chapter~33, equivalence relations sorted a set that was already given into classes, and quotients merged each class into a single new object, giving modular numbers and the torus. In both cases the whole collection of objects was handed to us at the start.

Many objects are not given all at once. They are built step by step from smaller pieces by fixed rules (they are \emph{generated recursively}). How do we prove that a property holds for every one of infinitely many such objects without checking each one?

Most students first meet the answer, mathematical induction, as a method for verifying summation formulas:
\[
1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}.
\]
You check $n=1$, assume the statement for $k$, add $k+1$ to both sides, factor an expression, and complete the induction step.

This routine is correct, but it hides what induction is (recall the picture proof of this sum with two interlocking staircases in Chapter~17). Induction works for any collection of objects built up from starting pieces by fixed rules. Such a collection is called \emph{inductively defined}. The positive integers are one example: start at $1$ and keep adding $1$. Syntax trees (Chapter~27) are another, and so are the recursive data types of programming, such as lists and trees, where a larger value is assembled from smaller values of the same type.

\begin{historybox}
In 1904, the German mathematician Ernst Zermelo tackled a problem that had been open for decades: Georg Cantor's conjecture that \emph{every} set can be well-ordered. An ordering of a set is a \emph{well-ordering} if every non-empty subset has a smallest element, as in the positive integers, where any collection you choose has a minimum. The counting numbers $1 < 2 < 3 < \dots$ come with such an order, but no one knew how to order the real numbers $\R$ so that every subset, even an open interval like $(0, 1)$, would have a least element. (The usual order fails: $(0,1)$ has no smallest member.)

To solve this, Zermelo used the \emph{Axiom of Choice}: given any collection of non-empty bins, even infinitely many, you may select one item from each bin, even when there is no explicit rule for choosing. Zermelo proved that with this axiom every set can be well-ordered. This made \emph{transfinite induction} available on every set: induction continued past all the counting numbers, along a well-ordering of any length. His proof caused a fierce controversy. The French mathematicians \'Emile Borel, Ren\'e Baire, and Henri Lebesgue rejected it, arguing that a well-ordering nobody can compute or write down is not a legitimate mathematical object.

In the early 1960s the computer scientist John McCarthy faced a different question: how can you prove mathematically that a program stops, or that a compiler (the program that translates source code into machine instructions) translates code without introducing bugs? Programs do not only process numbers; they handle nested, tree-shaped data such as the syntax trees of the code being compiled. Building on McCarthy's ideas, Rod Burstall in 1969 described \emph{structural induction}: proving a property of tree-shaped data by working from the leaves up to the root, without counting along a number line.

Today structural induction is built into proof assistants such as Lean, Coq, and Isabelle. The older debate is still alive: whether to do mathematics constructively (Chapter~5), without the Axiom of Choice, still shapes the type theories (Chapter~30) behind these tools. And by Turing's result on the Halting Problem (Chapter~19), no program can find an induction proof for every program loop: the task is \emph{undecidable}, meaning no algorithm solves it correctly in all cases.
\end{historybox}

\subsection{The Minimal Counterexample: Dominoes in Reverse}

Induction is easiest to understand through the \textbf{Well-Ordering Principle (WOP)} from Chapter~18:
\begin{quote}
\emph{Every non-empty subset of positive integers contains a smallest element.}
\end{quote}
No matter how complicated the rule defining the subset is, if at least one positive integer satisfies it, there is a first positive integer that satisfies it.

This gives a proof strategy called the \textbf{method of minimal counterexample}.

Consider a sequence of statements $P(1), P(2), P(3), \dots$. Standard induction proves the base case $P(1)$ and shows that $P(k)$ implies $P(k+1)$, so the property passes from each integer to the next.

The minimal counterexample method argues by contradiction instead. Suppose the claim fails for at least one positive integer. Then the set $S$ of counterexamples (the integers $n$ for which $P(n)$ is false) is non-empty. By the Well-Ordering Principle, $S$ has a smallest element: a \emph{first} integer where the claim fails. Call it $m = \min(S)$. Figure~\ref{34:fig-minimal-counterexample} shows the situation.

First, we check the base case $P(1)$ directly. That rules out $m = 1$, so $m \ge 2$ and $m - 1$ is a genuine positive integer. Because $m$ is the minimal failure, every integer strictly before it satisfies the property: $P(1), P(2), \dots, P(m-1)$ are all true.

We then use the truth of those preceding cases to deduce that $P(m)$ holds after all. This contradicts the choice of $m$ as a counterexample. Consequently, no counterexample exists, and the claim holds for all positive integers.

\begin{walkbox}
\textbf{Mental Check:} Why does the minimal counterexample method fail if you try to apply it to a claim about the set of all integers $\Z$ or the positive rational numbers $\Q^+$?
\\[0.3em]
\emph{Answer:} Neither $(\Z, <)$ nor $(\Q^+, <)$ satisfies the Well-Ordering Principle. In $\Z$, the subset of all negative integers has no minimum element; you can walk leftward toward $-\infty$ forever. In $\Q^+$, the subset $\{1, 1/2, 1/4, 1/8, \dots\}$ gets arbitrarily close to $0$, but has no minimum element inside the set. Without a guaranteed earliest failure $m = \min(S)$, the minimal counterexample strategy cannot even begin.
\end{walkbox}

\subsection{Subtle Induction Traps: Missing Overlaps and Infinite Descent}

Induction proofs go wrong when the inductive step is not checked for every case, or when the set being worked on has no starting point:

\begin{itemize}
  \item \textbf{P\'olya's Horse Paradox}: George P\'olya showed how a flawed inductive step can ``prove'' that all horses are the same color. Let $P(n)$ be the claim that in any set of $n$ horses, all have the same color. The base case $n=1$ holds immediately: in any single-horse set, every horse has the same color. In the induction step, assume $P(k)$ holds and consider $k+1$ horses. Remove horse $1$; the remaining $k$ horses share a color. Reinsert horse $1$ and remove horse $k+1$; those $k$ horses share a color. If $k \ge 2$, these two subsets overlap, forcing all $k+1$ horses to share the same color. The error occurs when transitioning from $k=1$ to $k=2$: the subsets $\{1\}$ and $\{2\}$ have no common element, so the induction step does not hold for $k=1$ (Figure~\ref{34:fig-horses}). An induction step that fails for even a single early value invalidates the proof.
\end{itemize}

\begin{itemize}
  \item \textbf{The Infinite Descending Chain Trap}: Ordinary induction works on $\N$ because $\N$ has a least element ($1$) and every strictly decreasing sequence of positive integers, such as $10 > 7 > 3 > 1$, must stop after finitely many steps. An ordered set (more generally, a partially ordered set from Chapter~16) is called \emph{well-founded} if every non-empty subset has a minimal element, or equivalently, if it contains no infinite strictly decreasing sequence
  \[
  x_0 > x_1 > x_2 > \cdots.
  \]
  The integers $\Z$ and the positive rationals $\Q^+$ are not well-founded under their usual order: $\Z$ contains the endless descent $-1 > -2 > -3 > \cdots$, and $\Q^+$ contains $1 > \tfrac12 > \tfrac14 > \cdots$, which approaches $0$ but never stops. On such a set a minimal counterexample need not exist, and there is no bottom case from which an induction can start. Figure~\ref{34:fig-descending-chains} compares the three sets.
\end{itemize}

\subsection{Structural Induction: Beyond Flat Numbers}

In computer science, logic, and algebra, many objects are defined recursively, by rules for building bigger objects from smaller ones, rather than by a position $1, 2, 3, \dots$ in a list. Examples include arithmetic expressions, the syntax trees a compiler builds from source code, propositional formulas, and graphs (networks of points joined by lines).

Consider arithmetic expressions formed from numbers, variables, and the two \emph{binary operations} $+$ and $\times$ (operations that combine two inputs into one output):
\begin{itemize}
  \item \textbf{Base Cases (Leaves)}: Any numeric constant $c$ or variable $x$ is a valid expression.
  \item \textbf{Recursive Rule (Internal Nodes)}: If $E_1$ and $E_2$ are valid expressions, then $(E_1 + E_2)$ and $(E_1 \times E_2)$ are valid expressions.
  \item \textbf{Extremal Clause}: Nothing else is an expression unless constructed through these rules.
\end{itemize}
Each expression can be drawn as a syntax tree: the constants and variables are the leaves at the bottom, and each use of the recursive rule adds an \emph{internal node} (a node that is not a leaf) whose two branches are $E_1$ and $E_2$. Figure~\ref{34:fig-expression-tree} shows the tree for $2 \times (x + 5)$.

    $\bullet$ Deduce $P$ for $(x + 5)$.\\
    $\bullet$ Deduce $P$ for $2 \times (x + 5)$.
  };
\end{tikzpicture}
\caption{Structural induction on the syntax tree for $2 \times (x + 5)$. The property $P$ is checked directly at the leaves (constants and variables). Each internal node then inherits $P$ from its two subtrees, so $P$ moves up the arrows to the root. No numbering of the expressions is needed.}
\label{34:fig-expression-tree}
\end{figure}

To prove a property $P(E)$ holds for \emph{all possible} expressions $E$:
\begin{enumerate}
  \item \textbf{Base Step}: Show the property holds for every leaf (every constant $c$ and variable $x$).
  \item \textbf{Inductive Step}: Assume the property holds for arbitrary sub-expressions $E_1$ and $E_2$ (these assumptions are the induction hypotheses). Prove that the combined expression $(E_1 \star E_2)$ also has the property, where $\star$ stands for either operation $+$ or $\times$.
\end{enumerate}

No numerical index is required. Every expression is built from leaves by finitely many uses of the recursive rule, and each use passes the property up one level, so the property reaches every expression.

\begin{walkbox}
\textbf{Mental Check:} In the expression tree for $2 \times (x + 5)$, what exact assumption constitutes the inductive hypothesis when proving that the root operator $\times$ satisfies the desired property?
\\[0.3em]
\emph{Answer:} The inductive hypothesis assumes the property has already been established for the left subtree (the leaf $2$) and the right subtree (the sub-expression $(x+5)$). You do not assume the property holds for the combined expression; your task is to show that combining two valid subtrees through the multiplication operator preserves the guarantee.
\end{walkbox}

\subsection{Worked Example: The Fundamental Theorem of Arithmetic}

The Fundamental Theorem of Arithmetic states that every integer $n \ge 2$ can be factored into prime numbers, and that this factorization is unique up to the order of factors (for example, $12 = 2 \cdot 2 \cdot 3 = 3 \cdot 2 \cdot 2$ count as the same factorization). Chapter~18 proved the \emph{existence} part with strong induction; here we prove it again with the minimal counterexample method.

\begin{theorem}[Existence of Prime Factorizations]
Every integer $n \ge 2$ can be factored into a product of one or more prime numbers.
\end{theorem}

\begin{proof}
Suppose, for contradiction, that there exist integers $n \geq 2$ that cannot be factored into primes. Let $S$ be the set of all such failing integers:
\[
S = \{n \in \Z : n \ge 2 \text{ and } n \text{ has no prime factorization}\}.
\]
By our contradictory assumption, $S$ is non-empty. Because $S$ is a non-empty subset of the positive integers, the Well-Ordering Principle guarantees that $S$ contains a smallest element:
\[
m = \min(S).
\]
Could $m$ be a prime number? No. If $m$ were prime, it would already be a product of a single prime ($m$ itself), which would mean $m \notin S$.

Therefore, $m$ must be composite. By definition of a composite integer, $m$ factors into two strictly smaller positive integers:
\[
m = a \cdot b, \qquad \text{with } 1 < a < m \quad \text{and} \quad 1 < b < m.
\]
Because both $a$ and $b$ are strictly smaller than $m$, and $m$ was chosen to be the \emph{smallest} member of $S$, neither $a$ nor $b$ can belong to $S$.

Consequently, both $a$ and $b$ must have valid prime factorizations:
\[
a = p_1 p_2 \cdots p_j, \qquad b = q_1 q_2 \cdots q_k,
\]
where each $p_i$ and $q_i$ is prime. Multiplying these factorizations together gives:
\[
m = a \cdot b = (p_1 p_2 \cdots p_j)(q_1 q_2 \cdots q_k).
\]
This displays $m$ as a product of primes, which contradicts $m \in S$.

Because assuming $S$ was non-empty led to a direct contradiction, $S$ must be empty. Every integer $n \geq 2$ can be factored into primes.
\end{proof}

Figure~\ref{34:fig-prime-factorization-wop} lays out this proof on the number line: everything from $2$ to $m-1$ factors into primes, and $m$ splits into two factors $a$ and $b$ that lie in that range.

\begin{intuitionbox}
\textbf{Minimal Counterexample Versus Standard Induction:}
Proving this theorem with standard induction ($k \implies k+1$) is difficult because the factorization of $k$ gives no information about the factorization of $k+1$ (for instance, knowing $14 = 2 \cdot 7$ does not determine the factors of $15 = 3 \cdot 5$).

That is why Chapter~18 used strong induction, assuming every integer from $2$ up to $k$ factors into primes. The minimal counterexample method contains the same logic in a shorter form: once $m = \min(S)$ is chosen, every smaller integer, including $a$ and $b$, is automatically known to factor. Figure~\ref{34:fig-strong-vs-ordinary} shows the difference for $15$.
\end{intuitionbox}

\subsection{What Generalized Induction Is Used For---and Its Limits}

Induction reaches well beyond arithmetic formulas:
\begin{enumerate}
  \item \textbf{Software Verification and Compilers}: Structural induction over syntax trees proves that a compiler's output does the same thing as the source program, and that a type checker (the part of a compiler that rejects code using a value of the wrong type, Chapter~25) rules out certain kinds of crash. Induction on the size of the input proves that recursive algorithms, such as tree traversals or the sorting method quicksort, terminate (stop after finitely many steps).
  \item \textbf{Minimal Counterexample Proofs}: The Well-Ordering Principle proves many theorems in discrete mathematics by looking at the smallest failing case directly. Examples are the Division Algorithm (Exercise~4) and results in graph theory, such as bounds on how many colors are needed to color the points of a network so that joined points get different colors.
  \item \textbf{Transfinite Reasoning}: In set theory, transfinite induction runs along the \emph{ordinal numbers}, which continue the counting numbers past infinity ($1, 2, 3, \dots$, then a first infinite ordinal $\omega$, then $\omega + 1$, and so on; see Figure~\ref{34:fig-ordinals}). Usually packaged as Zorn's Lemma, a consequence of the Axiom of Choice, it proves that certain objects exist even though they cannot be built in finitely many steps. Examples from algebra are the algebraic closure of a field (Chapter~24; a larger number system in which every non-constant polynomial equation has a solution) and maximal ideals in rings (ideals that are as large as possible without being the whole ring).
\end{enumerate}

\paragraph{Scope and Limitations.}
Induction has definite theoretical and practical boundaries:
\begin{itemize}
  \item \textbf{The Continuum Barrier}: The Axiom of Choice guarantees that the real numbers can be well-ordered, but the proof is non-constructive: nobody can write down such an ordering. With the usual order you cannot step from one real number to the next, because there is no next real number: between any two distinct reals lies another real number. So induction cannot prove statements about functions on $\R$ by stepping along the line.
  \item \textbf{Cyclic and Continuous Settings}: Induction requires a well-founded order, with no cycles and no infinite descending paths. For infinite data streams, networks that contain cycles, or differential equations, ordinary induction does not apply directly. These settings need other tools, such as \emph{coinduction} (a method for reasoning about infinite objects, like endless streams, by what can be observed of them one step at a time) or topological \emph{compactness} (a property of sets such as $[0,1]$ that lets you replace any covering by infinitely many open intervals with a covering by finitely many of them).
\end{itemize}

\subsection{Exercises}

\begin{enumerate}
  \item \textbf{Warm-up and Fallacy Audits}:
  \begin{enumerate}
    \item A student claims to prove $P(n)$ for all integers $n \ge 1$ by showing that $P(1)$ is true and that whenever $P(k)$ is true, $P(k+2)$ is true. Which integers have been proven to satisfy $P$? What minimal additional work would prove the claim for all $n \ge 1$?
    \item Which of the following subsets of $\R$ have a smallest element? Explain using the Well-Ordering Principle or the concept of well-foundedness.
    \begin{align*}
    A &= \{x \in \Q : x > 0\}, \\
    B &= \left\{n - \frac{1}{m} : n, m \in \Z^+\right\}, \\
    C &= \{n^2 - 10n + 30 : n \in \Z^+\}.
    \end{align*}
    \item In P\'olya's horse paradox, for a set of $n=2$ horses $\{H_1, H_2\}$, write down explicitly the two subsets of size $n-1 = 1$, and compute their intersection. Why does this calculation show why the proof fails?
  \end{enumerate}

  \item \textbf{Full Binary Trees via Structural Induction}:
  A full binary tree is a tree in which every node either is a \emph{leaf} (has no children) or is an \emph{internal node} with exactly two children. It is defined recursively as follows:
  \begin{itemize}
    \item \emph{Base Case}: A single leaf node is a full binary tree with $L=1$ leaf and $I=0$ internal nodes.
    \item \emph{Recursive Step}: If $T_1$ and $T_2$ are full binary trees, joining them under a new root node creates a new full binary tree $T$ whose leaf set is the union of the leaves of $T_1$ and $T_2$, and whose internal nodes consist of the internal nodes of $T_1$ and $T_2$ plus the new root.
  \end{itemize}
  Figure~\ref{34:fig-full-binary-tree} shows both rules and one tree they build.

  \item \textbf{Parenthesis Balancing in Propositional Logic}:
  Let $\mathcal{F}$ be the set of propositional formulas generated from variable symbols $\{p, q, r, \dots\}$ by the following grammar:
  \begin{itemize}
    \item Any variable symbol $p$ is in $\mathcal{F}$.
    \item If $A \in \mathcal{F}$, then $(\neg A) \in \mathcal{F}$.
    \item If $A, B \in \mathcal{F}$, then $(A \land B) \in \mathcal{F}$ and $(A \lor B) \in \mathcal{F}$.
  \end{itemize}
  Use structural induction to prove that for every formula $F \in \mathcal{F}$, the number of left parentheses in $F$ equals the number of right parentheses in $F$.

  \item \textbf{The Division Algorithm via Minimal Counterexample}:
  Let $a$ and $b$ be integers with $b > 0$. We wish to prove that there exist integers $q$ and $r$ such that
  \[
  a = bq + r \quad \text{with} \quad 0 \le r < b.
  \]
  \begin{enumerate}
    \item Define the set of non-negative differences:
    \[
    S = \{a - bq : q \in \Z \text{ and } a - bq \ge 0\}.
    \]
    Show that $S$ is non-empty. (Hint: consider $q = -|a|$.)
    \item By the Well-Ordering Principle, let $r = \min(S)$, and let $q \in \Z$ be the quotient such that $r = a - bq$. Prove by contradiction that $r < b$. (Hint: if $r \ge b$, consider $r - b = a - b(q+1)$.)
  \end{enumerate}

  \item \textbf{Irrationality of $\sqrt{2}$ via Minimal Counterexample}:
  Suppose for contradiction that $\sqrt{2}$ is rational, so $\sqrt{2} = a/b$ for positive integers $a, b$.
  \begin{enumerate}
    \item Define the set $S = \{k \in \Z^+ : k\sqrt{2} \in \Z^+\}$. Show that $S$ is non-empty.
    \item Since $S$ is a non-empty subset of $\Z^+$, the Well-Ordering Principle guarantees a minimum $m = \min(S)$.
    \item Define $m' = m(\sqrt{2} - 1)$. Show that $m'$ is an integer, that $m' > 0$, and that $m'\sqrt{2} \in \Z^+$, so $m' \in S$.
    \item Show that $m' < m$, producing a direct contradiction with $m = \min(S)$.
  \end{enumerate}

  \item \textbf{Tournaments and Hamiltonian Paths}:
  A round-robin tournament among $n \ge 2$ players is a directed graph (a set of points joined by arrows) whose points are the players and in which every pair of distinct players $u, v$ has exactly one arrow between them (either $u \to v$, meaning $u$ defeated $v$, or $v \to u$, meaning $v$ defeated $u$).
  \begin{enumerate}
    \item A \emph{Hamiltonian path} is a listing of all $n$ players in some order $p_1, p_2, \dots, p_n$ in which each player beat the next one:
    \[
    p_1 \to p_2 \to \cdots \to p_n, \qquad \text{that is, } p_i \to p_{i+1} \text{ for } 1 \le i \le n-1.
    \]
    Verify that every $2$-player tournament has a Hamiltonian path.
    \item Assume that every tournament on $k$ players has a Hamiltonian path
    \[
    p_1 \to p_2 \to \cdots \to p_k.
    \]
    Add a new player $v$. If $v$ beats $p_1$, where can you insert $v$? If $p_k$ beats $v$, where can you insert $v$?
    \item If neither of those occurs, show that there must be an index $i$ such that $p_i \to v$ and $v \to p_{i+1}$. Deduce that every tournament on $n$ players has a Hamiltonian path.
  \end{enumerate}
\end{enumerate}
