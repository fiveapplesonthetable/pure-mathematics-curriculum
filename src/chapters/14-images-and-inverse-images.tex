\section{Images and Inverse Images}
\chapterline

Up to this point, we have considered functions acting on individual points: given an input $x$, we evaluate the output $f(x)$. 

Functions also act on whole subsets of their domain and codomain. A function $f: X \to Y$ gives two operations between subsets of $X$ and subsets of $Y$:
\begin{itemize}
\item \textbf{Image (pushing forward):} Given a subset $S \subseteq X$, collect all outputs $f(s)$ in $Y$.
\item \textbf{Inverse image, or preimage (pulling back):} Given a subset $T \subseteq Y$, collect all points in $X$ whose outputs belong to $T$.
\end{itemize}

You might expect pushing forward and pulling back to behave the same way. They do not. Say an operation \emph{preserves} intersections if applying it to $A \cap B$ gives the same result as applying it to $A$ and to $B$ separately and then intersecting; preserving unions and complements means the same with $\cup$ or complements in place of $\cap$. Preimages preserve unions, intersections, and complements. Forward images preserve unions, but can fail on intersections when two different inputs collide (have the same output), and can fail on complements when a function merges inputs or misses points of its codomain.

\begin{historybox}
This difference between images and preimages was studied in the early twentieth century by Felix Hausdorff (\emph{Grundz\"uge der Mengenlehre}, ``Foundations of Set Theory'', 1914) alongside Maurice Fr\'echet, Kazimierz Kuratowski, and Henri Lebesgue. 

These mathematicians wanted to extend calculus beyond ordinary space with coordinates ($\R^n$, the set of lists of $n$ real numbers). In a space with no coordinates or distances, how do you say that a function is continuous (has no jumps), or that a set can be assigned a size such as a length or an area?

The first instinct was to push sets forward: if $U$ is an open set (a set with no edge points, defined later in this chapter), should $f(U)$ be open? That fails even for simple functions. Hausdorff saw that the useful structure flows backward: the preimage operation $f^{-1}$ preserves unions, intersections, and complements without exception. This made the preimage a standard tool in topology (the study of shapes up to stretching, previewed in Chapter~22) and in measure theory (the theory of lengths, areas, and probabilities).
\end{historybox}

\subsection{Formal Definitions}

\begin{definition}[Forward Image]
Let $f: X \to Y$ be a function and let $S \subseteq X$. The \textbf{image} of $S$ under $f$ is
\[
f(S) = \{f(s) \in Y : s \in S\} = \{y \in Y : (\exists s \in S)(f(s) = y)\}.
\]
\end{definition}

\begin{definition}[Inverse Image / Preimage]
Let $f: X \to Y$ be a function and let $T \subseteq Y$. The \textbf{inverse image} (or \textbf{preimage}) of $T$ under $f$ is
\[
f^{-1}(T) = \{x \in X : f(x) \in T\}.
\]
\end{definition}

In words: $f(S)$ is the set of outputs you get by feeding in the elements of $S$, and $f^{-1}(T)$ is the set of inputs whose output lands in $T$.

For a quick finite example, let $f: \{1, 2, 3\} \to \{a, b\}$ send $f(1) = a$, $f(2) = a$, and $f(3) = b$. Pushing $\{1\}$ forward gives $f(\{1\}) = \{a\}$, whereas pulling $\{a\}$ back collects every input that lands on $a$: $f^{-1}(\{a\}) = \{1, 2\}$. Figure~\ref{fig:img-finite-example} shows both. In general, for a single output $y \in Y$, the preimage $f^{-1}(\{y\}) = \{x \in X : f(x) = y\}$ of its singleton is called the \textbf{fiber} of $f$ over $y$: the set of all inputs that land on $y$.

\subsection{Why Preimages Preserve Set Operations}

Deciding whether $x \in f^{-1}(T)$ comes down to one question about one output: does $f(x)$ land inside $T$?

Because $f$ is a function, every element $x$ has exactly one output $f(x)$. That single point $f(x)$ either belongs to an intersection, union, or complement, or it does not.

\begin{theorem}[Preimages Distribute Over Intersections]
Let $f: X \to Y$ be a function and let $T_1, T_2 \subseteq Y$. Then
\[
f^{-1}(T_1 \cap T_2) = f^{-1}(T_1) \cap f^{-1}(T_2).
\]
\end{theorem}

\begin{proof}
Let $x \in X$ be arbitrary. We follow a chain of ``if and only if'' steps:
\begin{align*}
x \in f^{-1}(T_1 \cap T_2) 
&\iff f(x) \in T_1 \cap T_2 && \text{(definition of preimage)} \\
&\iff f(x) \in T_1 \text{ and } f(x) \in T_2 && \text{(definition of intersection)} \\
&\iff x \in f^{-1}(T_1) \text{ and } x \in f^{-1}(T_2) && \text{(definition of preimage)} \\
&\iff x \in f^{-1}(T_1) \cap f^{-1}(T_2) && \text{(definition of intersection)}.
\end{align*}
Since each step is an equivalence, the two sets contain identical elements:
\[
f^{-1}(T_1 \cap T_2) = f^{-1}(T_1) \cap f^{-1}(T_2). \qedhere
\]
\end{proof}

The same reasoning applies to complements and unions:

\begin{theorem}[Preimages Preserve Complements]
Let $f: X \to Y$ be a function and let $T \subseteq Y$. Then
\[
f^{-1}(Y \setminus T) = X \setminus f^{-1}(T).
\]
\end{theorem}

\begin{proof}
Let $x \in X$ be arbitrary. We trace the equivalences:
\begin{align*}
x \in f^{-1}(Y \setminus T) 
&\iff f(x) \in Y \setminus T && \text{(definition of preimage)} \\
&\iff f(x) \notin T && \text{(definition of set difference, since } f(x) \in Y \text{)} \\
&\iff \neg (f(x) \in T) && \text{(meaning of } \notin \text{)} \\
&\iff \neg (x \in f^{-1}(T)) && \text{(definition of preimage)} \\
&\iff x \notin f^{-1}(T) && \text{(meaning of } \notin \text{)} \\
&\iff x \in X \setminus f^{-1}(T) && \text{(since } x \in X \text{)}.
\end{align*}
Because every step is an equivalence, the two sets are identical.
\end{proof}

This property also holds for infinitely many sets at once. Recall from Chapter~11 that an indexed family $\{T_\alpha\}_{\alpha \in I}$ is a collection with one set $T_\alpha$ for each label $\alpha$ in an index set $I$. If $\{T_\alpha\}_{\alpha \in I}$ is any family of subsets of $Y$, indexed by any set $I$:
\[
\begin{aligned}
f^{-1}\Bigl(\bigcup_{\alpha \in I} T_\alpha\Bigr) &= \bigcup_{\alpha \in I} f^{-1}(T_\alpha), \\
f^{-1}\Bigl(\bigcap_{\alpha \in I} T_\alpha\Bigr) &= \bigcap_{\alpha \in I} f^{-1}(T_\alpha).
\end{aligned}
\]
Algebraists have a name for a map that preserves the operations of a system: a \textbf{homomorphism} (Greek for ``same shape''). Subsets with union, intersection, and complement form a system called a \textbf{Boolean algebra}, after George Boole, so the preimage operation is called a \textbf{Boolean algebra homomorphism}.

\subsection{Where Forward Images Break Down}

Pushing sets forward through $f$ behaves differently.

\begin{theorem}
Let $f: X \to Y$ and let $S_1, S_2 \subseteq X$. Then
\[
f(S_1 \cap S_2) \subseteq f(S_1) \cap f(S_2).
\]
\end{theorem}

\begin{proof}
Let $y \in f(S_1 \cap S_2)$ be arbitrary. By definition of the forward image, there exists some $x \in S_1 \cap S_2$ such that $f(x) = y$.

Since $x \in S_1 \cap S_2$, we know that $x \in S_1$ and $x \in S_2$.
\begin{itemize}
\item Because $x \in S_1$ and $f(x) = y$, we have $y \in f(S_1)$.
\item Because $x \in S_2$ and $f(x) = y$, we have $y \in f(S_2)$.
\end{itemize}
Thus $y \in f(S_1) \cap f(S_2)$. Hence $f(S_1 \cap S_2) \subseteq f(S_1) \cap f(S_2)$.
\end{proof}

\emph{Why does the reverse inclusion fail?} 
Suppose $y \in f(S_1) \cap f(S_2)$. This means $y \in f(S_1)$ and $y \in f(S_2)$.
Therefore, there exists some $x_1 \in S_1$ with $f(x_1) = y$, and there exists some $x_2 \in S_2$ with $f(x_2) = y$.
\emph{Does this guarantee $x_1 = x_2$?}

No. If $f$ is not injective, $x_1$ and $x_2$ can be two distinct inputs that have the same output $y$. If $x_1 \neq x_2$, neither input needs to belong to the intersection $S_1 \cap S_2$. As a result, $f(S_1 \cap S_2)$ can be empty even though $f(S_1) \cap f(S_2)$ is non-empty.

\begin{example}[A Counterexample]
Let $f: \R \to \R$ be $f(x) = x^2$.
Take the disjoint subsets $S_1 = \{-2\}$ and $S_2 = \{2\}$.
Their intersection is empty: $S_1 \cap S_2 = \emptyset$, so
\[
f(S_1 \cap S_2) = f(\emptyset) = \emptyset.
\]
However, when we compute the images separately, we obtain
\[
f(S_1) = \{4\} \quad \text{and} \quad f(S_2) = \{4\}, \quad \text{so} \quad f(S_1) \cap f(S_2) = \{4\}.
\]
Here $\emptyset \subsetneq \{4\}$, where $A \subsetneq B$ means $A \subseteq B$ but $A \neq B$. The equality fails because $-2$ and $2$ both map to $4$ under the squaring map.
\end{example}

What property ensures that forward images preserve intersections? We need distinct inputs to produce distinct outputs. That property is injectivity, from Chapter~13.

\begin{theorem}[Injectivity Characterizes Intersection Preservation]
Let $f: X \to Y$ be a function. Then
\[
f(S_1 \cap S_2) = f(S_1) \cap f(S_2) \quad \text{for all subsets } S_1, S_2 \subseteq X
\]
if and only if $f$ is injective.
\end{theorem}

\begin{proof}
This is an ``if and only if'' claim, so we prove both directions separately.

($\implies$) Assume that $f$ preserves intersections for all pairs of subsets. We must show $f$ is injective. We prove injectivity in its contrapositive form ($a \neq b \implies f(a) \neq f(b)$): suppose $a, b \in X$ with $a \neq b$. 

Consider the disjoint singletons $S_1 = \{a\}$ and $S_2 = \{b\}$. Since $a \neq b$, we have $S_1 \cap S_2 = \emptyset$, so
\[
f(S_1 \cap S_2) = f(\emptyset) = \emptyset.
\]
By our assumption, $f(S_1) \cap f(S_2) = f(S_1 \cap S_2) = \emptyset$. But direct evaluation gives
\[
f(S_1) = \{f(a)\} \quad \text{and} \quad f(S_2) = \{f(b)\}.
\]
Since their intersection is empty, $\{f(a)\} \cap \{f(b)\} = \emptyset$, which forces $f(a) \neq f(b)$. Hence $f$ is injective.

($\impliedby$) Assume that $f$ is injective. We already know that $f(S_1 \cap S_2) \subseteq f(S_1) \cap f(S_2)$ holds for any function. It remains to prove the reverse inclusion: $f(S_1) \cap f(S_2) \subseteq f(S_1 \cap S_2)$.

Let $y \in f(S_1) \cap f(S_2)$. Then $y \in f(S_1)$ and $y \in f(S_2)$.
By definition of forward image, there exists some $x_1 \in S_1$ with $f(x_1) = y$, and some $x_2 \in S_2$ with $f(x_2) = y$.
Since $f(x_1) = y = f(x_2)$ and $f$ is injective, we must have $x_1 = x_2$.
Call this shared input $x$. Because $x \in S_1$ and $x \in S_2$, we have $x \in S_1 \cap S_2$.
Therefore, $y = f(x) \in f(S_1 \cap S_2)$.
This establishes that $f(S_1) \cap f(S_2) \subseteq f(S_1 \cap S_2)$, completing the equality.
\end{proof}

\begin{theorem}[Forward Images Distribute Over Unions]
Let $f: X \to Y$ and let $S_1, S_2 \subseteq X$. Then
\[
f(S_1 \cup S_2) = f(S_1) \cup f(S_2).
\]
\end{theorem}

\begin{proof}
Let $y \in Y$ be arbitrary. We trace its membership step by step:
\begin{align*}
y \in f(S_1 \cup S_2)
&\iff (\exists x \in S_1 \cup S_2)\bigl(f(x) = y\bigr) && \text{(definition of image)} \\
&\iff (\exists x \in X)\bigl((x \in S_1 \lor x \in S_2) \land f(x) = y\bigr) && \text{(definition of union)} \\
&\iff (\exists x \in X)\bigl((x \in S_1 \land f(x) = y) \\
&\qquad\qquad\qquad \lor (x \in S_2 \land f(x) = y)\bigr) && \text{(distributive law)} \\
&\iff (\exists x \in S_1)\bigl(f(x) = y\bigr) \lor (\exists x \in S_2)\bigl(f(x) = y\bigr) && \text{(split the $\exists$)} \\
&\iff y \in f(S_1) \lor y \in f(S_2) && \text{(definition of image)} \\
&\iff y \in f(S_1) \cup f(S_2) && \text{(definition of union)}. \qedhere
\end{align*}
\end{proof}

Why do forward images preserve unions but not intersections? The answer comes from the quantifier logic of Chapter~4: the existential quantifier $\exists$ distributes across ``or'' ($\lor$), but only partly across ``and'' ($\land$). Fix an output $y$, and write $P(x)$ for the statement ``$x \in S_1$ and $f(x) = y$'' and $Q(x)$ for ``$x \in S_2$ and $f(x) = y$''. Then
\begin{align*}
(\exists x)\bigl(P(x) \lor Q(x)\bigr) &\iff (\exists x)P(x) \lor (\exists x)Q(x), \\
(\exists x)\bigl(P(x) \land Q(x)\bigr) &\implies (\exists x)P(x) \land (\exists x)Q(x) && \text{(this direction only)}.
\end{align*}
The first line says $y \in f(S_1 \cup S_2) \iff y \in f(S_1) \cup f(S_2)$: to belong to the image of a union, $y$ needs to come from at least one source set. In the second line, the left side says $y \in f(S_1 \cap S_2)$: a single input must belong to both source sets at once. The right side says $y \in f(S_1) \cap f(S_2)$, which only requires two separate inputs $x_1 \in S_1$ and $x_2 \in S_2$ that happen to share the output $y$.

\subsection{Round Trips: Pushing Forward and Pulling Backward}

What happens when you combine both operations in sequence? If you take a set $S \subseteq X$, push it forward to $f(S)$, and then pull it back to $f^{-1}(f(S))$, do you return to exactly the set $S$ you started with? 

Not always. Take $f(x) = x^2$ on $\R$ and start in the domain with $S = [0, 2]$:
\[
S = [0, 2] \;\xrightarrow{\ \text{push forward}\ }\; f(S) = [0, 4] \;\xrightarrow{\ \text{pull back}\ }\; f^{-1}(f(S)) = [-2, 2].
\]
The round trip picks up the negative numbers $[-2, 0)$, which have the same squares as numbers in $S$. Start instead in the codomain with $T = [-1, 4]$:
\[
T = [-1, 4] \;\xrightarrow{\ \text{pull back}\ }\; f^{-1}(T) = [-2, 2] \;\xrightarrow{\ \text{push forward}\ }\; f(f^{-1}(T)) = [0, 4].
\]
This round trip loses $[-1, 0)$, because no real number squares to a negative number. Figure~\ref{fig:img-roundtrip-intervals} draws both trips on number lines. In general, the domain round trip can only add points and the codomain round trip can only lose points.

\begin{theorem}[The Domain Round Trip]
Let $f: X \to Y$ and let $S \subseteq X$. Then
\[
S \subseteq f^{-1}(f(S)).
\]
Equality holds for all subsets $S \subseteq X$ if and only if $f$ is injective.
\end{theorem}

\begin{proof}
Let $x \in S$. Then its output $f(x)$ belongs to $f(S)$ by definition of the forward image. By definition of the preimage, any point whose output lands in $f(S)$ belongs to $f^{-1}(f(S))$. Thus $x \in f^{-1}(f(S))$, proving $S \subseteq f^{-1}(f(S))$.

Now consider when equality holds.
If $f$ is injective and $x \in f^{-1}(f(S))$, then $f(x) \in f(S)$, so $f(x) = f(s)$ for some $s \in S$. Since $f$ is injective, $x = s$, which means $x \in S$. Thus $f^{-1}(f(S)) \subseteq S$, giving equality.

Conversely, suppose $f^{-1}(f(S)) = S$ holds for all $S \subseteq X$. If $f(a) = f(b)$, set $S = \{a\}$. Then $f(S) = \{f(a)\}$. Since $f(b) = f(a)$, the element $b$ satisfies $f(b) \in f(S)$, so $b \in f^{-1}(f(S)) = \{a\}$. Therefore $b = a$, proving $f$ is injective.
\end{proof}

\begin{theorem}[The Codomain Round Trip]
Let $f: X \to Y$ and let $T \subseteq Y$. Then
\[
f(f^{-1}(T)) \subseteq T.
\]
Equality holds for all subsets $T \subseteq Y$ if and only if $f$ is surjective.
\end{theorem}

\begin{proof}
Let $y \in f(f^{-1}(T))$. Then $y = f(x)$ for some $x \in f^{-1}(T)$. By definition of the preimage, $x \in f^{-1}(T)$ means $f(x) \in T$. Since $y = f(x)$, we have $y \in T$. Thus $f(f^{-1}(T)) \subseteq T$.

Now consider when equality holds.
If $f$ is surjective, let $y \in T$. Because $f$ is surjective, there exists some $x \in X$ with $f(x) = y \in T$. Thus $x \in f^{-1}(T)$, so $y = f(x) \in f(f^{-1}(T))$, giving $T \subseteq f(f^{-1}(T))$ and hence equality.

Conversely, suppose $f(f^{-1}(T)) = T$ holds for all $T \subseteq Y$. In particular, choose $T = \{y\}$ for any $y \in Y$. Then $f(f^{-1}(\{y\})) = \{y\}$. The set $f(f^{-1}(\{y\}))$ cannot be empty, so $f^{-1}(\{y\})$ is non-empty. This means there is at least one $x \in X$ with $f(x) = y$, proving $f$ is surjective.
\end{proof}

\subsection{Connection to Topology: Continuity via Preimages}

On the real line, an \textbf{open set} is a set in which every point has some room around it in both directions that stays inside the set. An open interval $(a, b)$ is open; the interval $[0, 1)$ is not, because the endpoint $0$ belongs to it but every small step to the left of $0$ leaves it. (In more general spaces, which sets count as open is part of the description of the space.) Because preimages behave so well, topology defines \emph{continuous functions} through them:
\begin{center}
\emph{A function $f: X \to Y$ is continuous if for every open set $V \subseteq Y$, the preimage $f^{-1}(V)$ is open in $X$.}
\end{center}

If topologists had tried to define continuity using forward images (demanding that $f(U)$ be open whenever $U$ is open), familiar functions with no jumps would fail:
\begin{itemize}
\item The parabola $f(x) = x^2$ maps the open interval $(-1, 1)$ to $[0, 1)$, which contains its endpoint $0$ and so is not open.
\item The constant function $f(x) = 5$ maps $\R$ to the single point $\{5\}$, which is not open in $\R$.
\end{itemize}
Preimages avoid this problem: if $f(x)$ sits inside an open set $V$, continuity ensures that inputs near $x$ still map into $V$, so those nearby inputs stay inside $f^{-1}(V)$ and $f^{-1}(V)$ is open.

The preimage definition also catches jumps. Let $g(x) = x$ for $x < 1$ and $g(x) = x + 1$ for $x \ge 1$, so the graph jumps from height $1$ up to height $2$ at $x = 1$. The interval $V = (1.5, 3)$ is open, but
\[
g^{-1}(V) = [1, 2),
\]
which contains its endpoint $1$ and so is not open. Inputs just left of $1$ have outputs near $1$, outside $V$, even though $g(1) = 2$ lies in $V$. Figure~\ref{fig:img-continuity} shows both pictures.

\subsection{The Limits of Set Transport and Where We Go Next}

Preimages appear throughout mathematics. Two examples:
\begin{itemize}
\item \textbf{Probability:} A random variable is a function $X$ that assigns a number to each possible outcome of an experiment; the set of all outcomes is written $\Omega$, so $X: \Omega \to \R$. The probability that the value of $X$ lands in a set of numbers $E \subseteq \R$ is the probability of the set of outcomes that $X$ sends into $E$, which is the preimage:
\[
\mathbb{P}(X \in E) = \mathbb{P}\bigl(X^{-1}(E)\bigr).
\]
Here $\mathbb{P}$ stands for ``the probability of''. For example, toss a fair coin twice, so $\Omega = \{HH, HT, TH, TT\}$ with each outcome having probability $\tfrac14$, and let $X$ count the heads. Then $X^{-1}(\{1\}) = \{HT, TH\}$, so $\mathbb{P}(X = 1) = \tfrac24 = \tfrac12$ (Figure~\ref{fig:img-random-variable}).
\item \textbf{Pulling back through two functions:} Recall that $g \circ f$ means ``apply $f$, then apply $g$''. For $f: X \to Y$, $g: Y \to Z$ and $W \subseteq Z$, an element $x \in X$ satisfies $(g \circ f)(x) \in W$ if and only if $f(x) \in g^{-1}(W)$, so
\[
(g \circ f)^{-1}(W) = f^{-1}\bigl(g^{-1}(W)\bigr).
\]
Pulling back reverses the order: first pull back along $g$, then along $f$ (Figure~\ref{fig:img-composition}). Many objects in advanced geometry are carried backward along functions in this way.
\end{itemize}

Image and preimage operations have a common limit: they move subsets between two spaces $X$ and $Y$ that already exist.

To build new spaces by grouping points together, we need a new tool. Chapter~15 introduces \textbf{relations and equivalence}, and shows how three simple properties let us split a set into non-overlapping groups and build new mathematical objects from them.

\subsection{Exercises}

\subsubsection*{Warm-Up and Mental Checks}

\begin{enumerate}
\item Let $f: \R \to \R$ be the constant function $f(x) = 7$.
\begin{enumerate}[label=(\alph*)]
\item Compute $f([0, 10])$ and $f(\emptyset)$.
\item Compute $f^{-1}(\{7\})$, $f^{-1}(\{3\})$, and $f^{-1}([0, 10])$.
\end{enumerate}

\item Let $f: \R \to \R$ be the absolute value function $f(x) = |x|$.
\begin{enumerate}[label=(\alph*)]
\item Compute $f([-3, 2])$.
\item Compute $f^{-1}([1, 4])$ and $f^{-1}([-5, -1])$.
\end{enumerate}
\end{enumerate}

\subsubsection*{Practice and Computations}

\begin{enumerate}[resume]
\item Let $f: \R \to \R$ be defined by $f(x) = x^2 - 2x$. Find:
\begin{enumerate}[label=(\alph*)]
\item $f([0, 3])$.
\item $f^{-1}([-1, 3])$.
\item $f^{-1}(\{-5\})$.
\end{enumerate}

\item Let $f: X \to Y$ and let $S \subseteq X$.
\begin{enumerate}[label=(\alph*)]
\item Does forward image preserve complements? That is, does $f(X \setminus S) = Y \setminus f(S)$ always hold?
\item Either prove this equality or provide a concrete counterexample with simple finite sets.
\end{enumerate}

\item Let $f: X \to Y$ and let $T_1, T_2 \subseteq Y$. Prove directly using element chasing that
\[
f^{-1}(T_1 \setminus T_2) = f^{-1}(T_1) \setminus f^{-1}(T_2).
\]
\end{enumerate}

\subsubsection*{Deeper Structural Problems}

\begin{enumerate}[resume]
\item \textbf{Arbitrary Families:} Let $f: X \to Y$ and let $\{T_\alpha\}_{\alpha \in I}$ be an arbitrary collection of subsets of $Y$, where the index set $I$ may be finite or infinite.
\begin{enumerate}[label=(\alph*)]
\item Prove that
\[
f^{-1}\Bigl(\bigcup_{\alpha \in I} T_\alpha\Bigr) = \bigcup_{\alpha \in I} f^{-1}(T_\alpha).
\]
\item Prove that
\[
f^{-1}\Bigl(\bigcap_{\alpha \in I} T_\alpha\Bigr) = \bigcap_{\alpha \in I} f^{-1}(T_\alpha).
\]
\end{enumerate}

\item \textbf{Forward Images of Intersections:} Let $f: X \to Y$. Prove that $f$ is injective if and only if for every pair of disjoint subsets $A, B \subseteq X$ (meaning $A \cap B = \emptyset$), their images are disjoint: $f(A) \cap f(B) = \emptyset$.

\item \textbf{Round-Trip Invertibility:} Let $f: X \to Y$.
\begin{enumerate}[label=(\alph*)]
\item Prove that $f$ is bijective if and only if for every subset $S \subseteq X$, $f^{-1}(f(S)) = S$, and for every subset $T \subseteq Y$, $f(f^{-1}(T)) = T$.
\item In this case, how does the set operation $f^{-1}(T)$ relate to the inverse function $f^{-1}: Y \to X$?
\end{enumerate}
\end{enumerate}
