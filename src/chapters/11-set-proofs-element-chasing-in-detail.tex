\section{Set Proofs: Element Chasing in Detail}
\chapterline

In Chapter~10, we introduced sets, membership ($\in$), and operations such as union, intersection, and set difference. When encountering an identity like
\[
A \cap (B \cup C) = (A \cap B) \cup (A \cap C),
\]
it is tempting to sketch overlapping circles and declare the result obvious.

A Venn diagram (one circle per set, drawn overlapping) is a good guide, but it cannot be the proof. With four sets, circles can no longer show every combination of overlaps (the history note later in this chapter explains why), and no picture can show infinitely many sets. A picture can also hide special cases, such as a set that happens to be empty ($\emptyset$).

To prove a \emph{set identity} (an equation between sets that holds whatever the sets are), mathematicians use \emph{element chasing}: take an arbitrary element $x$ of one set, apply the definitions step by step, and show that $x$ belongs to the other set.

\subsection{How to Prove Containment and Equality}

A set is determined entirely by which elements belong to it, not by the names or formulas we use to describe it. This principle is called \emph{extensionality}. If two sets $A$ and $B$ contain exactly the same elements, they are the same set. For example, $\{x \in \Z : x^2 = 1\}$ and $\{-1, 1\}$ are described differently but are equal.

To prove that one set is contained in another, we recall the definition of subset inclusion:
\[
A \subseteq B \iff (\forall x)(x \in A \implies x \in B).
\]
So a proof of $A \subseteq B$ is a proof of an if-then statement about one arbitrary element:
\begin{enumerate}[label=\arabic*.]
\item Begin by introducing an arbitrary element: ``Let $x \in A$.''
\item Unpack what $x \in A$ means using definitions, hypotheses, and logic.
\item Conclude that $x$ must satisfy the membership condition for $B$: ``Therefore $x \in B$.''
\end{enumerate}

To prove that two sets $A$ and $B$ are \emph{equal}, we prove containment in both directions (the double containment method of Chapter~10). Two sets are equal exactly when every element of each one is also an element of the other:
\[
A = B \iff (A \subseteq B \text{ and } B \subseteq A).
\]
Figure~\ref{11:fig-double-containment} shows the two separate arguments this requires.

\begin{intuitionbox}
Think of element chasing as reasoning about an arbitrary element $x$. You do not pick a specific number like $x = 0$ or $x = 5$. You write ``Let $x \in A$,'' using only the properties guaranteed by membership in $A$. If you can deduce from those properties that $x \in B$, then every element of $A$ must belong to $B$.
\end{intuitionbox}

\subsection{A Warm-Up: Intersection Subsets}

The first example applies the method to the simplest fact about intersections.

\begin{theorem}
For any sets $A$ and $B$, $A \cap B \subseteq A$.
\end{theorem}

\begin{proof}
Let $x \in A \cap B$ be arbitrary. 

By definition of intersection, $x \in A \cap B$ means that $x \in A$ and $x \in B$. 

This is a \emph{conjunction} $x \in A \land x \in B$ (an ``and'' statement, Chapter~5). If both parts of an ``and'' statement are true, each part is true on its own, so $x \in A$. Logicians call this step \emph{simplification}.

Since $x$ was an arbitrary element of $A \cap B$, every element of $A \cap B$ belongs to $A$. Thus $A \cap B \subseteq A$.
\end{proof}

The proof has four steps: assume $x \in A \cap B$, unpack the definition into a logical statement, keep the part that is needed, and conclude containment. Figure~\ref{11:fig-warmup-intersection} shows the same steps next to the picture they come from.

\begin{intuitionbox}
\textbf{Pause and think:} Why couldn't we prove $A \cap B \subseteq A$ by testing concrete sets, say $A = \{1, 2, 3\}$ and $B = \{2, 3, 4\}$, calculating $A \cap B = \{2, 3\}$, and observing that both $2$ and $3$ belong to $A$? Because testing concrete numbers only checks that specific example. To establish the universal claim
\[
(\forall x)\,(x \in A \cap B \implies x \in A),
\]
the element $x$ must be generic, possessing only the properties guaranteed by membership in $A \cap B$.
\end{intuitionbox}

\subsection{Set Difference as Complementation}

Next, consider how set difference relates to the complement. Before we can talk about a complement, we must fix a \emph{universal set} $U$: the set of all objects under discussion (such as the real numbers $\R$ or the integers $\Z$).

The \emph{complement} of a set $B$, denoted $B^c$, consists of all objects in $U$ that are not in $B$:
\[
B^c = \{x \in U : x \notin B\}.
\]
The \emph{set difference} $A \setminus B$ (read ``$A$ minus $B$'') consists of the elements of $A$ that are not in $B$:
\[
A \setminus B = \{x \in U : x \in A \text{ and } x \notin B\}.
\]
Removing $B$ from $A$ gives the same set as intersecting $A$ with everything outside $B$.

\begin{theorem}
Let $A$ and $B$ be subsets of a universal set $U$. Then
\[
A \setminus B = A \cap B^c.
\]
\end{theorem}

Figure~\ref{11:fig-difference-complementation} illustrates this identity: whether you start with $A$ and remove $B$, or intersect $A$ with the outside of $B$ (that is, with $B^c$), you get the same region.

\begin{proof}
We show that an arbitrary element $x \in U$ belongs to the left-hand side if and only if it belongs to the right-hand side.

Let $x \in U$ be arbitrary. Then:
\begin{align*}
x \in A \setminus B 
&\iff x \in A \text{ and } x \notin B && \text{(definition of set difference)} \\
&\iff x \in A \text{ and } x \in B^c && \text{(definition of complement)} \\
&\iff x \in A \cap B^c && \text{(definition of intersection)}.
\end{align*}
Because each step is an equivalence ($\Longleftrightarrow$, valid in both directions), the two sets contain exactly the same elements. Hence $A \setminus B = A \cap B^c$.
\end{proof}

\begin{trapbox}
A chain of if-and-only-if ($\Longleftrightarrow$) steps works only when every step is truly reversible. If even a single step holds in one direction only (for instance, $x \in S \implies x \in S \cup T$, which cannot be reversed), the chain proves only one of the two containments. When in doubt, split the proof into two explicit halves: first assume $x$ is in the left set and deduce it is in the right, then assume $x$ is in the right set and deduce it is in the left. Figure~\ref{11:fig-one-way-step} shows why the step from $x \in S$ to $x \in S \cup T$ cannot be reversed.
\end{trapbox}

\subsection{Distributing Intersection Over Union}

In basic algebra, multiplication distributes across addition: $a \cdot (b + c) = (a \cdot b) + (a \cdot c)$. In set theory, intersection distributes across union in the same way:
\[
A \cap (B \cup C) = (A \cap B) \cup (A \cap C).
\]
Why does proving this identity require a case-by-case argument? When an element $x$ belongs to a union $B \cup C$, we get a \emph{disjunction} ($P \lor Q$, an ``or'' statement, Chapter~5): $x \in B$ or $x \in C$. From an ``and'' statement we may use both facts at once; from an ``or'' statement we only know that at least one of the two holds, not which one. So we consider each case separately and verify that in both cases $x$ belongs to $(A \cap B) \cup (A \cap C)$. This is called a \emph{proof by cases}.

\begin{theorem}
For all sets $A, B$, and $C$,
\[
A \cap (B \cup C) = (A \cap B) \cup (A \cap C).
\]
\end{theorem}

Figure~\ref{11:fig-distributive-branching} puts the Venn picture next to the structure of the proof: because a union gives an ``or'' condition, the chase in the first direction splits into two cases, and each case must reach the target set.

\begin{proof}
We prove mutual containment: first $A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C)$, and then the reverse inclusion.

\textbf{Direction 1: $(\subseteq)$.} Let $x \in A \cap (B \cup C)$ be arbitrary. 
By definition of intersection, $x \in A$ and $x \in B \cup C$. 
Unpacking the union, $x \in B \cup C$ means $x \in B$ or $x \in C$. We now argue by cases:
\begin{itemize}
\item \emph{Case 1: $x \in B$.} Since we already know $x \in A$, we have $x \in A$ and $x \in B$, which means $x \in A \cap B$. It follows that $x \in (A \cap B) \cup (A \cap C)$.
\item \emph{Case 2: $x \in C$.} Since $x \in A$, we have $x \in A$ and $x \in C$, so $x \in A \cap C$. Therefore $x \in (A \cap B) \cup (A \cap C)$.
\end{itemize}
In either case, $x \in (A \cap B) \cup (A \cap C)$. This establishes that
\[
A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C).
\]

\textbf{Direction 2: $(\supseteq)$.} Now let $y \in (A \cap B) \cup (A \cap C)$ be arbitrary.
By definition of union, $y \in A \cap B$ or $y \in A \cap C$. Again, we examine the two possibilities:
\begin{itemize}
\item \emph{Case 1: $y \in A \cap B$.} Then $y \in A$ and $y \in B$. Since $y \in B$, we have $y \in B \cup C$. Combining $y \in A$ with $y \in B \cup C$ gives $y \in A \cap (B \cup C)$.
\item \emph{Case 2: $y \in A \cap C$.} Then $y \in A$ and $y \in C$. Since $y \in C$, we have $y \in B \cup C$. Hence $y \in A \cap (B \cup C)$.
\end{itemize}
In both cases, $y \in A \cap (B \cup C)$. Thus
\[
(A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C).
\]

Having established containment in both directions, we conclude that $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.
\end{proof}

\begin{historybox}
In the 1760s, Leonhard Euler used closed curves to illustrate syllogisms, arguments such as ``all $P$ are $Q$; all $Q$ are $R$; so all $P$ are $R$.'' In an 1880 paper titled ``On the Diagrammatic and Mechanical Representation of Propositions and Reasonings,'' the English logician John Venn changed Euler's idea: his diagrams show every possible combination of being inside or outside each set, even combinations that turn out to be empty. For two or three sets the pictures are clear.

Four sets cause the first problem. They have $2^4 = 16$ combinations of inside and outside (counting the region outside all of them), but four circles can cut the plane into at most $14$ regions, so Venn switched to ellipses. For more sets, people looked for diagrams with \emph{rotational symmetry}: each set is the same curve turned by a fixed angle, so the whole picture looks unchanged after a turn of $360^\circ/n$. In 1963 David Henderson showed that such a diagram for $n$ sets can exist only when $n$ is prime, and in 2004 Jerrold Griggs, Charles Killian and Carla Savage showed that one exists for every prime $n$.

The second problem is infinite collections of sets. Take the intervals $(-1/n, 1/n)$ (all real numbers strictly between $-1/n$ and $1/n$) for $n = 1, 2, 3, \dots$. They get narrower and narrower, and the only number in every one of them is $0$ (Figure~\ref{11:fig-shrinking-intervals} draws the first six). This is written
\[
\bigcap_{n=1}^{\infty} \left( -\frac{1}{n}, \frac{1}{n} \right) = \{0\},
\]
where $\bigcap$ means the intersection of all the sets in the list. No picture can show infinitely many boundaries.

Element chasing replaced looking at pictures with step-by-step deduction: reasoning about an arbitrary element $x$ works equally well for two sets, twenty sets, or infinitely many.
\end{historybox}

\subsection{Power Sets and Inclusion: Chasing Across Layers}

Element chasing also works when the elements themselves are sets. The \emph{power set} of a set $A$, denoted $\pow(A)$, is the collection whose elements are all possible subsets of $A$:
\[
X \in \pow(A) \iff X \subseteq A.
\]
For example, if $A = \{1, 2\}$, its subsets are $\emptyset, \{1\}, \{2\}$, and $\{1, 2\}$, so
\[
\pow(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}.
\]

When we prove an inclusion between power sets, the element being chased is itself a set.

\begin{theorem}\label{11:thm-powerset-monotone}
If $A \subseteq B$, then $\pow(A) \subseteq \pow(B)$.
\end{theorem}

\begin{proof}
Suppose $A \subseteq B$. We want to show $\pow(A) \subseteq \pow(B)$.

Let $X \in \pow(A)$ be arbitrary. By definition of the power set, this means $X \subseteq A$.

Now we need to show that $X \in \pow(B)$, which means showing $X \subseteq B$. 

To show $X \subseteq B$, let $z \in X$ be an arbitrary element. Then
\begin{align*}
z \in X &\implies z \in A && \text{(because $X \subseteq A$)} \\
        &\implies z \in B && \text{(because $A \subseteq B$)}.
\end{align*}
Since every $z \in X$ belongs to $B$, we have $X \subseteq B$.

Therefore $X \in \pow(B)$. Because $X \in \pow(A)$ was arbitrary, $\pow(A) \subseteq \pow(B)$.
\end{proof}

For a concrete case, take $A = \{1, 2\}$ and $B = \{1, 2, 3\}$. Figure~\ref{11:fig-powerset-example} lists all eight subsets of $B$; the four subsets of $A$ are among them, as the theorem promises.

\begin{labbox}
The proof above has two layers of element chasing (illustrated in Figure~\ref{11:fig-power-set-levels}). At the outer level, the element is a set $X$ moving from $\pow(A)$ to $\pow(B)$. At the inner level, the element is a point $z$ moving from $X$ to $B$. Keeping these levels distinct prevents the common beginner mistake of confusing $\in$ with $\subseteq$.
\end{labbox}

\begin{intuitionbox}
\textbf{Pause and think:} What happens in the extreme case where $A = \emptyset$? Does Theorem~\ref{11:thm-powerset-monotone} still hold? Yes. The empty set has only one subset: itself ($\pow(\emptyset) = \{\emptyset\}$). If $A = \emptyset$, then $A \subseteq B$ is vacuously true for every set $B$, and since $\emptyset \subseteq B$, we have $\emptyset \in \pow(B)$. Thus $\{\emptyset\} \subseteq \pow(B)$, confirming that $\pow(\emptyset) \subseteq \pow(B)$ as required.
\end{intuitionbox}

\subsection{Scope of element chasing and the transition to functions}

Element chasing proves set identities and subset inclusions by step-by-step deduction about one arbitrary element, where a diagram can only suggest the answer.

Sets describe collections and which collections contain which. Much of mathematics is about rules that send each element of one set to an element of another. In Chapter~12 (\emph{Functions: Structured Promises, Not Just Formulas}), we study these rules, called functions.

\subsection{Exercises}

\subsubsection*{Warm-Up Mental Checks}
\begin{enumerate}[label=\arabic*.]
\item \textbf{The One-Way Trap:} A student writes: ``$x \in A \cup B \iff x \in A$, therefore $A \cup B \subseteq A$.'' Where is the exact logical flaw? Can you give a simple counterexample with numbers where $x \in A \cup B$ is true but $x \in A$ is false?
\item \textbf{Power Set Distinctions:} Let $A = \{1, 2\}$. For each of the following statements, decide whether it is true or false, and explain the difference between them in your own words:
\begin{enumerate}[label=(\alph*)]
\item $\emptyset \in \pow(A)$
\item $\emptyset \subseteq \pow(A)$
\item $\{\emptyset\} \subseteq \pow(A)$
\end{enumerate}
\item \textbf{Proving Emptiness:} Suppose you want to prove that a set $S$ is empty ($S = \emptyset$). How can you adapt the element-chasing method to achieve this? (Hint: Assume for contradiction that there exists some $x \in S$, and chase this hypothetical element until you deduce a logical impossibility.)
\end{enumerate}

\subsubsection*{Core Practice: Element-Chasing Proofs}
Write out complete proofs using full grammatical sentences, explicitly introducing every arbitrary element.
\begin{enumerate}[resume*]
\item Prove that for any sets $A$ and $B$, $A \subseteq A \cup B$.
\item Prove that $A \cap (B \setminus C) = (A \cap B) \setminus C$.
\item Prove De Morgan's Law for set difference across unions:
\[
A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C).
\]
\item Prove the companion De Morgan identity for set difference across intersections:
\[
A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C).
\]
\end{enumerate}

\subsubsection*{Deeper Explorations}
\begin{enumerate}[resume*]
\item \textbf{Power Sets and Intersections:} Prove that for all sets $A$ and $B$,
\[
\pow(A \cap B) = \pow(A) \cap \pow(B).
\]
\item \textbf{Power Sets and Unions:} What happens if we replace intersection with union in the previous problem?
\begin{enumerate}[label=(\alph*)]
\item Prove that $\pow(A) \cup \pow(B) \subseteq \pow(A \cup B)$ always holds.
\item Give an explicit counterexample with small finite sets to prove that the reverse containment, $\pow(A \cup B) \subseteq \pow(A) \cup \pow(B)$, is generally false.
\end{enumerate}
\item \textbf{Infinite Families:} Let $\{A_i\}_{i \in I}$ be an \emph{indexed family} of sets: there is one set $A_i$ for each label $i$ in an \emph{index set} $I$. For example, $I = \{1, 2, 3, \dots\}$ gives the sets $A_1, A_2, A_3, \dots$. The index set may be finite or infinite. Let $B$ be a set. An element belongs to the intersection $\bigcap_{i \in I} A_i$ of the whole family if and only if it belongs to $A_i$ for every $i \in I$. Prove that:
\[
\left( \bigcap_{i \in I} A_i \right) \cap B = \bigcap_{i \in I} (A_i \cap B).
\]
The same method of tracking one arbitrary element $x$ works here, even if there are infinitely many sets.
\end{enumerate}
