\section{Set Proofs: Element Chasing in Detail}
\chapterline

When you encounter an identity between two sets, such as
\[
A \cap (B \cup C) = (A \cap B) \cup (A \cap C),
\]
it can be tempting to sketch overlapping circles, shade the regions, and declare the equality obvious. Venn diagrams build valuable visual intuition, but in pure mathematics, a picture is never the proof itself. 

To understand why, we have to look back at the turn of the twentieth century. In the late 1800s, Georg Cantor and Gottlob Frege operated with what is now called \emph{naive set theory}: the belief that any property or predicate you can state in words automatically defines a legitimate set. But in 1901, Bertrand Russell shattered that confidence with a devastatingly simple question. Consider the collection of all sets that do not contain themselves:
\[
R = \{x : x \notin x\}.
\]
Does $R$ belong to itself? If it does, then by definition it must not; if it does not, then it satisfies the membership condition and must belong to itself. Mathematics had arrived at an outright contradiction at its very foundation.

In 1908, Ernst Zermelo, later joined by Abraham Fraenkel, rescued mathematics from this paradox by creating the axiomatic framework known today as ZFC (Zermelo-Fraenkel set theory with the Axiom of Choice). Zermelo recognized that the error lay in unrestricted comprehension: you cannot simply conjure infinite collections from the ether. Instead, via the Axiom of Specification (or Separation), elements may only be selected from an already existing, well-defined mathematical universe.

This axiomatic revolution changed the nature of mathematical argument. Proofs about sets could no longer rely on handwaving or informal geometric sketches. Mathematicians needed a strict, unambiguous, syntactic protocol to verify that two collections are identical without accidentally summoning paradoxical sets into existence.

That technique is called \emph{element chasing}. The core idea is simple yet unstoppable: imagine placing a tracking device on a single, generic test particle $x$ from one set, and following its logical properties step by step until you demonstrate that $x$ must belong to the other set.

\subsection{The Architecture of Set Containment}

Recall the fundamental definition of subset inclusion:
\[
A \subseteq B \iff (\forall x)(x \in A \implies x \in B).
\]
Proving that $A \subseteq B$ is not about manipulating entire collections all at once. It is a conditional proof about an arbitrary element:
\begin{enumerate}[label=\arabic*.]
\item Begin by introducing an arbitrary element: ``Let $x \in A$.''
\item Unpack what $x \in A$ means using definitions, hypotheses, and logic.
\item Conclude that $x$ must satisfy the membership condition for $B$: ``Therefore $x \in B$.''
\end{enumerate}

To show that two sets $A$ and $B$ are \emph{equal}, we establish mutual containment in both directions. Two sets contain the exact same elements if and only if neither set contains an element foreign to the other:
\[
A = B \iff (A \subseteq B \text{ and } B \subseteq A).
\]

\begin{intuitionbox}
Think of element chasing like placing a tracking device on an anonymous particle. You do not get to pick a special number like $x = 0$ or $x = 5$. You say ``Let $x$ be an arbitrary member of $A$,'' meaning $x$ has only the properties guaranteed by the definition of $A$. If you can guide this particle into $B$ purely through logical deductions, every point in $A$ must make the journey.
\end{intuitionbox}

\subsection{A Warm-Up: Intersection Subsets}

Let us start with the most basic structural property of intersections.

\begin{theorem}
For any sets $A$ and $B$, $A \cap B \subseteq A$.
\end{theorem}

\begin{proof}
Let $x \in A \cap B$ be arbitrary. 

By definition of intersection, $x \in A \cap B$ means that $x \in A$ and $x \in B$. 

From the conjunction $x \in A \land x \in B$, the statement $x \in A$ follows directly by simplification. 

Since $x$ was an arbitrary element of $A \cap B$, every element of $A \cap B$ belongs to $A$. Thus $A \cap B \subseteq A$.
\end{proof}

Notice how clean the flow is: we assumed $x \in A \cap B$, unwrapped the definition into a logical statement, extracted what was needed, and concluded containment.

\subsection{Set Difference as Complementation}

Next, consider the relationship between set difference and the complement. For an element to belong to $A \setminus B$, it must be inside $A$ while lying strictly outside $B$.

\begin{theorem}
Let $A$ and $B$ be subsets of a universal set $U$. Then
\[
A \setminus B = A \cap B^c.
\]
\end{theorem}

\begin{proof}
We will prove this equality by demonstrating that an arbitrary element $x \in U$ belongs to the left-hand side if and only if it belongs to the right-hand side.

Let $x \in U$ be arbitrary. Then:
\begin{align*}
x \in A \setminus B 
&\iff x \in A \text{ and } x \notin B && \text{(definition of set difference)} \\
&\iff x \in A \text{ and } x \in B^c && \text{(definition of complement)} \\
&\iff x \in A \cap B^c && \text{(definition of intersection)}.
\end{align*}
Because each step is a bidirectional logical equivalence ($\iff$), the two sets contain exactly the same elements. Hence $A \setminus B = A \cap B^c$.
\end{proof}

\begin{trapbox}
Chaining if-and-only-if ($\iff$) statements is elegant when every step is truly reversible. But be careful: if even a single step only holds in one direction (for instance, $x \in S \implies x \in S \cup T$, which cannot be reversed), the whole two-way proof collapses. When in doubt, split the proof into two explicit halves: first assume $x$ is in the left set and deduce it is in the right, then assume $x$ is in the right set and deduce it is in the left.
\end{trapbox}

\subsection{Distributing Intersection Over Union}

Now we tackle a statement where splitting into cases is necessary: the distributive law.

\begin{theorem}
For all sets $A, B$, and $C$,
\[
A \cap (B \cup C) = (A \cap B) \cup (A \cap C).
\]
\end{theorem}

\begin{proof}
We prove mutual containment: first $A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C)$, and then the reverse inclusion.

\textbf{Direction 1: $(\subseteq)$.} Let $x \in A \cap (B \cup C)$ be arbitrary. 
By definition of intersection, $x \in A$ and $x \in B \cup C$. 
Unpacking the union, $x \in B \cup C$ means $x \in B$ or $x \in C$. We now argue by cases:
\begin{itemize}
\item \emph{Case 1: $x \in B$.} Since we already know $x \in A$, we have $x \in A$ and $x \in B$, which means $x \in A \cap B$. It follows that $x \in (A \cap B) \cup (A \cap C)$.
\item \emph{Case 2: $x \in C$.} Since $x \in A$, we have $x \in A$ and $x \in C$, so $x \in A \cap C$. Therefore $x \in (A \cap B) \cup (A \cap C)$.
\end{itemize}
In either case, $x \in (A \cap B) \cup (A \cap C)$. This establishes that
\[
A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C).
\]

\textbf{Direction 2: $(\supseteq)$.} Now let $y \in (A \cap B) \cup (A \cap C)$ be arbitrary.
By definition of union, $y \in A \cap B$ or $y \in A \cap C$. Again, we examine the two possibilities:
\begin{itemize}
\item \emph{Case 1: $y \in A \cap B$.} Then $y \in A$ and $y \in B$. Since $y \in B$, we certainly have $y \in B \cup C$. Combining $y \in A$ with $y \in B \cup C$ gives $y \in A \cap (B \cup C)$.
\item \emph{Case 2: $y \in A \cap C$.} Then $y \in A$ and $y \in C$. Since $y \in C$, we have $y \in B \cup C$. Hence $y \in A \cap (B \cup C)$.
\end{itemize}
In both cases, $y \in A \cap (B \cup C)$. Thus
\[
(A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C).
\]

Having established containment in both directions, we conclude that $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.
\end{proof}

\begin{historybox}
John Venn popularized his overlapping circle diagrams in an 1880 paper, ``On the Diagrammatic and Mechanical Representation of Propositions and Reasonings.'' For two or three sets, Venn's diagrams are intuitive triumphs. But mathematics quickly encountered severe limitations. Drawing four mutually intersecting sets with circles is geometrically impossible (it requires ellipses or complex interlocking shapes), and visualizing infinite collections---such as countable intersections $\bigcap_{n=1}^\infty A_n$ in analysis---is completely beyond pictorial representation. Worse, Gottlob Frege's monumental attempt to build all of arithmetic from intuitive set definitions (\emph{Grundgesetze der Arithmetik}, 1893--1903) collapsed when Russell's paradox demonstrated that unrestrained visual and linguistic intuition could prove falsehoods. Element chasing replaced pictorial reliance with formal logical inference: an arbitrary test particle $x$ can navigate an infinite family of sets with the same exact certainty as two finite sets.
\end{historybox}

\subsection{Power Sets and Inclusion}

Element chasing also works when the elements themselves are sets. Recall that the power set $\pow(A)$ is the collection of all subsets of $A$:
\[
X \in \pow(A) \iff X \subseteq A.
\]

\begin{theorem}
If $A \subseteq B$, then $\pow(A) \subseteq \pow(B)$.
\end{theorem}

\begin{proof}
Suppose $A \subseteq B$. We want to show $\pow(A) \subseteq \pow(B)$.

Let $X \in \pow(A)$ be arbitrary. By definition of the power set, this means $X \subseteq A$.

Now we need to show that $X \in \pow(B)$, which means showing $X \subseteq B$. 

To show $X \subseteq B$, let $z \in X$ be an arbitrary element. Since $X \subseteq A$, we have $z \in A$. Since $A \subseteq B$, we have $z \in B$. Since every $z \in X$ belongs to $B$, we have $X \subseteq B$.

Therefore $X \in \pow(B)$. Because $X \in \pow(A)$ was arbitrary, $\pow(A) \subseteq \pow(B)$.
\end{proof}

\begin{labbox}
Notice the two layers of element chasing in the proof above! At the outer level, the element is a set $X$ moving from $\pow(A)$ to $\pow(B)$. At the inner level, the element is a point $z$ moving from $X$ to $B$. Keeping these levels distinct prevents the common beginner mistake of confusing $\in$ with $\subseteq$.
\end{labbox}

\subsection{What Element Chasing Unlocked, Its Honest Limits, and Where We Go Next}

Element chasing gives you an indispensable foundation: it allows you to verify set-theoretic equations, Boolean identities, power set hierarchies, and De Morgan laws with mechanical, inescapable precision. It strips away the fog of diagrammatic ambiguity and protects mathematical reasoning from the paradoxes of naive set theory.

Yet it is vital to recognize what this tool cannot do. Element chasing is purely \textbf{static and extensional}. It views sets as inert, passive containers of elements sitting fixed in a frozen landscape. It can tell you whether an object belongs inside a box, but it has no vocabulary for:
\begin{itemize}
\item \textbf{Motion and transformation:} How elements in one set dynamically map or transform into elements of another.
\item \textbf{Directional processes:} How an input produces an output, or how an algorithm computes a result.
\item \textbf{Preservation of structure:} Whether a transformation compresses information, loses data, or can be run backward.
\end{itemize}
A universe of static sets without mappings is like an elaborate theater stage with sets and scenery, but no actors and no action.

To bring this world to life, we need a mathematical machine that connects different sets across directed bridges. In Chapter~12, we introduce \textbf{Functions: Structured Promises, Not Just Formulas}, transforming passive collections into domains and codomains linked by lawful assignments. Later, in Chapter~31, we will return to the deeper algebraic architecture of sets to explore Boolean algebras and Stone's representation theorem.

\subsection{Exercises}

Prove each of the following statements using element chasing. Write out full sentences and explicitly name your arbitrary elements.

\begin{enumerate}
\item Show that for any sets $A$ and $B$, $A \subseteq A \cup B$.
\item Prove that $A \cap (B \setminus C) = (A \cap B) \setminus C$.
\item Prove De Morgan's Law for set difference:
\[
A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C).
\]
\item Prove the companion De Morgan identity:
\[
A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C).
\]
\item Prove that $\pow(A \cap B) = \pow(A) \cap \pow(B)$ for all sets $A$ and $B$.
\end{enumerate}
