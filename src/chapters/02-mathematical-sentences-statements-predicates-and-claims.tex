\section{Mathematical Sentences: Statements, Predicates, and Claims}
\chapterline

In Chapter~1, we saw that numerical calculation and diagrams have limits: pictures can mislead, and checking finite cases cannot survey an infinite collection. To build arguments that hold without exception, we need a precise medium: mathematical language.

In everyday conversation, words shift their meanings, statements can be figurative or approximate, and a word as common as ``is'' serves different functions from one sentence to the next. Before constructing proofs, we need to understand the structure of mathematical sentences: what kinds of objects exist, which expressions refer to objects, which expressions make assertions, and which assertions evaluate to true or false.

\begin{historybox}
For more than two thousand years, formal logic was synonymous with Aristotle's syllogisms (c.~350 BCE in the \emph{Prior Analytics}), which classified arguments into rigid verbal templates like ``All humans are mortal; Socrates is human; therefore Socrates is mortal.'' A syllogism is a two-premise deduction where general categories are combined to force a conclusion. Scholars had only natural language and rhetorical rules to guide them. But as mathematics advanced toward calculus and abstract geometry, Aristotle's system proved too narrow. It could not express even simple relational deductions---arguments that depend on how two objects relate to one another---such as Augustus De Morgan's 1860 challenge: ``All horses are animals; therefore every head of a horse is a head of an animal.''

Everyday grammar also blurs distinct logical relationships. In ordinary speech, the word ``is'' performs three different roles: it asserts identity (``a triangle \emph{is} a three-sided polygon''), declares a property or membership (``seven \emph{is} prime''), or claims universal containment (``a dog \emph{is} an animal''). Mixing up these three roles caused centuries of philosophical confusion.

In 1879, the German mathematician Gottlob Frege published his \emph{Begriffsschrift} (``Concept Script''). Frege replaced everyday subject-predicate grammar with the mathematical concept of a function. An open condition like ``\ldots is prime'' is a predicate function $P(x)$ that accepts an input object and outputs an unambiguous truth value: True or False.

Frege's work was initially met with skepticism; contemporary mathematicians found his two-dimensional notation unwieldy. In addition, Frege's system allowed a set (a collection of objects) to be formed from any condition whatsoever. In 1901 Bertrand Russell showed that this leads to a contradiction, now called Russell's Paradox: the set of all sets that do not contain themselves can neither contain itself nor fail to contain itself. In the 1910s, L.E.J.~Brouwer challenged the Law of the Excluded Middle (the assumption that every statement is either True or False), arguing that a claim that something exists is established only when one can explicitly construct an example of it.

Despite these debates, Frege's use of functions gave mathematics its modern classification of expressions into terms, predicates, and statements, the classification this chapter teaches. It also made it possible to study proof itself mathematically: in 1931, Kurt G\"odel showed that any formal system (a fixed list of axioms and rules for deriving new statements) that contains basic arithmetic and never proves a contradiction has true statements that cannot be proved within the system.
\end{historybox}

The first distinction to make is between sentences that are true or false and sentences that are not.

\begin{definition}
A \emph{statement} (or \emph{proposition}) is a sentence that is unambiguously either true or false, but not both.
\end{definition}

In pure mathematics, statements are the central objects of deduction. A proof is a chain of reasoning showing that a given statement is true. If a sentence has no truth value, asking for a proof of it is a category mistake, like asking what colour the number $7$ is.

Consider these examples:
\begin{itemize}
\item ``$7$ is a prime number'' is a true statement.
\item ``$9$ is a prime number'' is a false statement.
\item ``There are infinitely many prime numbers'' is a true statement.
\item ``Every continuous function on $\R$ is differentiable'' is a false statement. Here $\R$ is the set of real numbers; a function is \emph{continuous} if, roughly, its graph can be drawn without lifting the pen, and \emph{differentiable} if its graph has a well-defined slope (a derivative) at every point. The absolute value function $f(x) = \lvert x\rvert$ is continuous, but its graph has a sharp corner at $x = 0$, where it has no derivative (Figure~\ref{02:fig-abs-corner}).
\end{itemize}

A sentence does not need to be easy to evaluate to qualify as a statement. For more than three centuries, Fermat's Last Theorem---the claim that $a^n + b^n = c^n$ has no positive integer solutions for integers $n > 2$---remained unproved. Its truth was unknown until Andrew Wiles and Richard Taylor completed a proof in 1995. Throughout those three centuries, the sentence was not a vague riddle; it was a well-defined statement whose truth value had not yet been established.

\begin{recoverybox}
\textbf{Pause and think:} Test your intuition on these four sentences. Which ones are statements?
\begin{enumerate}[label=(\alph*)]
\item ``$2 + 3 = 5$.''
\item ``$x + 3 = 5$.''
\item ``$1 = 0$.''
\item ``Please solve for $x$.''
\end{enumerate}
\textbf{Check:} Sentence (a) is a true statement. Sentence (c) is also a statement: it is false, and unambiguously so. Sentence (b) is \emph{not} a statement yet; without knowing what $x$ stands for, it cannot be judged true or false. Sentence (d) is an imperative command, not an assertion of fact.
\end{recoverybox}

\subsection{The taxonomy of mathematical expressions}

A common obstacle when moving from computational mathematics to proof-based mathematics is mixing up four kinds of expression:
\begin{itemize}
\item A \emph{term} names an object, such as a number, a function, or a set. The expression $x^2 + 1$ is a term: it stands for a number, and it is neither true nor false.
\item A \emph{predicate} is a condition with open slots, such as ``$n$ is prime''. It is not true or false until the slots are filled.
\item A \emph{statement} asserts something definite, such as ``$7$ is prime'', and is true or false.
\item An \emph{ill-formed} expression puts objects of the wrong kinds together, such as ``$5 \subseteq \R$''. (Here $A \subseteq B$, read ``$A$ is a subset of $B$'', means every element of the set $A$ is also an element of the set $B$; a number like $5$ is not a set, so the expression means nothing.) Programmers call this a \emph{type error}, as when code tries to add a number to a piece of text.
\end{itemize}
Instructions such as ``Solve for $x$'' or ``Let $G$ be a finite group'' form a fifth kind: they tell the reader what to do or what to assume, and have no truth value. Figure~\ref{02:fig-expression-taxonomy} sorts examples of the first four kinds. Before evaluating an expression, you must know which kind it is.

\subsection{Predicates: sentences with open variable slots}

An expression such as $x^2 - 1 = 0$ looks like a statement, but it is not. You cannot say whether it is true or false until you know what $x$ is. If $x = 1$, the sentence becomes $1^2 - 1 = 0$, which is true. If $x = 3$, the sentence becomes $3^2 - 1 = 0$, which is false.

\begin{definition}
A \emph{predicate} is a sentence containing one or more variables that becomes a statement whenever each variable is replaced by a specific element from a specified domain (the collection of values the variable may take; see the next subsection), or bound by a quantifier (explained below).
\end{definition}

In computer science, a predicate is a function that returns a Boolean value, that is, True or False:
\begin{center}
\texttt{isEven : Integer $\to$ \{True, False\}}
\end{center}
This line says that \texttt{isEven} takes an integer as input and returns True or False. Until you pass an input into \texttt{isEven(n)}, the function produces no output. A predicate works the same way: until an input fills every slot, the expression does not evaluate to True or False. In mathematics, we write $P(x)$ to indicate that $P$ is an open condition waiting for an input $x$, and we write $P(x) : x^2 - 1 = 0$ to say which condition $P(x)$ stands for. A variable that is still an open slot is called a \emph{free} variable. Figure~\ref{02:fig-predicate-function} draws $P(x) : x^2 - 1 = 0$ as such a function: each input goes to True or False.

There are two ways to close an open slot and obtain a statement:
\begin{enumerate}
\item \textbf{Instantiation (Substituting a Value):} We select a specific value $c$ from our domain and evaluate $P(c)$. For $P(x) : x^2 - 1 = 0$, setting $x = 1$ gives the true statement $1^2 - 1 = 0$; setting $x = 3$ gives the false statement $3^2 - 1 = 0$.
\item \textbf{Quantification (Binding the Variable):} We close the variable slot by saying how widely the condition holds across the entire domain. The universal quantifier $\forall$ (read ``for all'') asserts that every value in the domain satisfies the predicate:
\[
\forall x \in \R,\; x^2 - 1 = 0 \quad (\text{False: } x = 0 \text{ is a counterexample}).
\]
The existential quantifier $\exists$ (read ``there exists'') asserts that at least one value works:
\[
\exists x \in \R,\; x^2 - 1 = 0 \quad (\text{True: } x = 1 \text{ is a witness}).
\]
A \emph{counterexample} is a value for which the condition fails, which is enough to make a ``for all'' statement false; a \emph{witness} is a value for which the condition holds, which is enough to make a ``there exists'' statement true. Once bound by a quantifier, $x$ is no longer an open slot waiting for input; it is a \emph{bound} (or dummy) variable, a placeholder like the loop variable in a \texttt{for} loop. Renaming it changes nothing: $\exists y \in \R,\; y^2 - 1 = 0$ says the same thing. The entire sentence is now a statement.
\end{enumerate}

Predicates can have more than one variable. For instance, the inequality $L(x, y) : x < y$ has two free variables, so it has two slots: $L(\,\cdot\,, \,\cdot\,)$. If you substitute only one value, say $x = 3$, you obtain $L(3, y) : 3 < y$, which is still a predicate in $y$. Only when both variables are filled or bound do you get a statement: $L(3, 5)$ is True, while $L(3, 2)$ is False. Chapters~3 and~4 treat multiple variables and the order of quantifiers in depth.

\subsection{The domain changes everything}

When you work with a predicate, the collection from which its variables may be chosen---the \emph{domain of discourse}, or \emph{domain} for short---can decide whether the sentence is true or false.

Recall our standard number systems:
\begin{itemize}
\item $\N = \{1, 2, 3, \ldots\}$: the natural numbers (positive integers).
\item $\Z = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$: the integers.
\item $\Q = \{\, p/q : p, q \in \Z,\ q \neq 0 \,\}$: the rational numbers (fractions). Read the braces as ``the set of all $p/q$ such that $p$ and $q$ are integers and $q \neq 0$''; the colon means ``such that''.
\item $\R$: the real numbers (including rationals and irrationals like $\sqrt{2}$ and $\pi$).
\item $\C = \{\, a + bi : a, b \in \R \,\}$, where $i$ is a new number with $i^2 = -1$: the complex numbers.
\end{itemize}
Each system contains the one before it, as Figure~\ref{02:fig-number-systems} shows, so moving to a larger domain adds new values that a variable may take.

Take the predicate $P(x) : x^2 < 2$. Its truth depends entirely on where $x$ is allowed to live:
\begin{itemize}
\item Over the natural numbers $\N$, only $x = 1$ satisfies it, so $x = 1$ is the only witness for the statement ``$\exists x \in \N,\; x^2 < 2$''.
\item Over the integers $\Z$, the solutions are $x \in \{-1, 0, 1\}$.
\item Over the rational numbers $\Q$, there are infinitely many solutions, yet the boundary points $-\sqrt{2}$ and $\sqrt{2}$ do not exist inside $\Q$.
\item Over the real numbers $\R$, the solution set is the open interval $(-\sqrt{2}, \sqrt{2})$: every real number strictly between $-\sqrt{2}$ and $\sqrt{2}$, with the two endpoints left out.
\item Over the complex numbers $\C$, the inequality $x^2 < 2$ is not even standardly defined, because there is no way to define $<$ on $\C$ that obeys the usual rules of arithmetic, such as ``the product of two positive numbers is positive''. Under those rules every nonzero square must be positive, which would give both
\[
1 = 1^2 > 0 \qquad\text{and}\qquad -1 = i^2 > 0.
\]
Adding these two inequalities gives $0 > 0$, which is impossible.
\end{itemize}

\begin{trapbox}
Always specify the domain of a variable. The assertion ``$x^2 \ge 0$ for all $x$'' depends on where $x$ lives: over $\R$ it is true, while over $\C$ it fails. Choosing $x = i$ gives $i^2 = -1$, which is not $\ge 0$, and for $x = 1 + i$ the square is $(1 + i)^2 = 1 + 2i + i^2 = 2i$, which cannot be compared with $0$ at all.
\end{trapbox}

\begin{recoverybox}
\textbf{Pause and think:} Consider the predicate $E(x) : 2x = 1$. Over which of the following domains does the statement ``$\exists x,\; E(x)$'' become True?
(a) The natural numbers $\N$; (b) The integers $\Z$; (c) The rational numbers $\Q$; (d) The real numbers $\R$.

\textbf{Answer:} Over $\N$ and $\Z$, the statement is False: no integer doubled equals $1$. Over $\Q$ and $\R$, it is True: the witness $x = 1/2$ exists in both domains.
\end{recoverybox}

\subsection{Claims, theorems, and mathematical etiquette}

When mathematicians state assertions they intend to establish, they use conventional labels to communicate the structural role of the result:

\begin{itemize}
\item \textbf{Theorem}: A main result of a theory (such as the Pythagorean Theorem, or the Fundamental Theorem of Arithmetic, which says every whole number greater than $1$ factors into primes in exactly one way, apart from the order of the factors).
\item \textbf{Proposition}: A result of moderate importance, worth recording and reusing on its own.
\item \textbf{Lemma}: A stepping-stone result. Lemmas often do the detailed technical work so that the main theorem can be stated and proved cleanly.
\item \textbf{Corollary}: A direct and immediate consequence of an established theorem, requiring minimal additional effort to verify.
\item \textbf{Conjecture}: A statement believed to be true because of strong evidence or observed patterns, but which has no proof yet. Examples are the Twin Prime Conjecture (there are infinitely many primes $p$ for which $p + 2$ is also prime) and the Goldbach Conjecture (every even integer greater than $2$ is the sum of two primes).
\item \textbf{Claim}: A local sub-goal inside an ongoing proof. An author isolates an intermediate milestone by declaring ``Claim: \ldots'', establishes it, and then resumes the main argument.
\end{itemize}

These labels describe the role a result plays, not a logical difference. To a computer checking a proof, a lemma, a proposition, and a theorem are identical: they are all proved statements. For a human reader, however, the labels show how a theory is organized, and one author's stepping-stone lemma might later become celebrated as a major theorem (such as Zorn's Lemma in set theory or Gauss's Lemma in number theory). Figure~\ref{02:fig-result-labels} shows how the labelled results typically depend on one another.

\subsection{What formal grammar gives us---and where it stops}

Frege's classification separates the objects we study (terms) from the assertions we make about them (statements), and treats open conditions as predicates. It protects us from type errors, such as treating a number as a set, and from asking whether an open formula is true before its variables are filled or bound. It also separates the three jobs that the English word ``is'' does, drawn in Figure~\ref{02:fig-three-is}: identity ($a = b$), membership ($x \in S$), and containment ($A \subseteq B$).

This classification looks at one expression at a time, but does not describe how variables behave across a multi-step proof. When an argument introduces a variable $x$, we must know how it is introduced: is $x$ a fixed parameter, an arbitrary element representing any member of a set, a specific witness chosen to satisfy a condition, or a bound variable local to a formula?

Without clear rules for where a variable is in force (its \emph{scope}) and which assumptions are active, even well-formed sentences can lead to invalid deductions. Chapter~3 (\emph{Variables Have Roles: Fixed, Arbitrary, Chosen, and Bound}) treats these four roles and the rules of scope.

\subsection{Exercises}

\textbf{Part A: Classification of Expressions.} Classify each expression below as a mathematical term, a predicate, a statement, an instruction, or a grammatical type error:
\begin{enumerate}
\item $2x + 5 = 11$.
\item $2(3) + 5 = 11$.
\item $\cos^2(\theta) + \sin^2(\theta)$.
\item For every real number $x$, $x^2 + 1 > 0$.
\item Let $G$ be a finite group.
\item $3 \in \{1, 2, 3, 4\}$.
\item $\{3\} \in \{1, 2, 3, 4\}$.
\item $\{3\} \subseteq \{1, 2, 3, 4\}$.
\item $\sqrt{-1} \le 4$.
\end{enumerate}

\textbf{Part B: Domain Investigations.} For each of the following predicates, describe two different domains where the predicate yields different sets of solutions:
\begin{enumerate}[resume]
\item $Q(x) : 2x = 7$.
\item $R(x) : x^2 = 2$.
\item $S(x) : x \ge 0$.
\item $T(x) : x^3 - x = 0$.
\end{enumerate}

\textbf{Part C: The Three Faces of ``Is''.} In everyday English, the word ``is'' does three distinct mathematical jobs: asserting identity ($a = b$), declaring membership or property ($x \in S$ or $P(x)$), and asserting subset inclusion ($A \subseteq B$); see Figure~\ref{02:fig-three-is}. Classify the role of ``is'' in each sentence, and rewrite it using precise mathematical symbols. (In the last item, the \emph{empty set} is the set with no elements.)
\begin{enumerate}[resume]
\item ``An equilateral triangle is an equiangular triangle.''
\item ``Seventeen is prime.''
\item ``The set of squares is a subset of the integers.''
\item ``The empty set is unique.''
\end{enumerate}

\textbf{Part D: Spotting Type Errors in Proofs.} Diagnose the type error in each student attempt. Here $A \cap B$ (``$A$ intersect $B$'') is the set of elements that are in both $A$ and $B$, and a function $f$ is \emph{bounded} if all its values lie between two fixed numbers.
\begin{enumerate}[resume]
\item A student writes: ``Since $x \in A \cap B$, therefore $x \cap A$.''
\item A student writes: ``We know that $f(x) \subseteq \R$, so $f$ is bounded.''
\item A student writes: ``Let $S = \{x \in \R : x > 0\}$. Then $S$ is true.''
\end{enumerate}

\begin{walkbox}
When reading a mathematical argument, count how often the word ``is'' appears. Can you pause at each occurrence and identify whether it asserts that two names refer to the same object ($a = b$), that an object has a property ($x \in S$), or that one entire class is contained in another ($A \subseteq B$)? Keeping these three meanings distinct helps prevent subtle errors in reasoning.
\end{walkbox}
