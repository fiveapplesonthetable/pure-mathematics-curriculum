\subsection{From physical intuition to formal axiomatics: Euclid to Hilbert}

Chapter~28 showed how a quantifier swap can break a proof. But logical syntax is only part of the foundation. A statement like $\forall x \in A, \; P(x)$ depends on how $A$ and $P(x)$ are defined. If definitions rest on informal mental pictures rather than explicit rules, unstated assumptions slip in unnoticed.

Euclid's \emph{Elements} (c.~300~BCE) introduced the axiomatic method to mathematics, yet Euclid opened his work with intuitive descriptions rather than formal tests: ``A point is that which has no part''; ``A line is breadthless length.''

These sentences appeal to visual imagination. They give no test you could apply to decide whether something is a point or a line. Because Euclid relied on physical intuition for what points and lines ``were,'' unstated assumptions entered his proofs. In his first proposition, constructing an equilateral triangle, Euclid drew two overlapping circles and assumed, without any axiom that says so, that they intersect (Figure~\ref{29:fig-euclid-circles}). In later proofs, he assumed that a line entering a triangle through one edge must leave through another. That fact does not follow from Euclid's axioms; it needs an extra axiom, now called Pasch's axiom after Moritz Pasch, who stated it in 1882.

For centuries, mathematicians treated these gaps as minor because everyone agreed on the geometry of physical space. But in the nineteenth century, mathematicians found non-Euclidean geometries: geometries that drop Euclid's parallel postulate (through a point not on a given line there is exactly one line that never meets it) and still never lead to a contradiction. On a sphere, where the ``lines'' are great circles such as the equator, every pair of lines crosses, so there are no parallels at all. In hyperbolic geometry, which can be pictured locally on a saddle-shaped surface, infinitely many lines pass through a point without meeting a given line. Figure~\ref{29:fig-three-geometries} compares the three. Which geometry was physically true?

In 1899, David Hilbert published \emph{Grundlagen der Geometrie} (Foundations of Geometry), which changed what a definition is. A definition no longer describes what an object is made of; it lists the rules the object must satisfy in relation to other objects.

\subsection{Definitions as precise classification tests}

In everyday conversation, words have soft edges. If someone asks you to define a ``chair'' or a ``game,'' you might describe typical examples: something with four legs you sit on, or an activity with rules and a winner. But if you encounter a beanbag, an office stool, or solitaire, the colloquial boundary blurs. Human language tolerates ambiguity because context fills the gaps.

Pure mathematics cannot rely on fuzzy boundaries. A mathematical definition works by an explicit set of conditions rather than typical examples or sensory impressions. It specifies an exact checklist of requirements: an object either satisfies every condition and qualifies, or fails at least one and does not. There is no intermediate case. Figure~\ref{29:fig-four-layers} shows the four parts that such a checklist has; the next subsection goes through them one at a time.

\subsection{The four anatomical parts of a definition}

Whenever you meet a new mathematical definition, do not memorize the sentence as a long string of words. Take it apart into four layers:

\begin{enumerate}
\item \textbf{The Ambient Universe}: What mathematical world are we standing in? (``Ambient'' means surrounding: the setting the definition takes for granted.) Does this definition require a plain set of numbers, a group (a collection of symmetries with a reversible operation), a metric space (a set equipped with a notion of distance between points), or a vector space (a space where objects can be stretched and added together)? If the setting is missing, the definition has nothing to talk about.
\item \textbf{The Input Signature}: What object is receiving the label? Is the definition classifying a single point, a subset, an ordered pair, or a function? (In programming, a function's signature lists the types of its inputs; the word is used the same way here.)
\item \textbf{The Defining Contract}: What exact condition must be checked? Is it an algebraic equation, an if-then implication, or a game between quantifiers like those in Chapter~4?
\item \textbf{The Downstream Rights}: What new tools for deduction do you gain once an object passes the test? If a set is open in a metric space, you can find an open ball (all points closer than some radius, as in Chapter~22) around any of its points that stays entirely inside the set. If a function is injective (one-to-one), you gain the right to cancel $f$ from both sides of an equation: $f(a_1) = f(a_2)$ implies $a_1 = a_2$.
\end{enumerate}

\begin{recoverybox}
\textbf{Pause and think}: Suppose someone asks you: ``Is the square root function injective?'' Before attempting a proof, check Layer~1 (the ambient universe). If the function is defined on the non-negative real numbers, $f: [0, \infty) \to \R$, it is strictly increasing and passes the test. But if someone tries to define $f$ on all real numbers, the output $\sqrt{-4}$ is not a real number, so $f$ is not a function from $\R$ to $\R$ at all. Testing the defining contract before fixing the ambient universe produces a type error (Chapter~2): the question is asked about an object that does not exist.
\end{recoverybox}

\subsection{Microscope study: why injective is defined via equality}

Consider the definition of an injective (one-to-one) function. The informal intuition is simple:
\begin{quote}
``Different inputs produce different outputs.''
\end{quote}
Translated directly into logic, this intuition reads:
\[
\forall a_1, a_2 \in A, \; a_1 \neq a_2 \implies f(a_1) \neq f(a_2).
\]
Yet almost every textbook in higher mathematics defines injectivity using its \textbf{contrapositive}---the logically equivalent statement formed by reversing the implication and negating both sides ($P \implies Q$ becomes $\text{not } Q \implies \text{not } P$):
\[
\forall a_1, a_2 \in A, \; f(a_1) = f(a_2) \implies a_1 = a_2.
\]

Why prefer the contrapositive over the intuitive sentence?

The reason is practical: \textbf{equations are far easier to compute with than statements of the form $x \neq y$.}
\begin{itemize}
\item If you start with $a_1 \neq a_2$, there is little you can do algebraically, because a ``not equal'' fact does not survive ordinary algebra. If you square two unequal numbers, they can become equal: $(-3)^2 = 3^2 = 9$ (Figure~\ref{29:fig-horizontal-line}b). If you multiply both sides by an unknown $z$, both sides become zero if $z = 0$. The statement $a_1 \neq a_2$ only tells you that two things differ; it gives you nothing to substitute or compute with.
\item If you start with $f(a_1) = f(a_2)$, you have an equation. Equality allows direct substitution: wherever $f(a_1)$ appears, it can be replaced by $f(a_2)$. You can apply algebraic identities, factor both sides, cancel non-zero terms, and systematically isolate the variables until you arrive at $a_1 = a_2$.
\end{itemize}

On a graph, injectivity means that every horizontal line meets the graph at most once: a horizontal line at height $y$ that meets the graph twice marks two different inputs with the same output $y$. Figure~\ref{29:fig-horizontal-line} shows a function that passes this test and one that fails it.

\begin{example}
Prove that $f: \R \to \R$ given by $f(x) = 5x - 7$ is injective.
\begin{proof}
Let $a_1, a_2 \in \R$ be arbitrary, and assume $f(a_1) = f(a_2)$. Then
\begin{align*}
5a_1 - 7 &= 5a_2 - 7 && \text{(definition of $f$)}\\
5a_1 &= 5a_2 && \text{(add $7$ to both sides)}\\
a_1 &= a_2 && \text{(divide both sides by $5$).}
\end{align*}
Therefore, $f$ is injective.
\end{proof}
Each step is a single operation on an equation.
\end{example}

\begin{recoverybox}
\textbf{Pause and think}: A beginner often tries to verify that a function is injective by assuming $a_1 = a_2$ and showing that $f(a_1) = f(a_2)$. Why is this wrong? The implication $a_1 = a_2 \implies f(a_1) = f(a_2)$ says only that equal inputs give equal outputs, that is, $f$ gives one output per input. That is part of being a function (Chapter~12 calls a rule that passes this check \emph{well-defined}), not injectivity. Every function satisfies it, even the constant function $f(x) = 42$. Injectivity runs the arrow in reverse: equal outputs must force equal inputs. Figure~\ref{29:fig-welldef-vs-injective} puts the two side by side.
\end{recoverybox}

\subsection{Stress-testing definitions: dropping an axiom}

The clearest way to understand why a definition contains the exact clauses it does is to ask: \emph{what breaks if one condition is omitted?}

Definitions in pure mathematics rarely include redundant conditions. Each clause serves a specific purpose in later proofs. (The clauses of a definition are often called \emph{axioms}, as in ``the group axioms.'') Omitting one widens the class of objects that pass the test, often letting in structures that lack the key properties of the original concept.

\begin{example}
Consider the definition of an \textbf{equivalence relation} on a set $S$ (Chapter~15)---a relation that behaves like a looser version of equality and sorts the elements into non-overlapping groups called equivalence classes:
\begin{enumerate}
\item \textbf{Reflexivity}: $\forall x \in S, \; x \sim x$ (every element is related to itself).
\item \textbf{Symmetry}: $\forall x, y \in S, \; x \sim y \implies y \sim x$ (if $x$ is related to $y$, then $y$ is related to $x$).
\item \textbf{Transitivity}: $\forall x, y, z \in S, \; (x \sim y \land y \sim z) \implies x \sim z$ (relations chain through a middle element).
\end{enumerate}

What happens if we drop \textbf{transitivity}, keeping only reflexivity and symmetry? A relation satisfying only reflexivity and symmetry is called a \emph{tolerance relation}.

Consider the relation on the real number line given by $|x - y| \le 1$ (``is within $1$ unit of''):
\begin{itemize}
\item Every number is within $1$ unit of itself: $|x - x| = 0 \le 1$ (reflexive).
\item Distance is symmetric: $|x - y| = |y - x| \le 1$ (symmetric).
\item But consider $x = 0$, $y = 0.7$, and $z = 1.4$:
\begin{align*}
|0 - 0.7| &= 0.7 \le 1, && \text{so } 0 \sim 0.7,\\
|0.7 - 1.4| &= 0.7 \le 1, && \text{so } 0.7 \sim 1.4,\\
|0 - 1.4| &= 1.4 > 1, && \text{so } 0 \not\sim 1.4.
\end{align*}
Transitivity fails.
\end{itemize}

Why does transitivity matter so much? Because without it, the ``classes'' need not \textbf{partition} the set---slice it into pieces that do not overlap and together cover all of it.

In a genuine equivalence relation, every element $x$ belongs to its \textbf{equivalence class}, the set of everything related to it:
\[
[x] = \{\, y \in S : x \sim y \,\}.
\]
Transitivity guarantees an all-or-nothing property: for any two elements $a$ and $b$, either their classes are completely identical ($[a] = [b]$) or they do not share any elements ($[a] \cap [b] = \emptyset$). Here is why. Suppose the classes share even one element $c \in [a] \cap [b]$, so that $a \sim c$ and $b \sim c$. Then
\begin{align*}
&c \sim b && \text{(symmetry, from $b \sim c$)},\\
&a \sim b && \text{(transitivity, from $a \sim c$ and $c \sim b$)},\\
&a \sim y \text{ for every } y \in [b] && \text{(transitivity, from $a \sim b$ and $b \sim y$)}.
\end{align*}
The last line says $[b] \subseteq [a]$, and the same argument with $a$ and $b$ swapped shows $[a] \subseteq [b]$. One shared element forces the two classes to merge completely. This allows mathematicians to construct a \textbf{quotient set} $S/{\sim}$ (read ``$S$ modulo $\sim$''), the set whose elements are the classes themselves, so that each entire class is treated as a single object. Equivalent fractions are the standard example: $\frac{1}{2}, \frac{2}{4}, \frac{3}{6}$ form one class, which is the single rational number $0.5$ (Figure~\ref{29:fig-quotient}).

Without transitivity this fails. In Figure~\ref{29:fig-tolerance}, the numbers within $1$ of $0$ form the interval $[-1, 1]$ and the numbers within $1$ of $1.4$ form $[0.4, 2.4]$. Both contain $0.7$, yet the two sets are different. The ``classes'' overlap without coinciding, so they do not partition $\R$, and there is no quotient set to form.
\end{example}

\begin{labbox}
Take the definition of a group $(G, *)$ from Chapter~21. What happens if you drop the inverse axiom? You get a \textbf{monoid}---a set with an associative operation and an identity element, but no guarantee that an operation can be undone. An example is $\{0, 1, 2, \ldots\}$ under addition: $0$ is the identity, but after adding $3$ there is no element you can add to get back where you started, because negative numbers are missing. What happens if you also drop associativity and the identity, keeping only an operation that combines any two elements into an element of the same set? You get a \textbf{magma}, where grouping can matter. Integer subtraction is an example:
\[
(8 - 4) - 2 = 2, \qquad \text{but} \qquad 8 - (4 - 2) = 6.
\]
Testing each boundary shows what each axiom contributes to the definition of a group. Figure~\ref{29:fig-group-monoid-magma} shows how the three classes sit inside one another.
\end{labbox}

\begin{historybox}
In 1891, while waiting for a train in a Berlin railway station on his way back from a mathematics meeting in Halle, David Hilbert remarked: ``One must be able to say at all times---instead of points, lines, and planes---tables, chairs, and beer mugs.'' Hilbert meant that geometry, as mathematics, is not a science of physical space. It does not matter whether a ``point'' is a speck of ink, an ordered pair of numbers, or a beer mug; what matters are only the relations the objects have with each other: incidence (which points lie on which lines), betweenness (which point lies between two others), and congruence (which segments and angles have the same size).

In his \emph{Grundlagen der Geometrie} of 1899, Hilbert wrote geometry this way, with every proof depending only on the stated axioms and none on pictures.

This led to the Frege-Hilbert correspondence, with most letters exchanged in 1899--1900; Frege published his criticism in 1903. The German logician Gottlob Frege criticized Hilbert's approach. Frege held the traditional view of definitions: a definition must describe a concept whose meaning is fixed before any axioms are stated. To Frege, asserting axioms about undefined terms was a game with empty words. Hilbert answered with the modern idea of \textbf{implicit definition}: mathematical objects are defined entirely by the axioms they satisfy. Whether we call the basic objects points and lines or tables and beer mugs, any collection of objects satisfying the axioms is a legitimate geometry.

Hilbert's axiomatic method became central to twentieth-century mathematics. When objects are defined by their axioms rather than by a physical model, a theorem applies to everything that satisfies those axioms. A theorem about groups applies at once to geometric rotations, to rearrangements of the roots of a polynomial (Galois theory, which uses this to explain why fifth-degree equations have no general formula built from arithmetic and $n$-th roots), and to the number systems used in modern cryptography.

Formal axiomatics also raised questions about mathematics itself. Hilbert hoped to prove, using only finite checks on strings of symbols, that the axioms of mathematics are consistent (never lead to a contradiction); this plan is called Hilbert's Program. In 1931, Kurt G\"odel showed with his Incompleteness Theorems that no consistent formal system containing basic arithmetic can prove its own consistency from within. Today, in interactive theorem provers such as Lean, Coq, and Isabelle (computer programs that check every step of a proof against the definitions), mathematicians face the ongoing challenge of writing definitions that human readers can understand and that the computer can check.
\end{historybox}

\subsection{Relational definitions---and the human reader}

Reading a definition by its four parts---ambient universe, input, defining condition, and what you may use afterward---tells you what to check when proving it and what you may use when it is given. Deleting one clause at a time shows why each condition is there, as dropping transitivity showed for partitions.

Axiomatic definitions do have a cost: without physical pictures, proofs can become dense sequences of symbols. When writing a proof for human readers, you must introduce variables cleanly, keep notation consistent, and make clear how long each assumption stays in force, so the reader can follow the argument.

Chapter~30, \textbf{Second Pass: Proofs as Programs for Human Readers}, compares the structure of a proof with the structure of a computer program, including how both keep track of which names and assumptions are in force at each point.

\begin{walkbox}
On your next walk, notice everyday definitions around you: a ``traffic stoplight,'' an ``academic degree,'' or a ``legal contract.'' Pick one and break it down into its four anatomical parts: what is the ambient universe, what is the input signature, what is the exact defining contract, and what downstream rights does it grant? What breaks down if you drop one of the requirements?
\end{walkbox}

\subsection{Exercises}

\subsubsection*{Part A: Quick Mental Checks}
\begin{enumerate}
\item For each of the following definitions, identify the \textbf{ambient universe}, the \textbf{input signature}, the \textbf{defining contract}, and the \textbf{downstream rights}:
\begin{enumerate}[label=(\alph*)]
\item A real sequence $(x_n)_{n=1}^\infty$ is \emph{bounded} if there exists a real number $M > 0$ such that $|x_n| \le M$ for all $n \in \N$.
\item A subset $U \subseteq \R$ is \emph{open} if for every $x \in U$, there exists $\eps > 0$ such that $(x - \eps, x + \eps) \subseteq U$.
\end{enumerate}

\item A student attempts to prove that $f: \R \to \R$ defined by $f(x) = 3x + 4$ is injective by writing:
\begin{quote}
``Assume $x_1 \neq x_2$. Then $3x_1 \neq 3x_2$ because $3 \neq 0$. Adding $4$ to unequal numbers gives unequal results, so $3x_1 + 4 \neq 3x_2 + 4$. Thus $f(x_1) \neq f(x_2)$.''
\end{quote}
While the student's arithmetic happens to work for this simple linear function, explain why this strategy fails for more complex functions such as $g(x) = x^3 - 3x$, and why setting $g(x_1) = g(x_2)$ gives you an equation to work with, which the inequality $x_1 \neq x_2$ does not.

\item In the definition of an equivalence relation, what happens if we drop \textbf{reflexivity}, keeping only symmetry and transitivity? A student argues: ``If $x \sim y$, then by symmetry $y \sim x$. Then by transitivity, $(x \sim y \land y \sim x) \implies x \sim x$, so reflexivity is redundant.'' Find the subtle flaw in the student's deduction.

\item In Euclid's first proposition, an equilateral triangle is constructed on a line segment $AB$ by drawing a circle centered at $A$ of radius $AB$ and a circle centered at $B$ of radius $AB$, and picking their intersection point $C$. What unstated physical assumption was Euclid making about the two circles?
\end{enumerate}

\subsubsection*{Part B: Dissecting and Stress-Testing Definitions}
\begin{enumerate}[resume]
\item A function $f: A \to B$ is \emph{surjective} (onto) if for every $b \in B$, there exists $a \in A$ such that $f(a) = b$.
\begin{enumerate}[label=(\alph*)]
\item Dissect this definition into its four anatomical parts.
\item What downstream rights do you gain when a proof hands you the hypothesis ``$f$ is surjective''?
\item What condition must you verify if your goal is to prove ``$f$ is surjective''?
\end{enumerate}

\item Consider the relation $\le$ on the set of real numbers $\R$.
\begin{enumerate}[label=(\alph*)]
\item Verify which of the three equivalence relation axioms (reflexivity, symmetry, transitivity) hold for $\le$, and which fail.
\item Because symmetry fails, $\le$ is not an equivalence relation. Since it is reflexive, transitive and antisymmetric ($x \le y$ and $y \le x$ together force $x = y$), it is a \emph{partial order} (Chapter~16). Explain geometrically why $\le$ cannot be used to partition $\R$ into disjoint clusters.
\end{enumerate}

\item Use the contrapositive definition of injectivity ($f(a_1) = f(a_2) \implies a_1 = a_2$) to prove that the rational function $f: \R \setminus \{1\} \to \R$ given by
\[
f(x) = \frac{2x + 3}{x - 1}
\]
is injective. Show every algebraic step, pointing out where downstream cancellation occurs.

\item A \emph{metric space} is a set $M$ equipped with a distance function $d: M \times M \to \R$ satisfying four axioms for all $x, y, z \in M$:
\begin{enumerate}[label=(\roman*)]
\item $d(x, y) \ge 0$ (non-negativity);
\item $d(x, y) = 0 \iff x = y$ (identity of indiscernibles);
\item $d(x, y) = d(y, x)$ (symmetry);
\item $d(x, z) \le d(x, y) + d(y, z)$ (triangle inequality).
\end{enumerate}
Stress-test this definition: what happens if we drop the direction $d(x, y) = 0 \implies x = y$ from axiom (ii), allowing distinct points to have zero distance between them? (Such a function is called a \emph{pseudometric}). Give a real-world example from daily life or physics where two distinct objects have a distance of zero under a natural measurement.
\end{enumerate}

\subsubsection*{Part C: Deeper Structural Thinking}
\begin{enumerate}[resume]
\item \textbf{Axiomatic Characterization versus Set-Theoretic Construction}: In Peano arithmetic (Chapter~17), the natural numbers are described by five axioms about a starting number and a successor function $S(n)$, the step from $n$ to the next number $n + 1$. (Here we start the count at $0$ rather than $1$, as set theorists do.) In axiomatic set theory, John von Neumann represented the natural numbers as concrete sets, each number being the set of all smaller numbers:
\[
0 = \emptyset, \qquad 1 = \{0\} = \{\emptyset\}, \qquad 2 = \{0, 1\} = \bigl\{\emptyset, \{\emptyset\}\bigr\}, \qquad \ldots
\]
\begin{enumerate}[label=(\alph*)]
\item In von Neumann's representation, the statement $1 \in 2$ is a true set-theoretic fact. Does the claim ``$1$ is an element of $2$'' have any meaning in elementary arithmetic?
\item Explain how Hilbert's relational view of definitions protects working mathematicians from asking meaningless questions about the particular set-theoretic implementation of mathematical objects.
\end{enumerate}

\item \textbf{The Non-Empty Universe Clause}: In abstract algebra, a \emph{group} $(G, *)$ is defined as a set $G$ with a binary operation $*$ satisfying associativity, containing an identity element $e \in G$, and providing an inverse $a^{-1} \in G$ for every element $a \in G$. Almost every textbook includes the upfront ambient clause: ``$G$ is a non-empty set.''
\begin{enumerate}[label=(\alph*)]
\item What happens to the identity axiom if $G = \emptyset$? Can an empty set contain an identity element?
\item If an author omitted the non-empty clause and relaxed the identity axiom so that the empty set counted as a group, what caveat would have to be attached to almost every theorem in group theory (such as Lagrange's theorem, which says that the number of elements of a subgroup divides the number of elements of the group)?
\end{enumerate}
\end{enumerate}
