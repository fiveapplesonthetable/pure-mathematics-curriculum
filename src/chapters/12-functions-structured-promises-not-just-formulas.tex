\section{Functions: Structured Promises, Not Just Formulas}
\chapterline

In the previous chapter, we treated sets as static collections. But mathematics also requires rules that assign elements from one set to another.

In elementary algebra and calculus, functions are usually introduced as formulas, such as $f(x) = x^2$ or $g(x) = \sin(x)$. You plug in a number, perform arithmetic, and obtain an output.

In pure mathematics, a formula is only one way to define a function. A \emph{function} is a rule connecting two sets: a domain of inputs and a codomain of possible outputs, specifying for each input exactly one output.

\begin{historybox}
The modern definition of a function came out of more than a century of argument. In 1718, Johann Bernoulli defined a function as ``any quantity composed in whatever manner of a variable and constants.'' Thirty years later, Leonhard Euler (\emph{Introductio in analysin infinitorum}, 1748) codified functions as expressions formed by algebraic operations or infinite series. 

This formula-based view triggered the famous 18th-century ``vibrating string controversy'' between Jean le Rond d'Alembert, Euler, and Daniel Bernoulli. If a plucked violin string is released from an initial triangular shape with a sharp corner, can that physical motion be described by a function? D'Alembert argued that a curve with a corner could not be a genuine function because it had no single continuous differential equation (an equation that relates a function to its rates of change); he insisted that calculus only applied to smooth curves, those with a derivative (an instantaneous rate of change, or tangent slope) at every point. Euler argued that the plucked string with a corner is an admissible function, even though no single formula describes it.

The breakthrough came in 1829 from Peter Gustav Lejeune Dirichlet while studying Fourier series (approximating complicated waves by adding together infinitely many smooth sine and cosine waves). Dirichlet realized that a function had to be separated from the demand for an algebraic formula. A function, Dirichlet proposed, is any assignment that pairs every input $x$ with a unique output $y$. To show how far this reaches beyond formulas, he introduced what is now called the Dirichlet function:
\[
\mathbf{1}_{\Q}(x) = \begin{cases} 1 & \text{if } x \in \Q, \\ 0 & \text{if } x \notin \Q, \end{cases}
\]
where $\Q$ denotes the rational numbers (fractions of integers) and $\mathbf{1}_{\Q}$ (read ``one-sub-$\Q$'') is the name of the function. It outputs $1$ on rational inputs and $0$ on all others. Dirichlet's function has no algebraic formula, cannot be drawn with a pen, and is discontinuous (its graph jumps) at every real number. Figure~\ref{fig:fn-dirichlet-sketch} gives a rough impression of its graph. Many mathematicians objected. Later in the century, after Karl Weierstrass exhibited continuous functions (graphs with no breaks) that have no derivative at any point, Charles Hermite wrote to Thomas Stieltjes (1893): ``I turn away with fright and horror from this lamentable plague of continuous functions which have no derivatives.''

Dirichlet's view won. Richard Dedekind and later Nicolas Bourbaki (the pen name of a group of French mathematicians, 1939) built it into modern set theory: a function is a subset of a Cartesian product (the set of all ordered pairs $(x, y)$ of elements from two sets) that obeys two rules, stated below.
\end{historybox}

\subsection{The Anatomy of a Function}

Formally, a function consists of three distinct components:
\begin{enumerate}[label=\arabic*.]
\item A set $A$ called the \textbf{domain} (the set of allowed inputs).
\item A set $B$ called the \textbf{codomain} (the set that every output is promised to lie in).
\item A rule or assignment that pairs \textbf{every} element $a \in A$ with \textbf{exactly one} element $b \in B$, denoted $f(a) = b$.
\end{enumerate}

We write this entire package in standard notation:
\[
f: A \to B \quad \text{(read: ``$f$ is a function from $A$ to $B$'')}.
\]

To make ``rule'' precise, we use the Cartesian product $A \times B$ from Chapter~10 (the set of all ordered pairs $(a, b)$ with $a \in A$ and $b \in B$). A function is identified with the set of its input--output pairs, which is called the \emph{graph} of the function.

\begin{definition}[Function]
Let $A$ and $B$ be sets. A \textbf{function} $f: A \to B$ is a subset $f \subseteq A \times B$ satisfying two structural conditions:
\begin{enumerate}[label=(\roman*)]
\item \textbf{Total Definition (no input left behind):} For every $a \in A$, there exists some $b \in B$ such that $(a, b) \in f$.
\item \textbf{Single-Valuedness (no input splits):} For every $a \in A$ and all $b_1, b_2 \in B$, if $(a, b_1) \in f$ and $(a, b_2) \in f$, then $b_1 = b_2$.
\end{enumerate}
When both conditions hold, we write $f(a) = b$ instead of $(a, b) \in f$.
\end{definition}

If you remember the ``vertical line test'' from calculus, you have already met single-valuedness. A vertical line at $x = a$ passes through all candidate pairs $(a, y)$. If the line hits two points on a graph, the single input $a$ is paired with two different outputs, which violates condition~(ii). If the vertical line misses the graph entirely for some $a$ in the declared domain, it breaks condition~(i). Figure~\ref{fig:fn-vertical-line} shows one curve that passes and two that fail.

\begin{intuitionbox}
Think of a function as an assignment table. Every element of the domain must appear in the table exactly once as an input, paired with a single value from the codomain. Multiple inputs may share the same output value, and some values in the codomain may never appear in the output column. But no input may be omitted, and no input may have two conflicting outputs.
\end{intuitionbox}

\begin{recoverybox}
\textbf{Pause and think:} Suppose $S = \{1, 2, 3\}$ and $T = \{a, b\}$. Is the set of pairs $P = \{(1, a), (2, b)\}$ a function from $S$ to $T$? What about $Q = \{(1, a), (2, b), (3, a), (1, b)\}$?

\emph{Check:} $P$ fails total definition because input $3 \in S$ has no assigned output. $Q$ fails single-valuedness because input $1$ is paired with both $a$ and $b$.
\end{recoverybox}

\subsection{Why the Formula Alone Is Incomplete}

Consider the squaring rule $x \mapsto x^2$ (read ``$x$ goes to $x^2$''; the arrow $\mapsto$ names a rule without giving the function a name or a domain). Stating only the formula leaves out half the specification. Watch how the behaviour of the function changes as we alter its domain and codomain. Below, $[0, \infty)$ is the set of all real numbers $y \ge 0$: the square bracket means the endpoint $0$ is included, and $\infty$ only signals that there is no right endpoint.

\begin{itemize}
\item \textbf{Function 1:} $f: \R \to \R$ with $f(x) = x^2$. 
Because negative numbers produce positive squares, $f(-2) = f(2) = 4$: two different inputs give the same output. We say the inputs \emph{collide}. Also, negative numbers in the codomain, such as $-7$, are never outputs.
\item \textbf{Function 2:} $g: \R \to [0, \infty)$ with $g(x) = x^2$.
Here, the codomain has been trimmed to match the actual outputs. Every target $y \ge 0$ is reached by at least one input ($x = \sqrt{y}$), but collisions still occur ($g(-2) = g(2) = 4$).
\item \textbf{Function 3:} $h: [0, \infty) \to [0, \infty)$ with $h(x) = x^2$.
Now negative inputs are removed from the domain. Collisions are gone, and every target in the codomain is hit. The square root undoes $h$: $\sqrt{h(x)} = x$ for every $x \ge 0$, and $h(\sqrt{y}) = y$ for every $y \ge 0$.
\end{itemize}

All three functions share the formula $x^2$, yet they behave differently. Three words name the differences; Chapter~13 studies them in detail. A function is \emph{surjective} if every element of the codomain is the output of at least one input. It is \emph{injective} if different inputs always give different outputs (no collisions). It is \emph{bijective} if it is both: then inputs and outputs are matched one-to-one, and the function can be run backwards. The backward function is called the \emph{inverse}; here the inverse of $h$ is $h^{-1}(y) = \sqrt{y}$. In these terms, $f$ is neither injective nor surjective, $g$ is surjective but not injective, and $h$ is bijective. Domain and codomain are part of the specification: changing either set produces a different function. Figure~\ref{fig:fn-same-formula} shows the three cases side by side.

\subsection{Codomain Versus Image}

A common mistake is to confuse the \emph{codomain} with the \emph{image} (some books call the image the \emph{range}, though others use ``range'' for the codomain, so the word is best avoided).

\begin{definition}[Image]
Let $f: A \to B$ be a function. The \textbf{image} of $f$, denoted $\operatorname{im}(f)$ or $f(A)$, is the subset of the codomain consisting of values that are actually achieved:
\[
\operatorname{im}(f) = \{f(a) \in B : a \in A\} = \{b \in B : (\exists a \in A)(f(a) = b)\}.
\]
\end{definition}

The codomain $B$ is the declared target set; the image $\operatorname{im}(f)$ is the set of values that actually occur as outputs. The image is always a subset of the codomain:
\[
\operatorname{im}(f) \subseteq B.
\]
When the image equals the entire codomain ($\operatorname{im}(f) = B$), the function is called \emph{surjective}.

\begin{example}[Finding the Image Rigorously]
Consider the function $f: \R \to \R$ defined by $f(x) = x^2 + 3$. The codomain is declared as the entire real line $\R$. What is the image?

To find $\operatorname{im}(f)$, we determine which real numbers $y \in \R$ can be expressed as $f(x)$ for some real input $x$.
Setting $y = x^2 + 3$, we solve for $x$:
\[
x^2 = y - 3 \implies x = \pm\sqrt{y - 3}.
\]
For $x$ to be a real number, the quantity under the square root must be non-negative: $y - 3 \ge 0$, which means $y \ge 3$. 
Conversely, if $y \ge 3$, the input $x = \sqrt{y - 3}$ is a well-defined real number in the domain $\R$, and
\begin{align*}
f(x) &= \bigl(\sqrt{y - 3}\,\bigr)^2 + 3 \\
     &= (y - 3) + 3 && \text{(because } y - 3 \ge 0\text{)} \\
     &= y.
\end{align*}
Thus the image is $\operatorname{im}(f) = [3, \infty)$, the set of real numbers $y \ge 3$. 

The number $-2$ lies in the declared codomain $\R$, but $-2 \notin \operatorname{im}(f)$. The codomain is the target set declared up front; the image is the subset of values the function actually reaches. Figure~\ref{fig:fn-codomain-image} shows both on the $y$-axis.
\end{example}

\begin{recoverybox}
\textbf{Pause and think:} Can the image of a function ever be empty?

\emph{Check:} If the domain $A$ has at least one element $a$, then $f(a)$ must exist by total definition, so the image contains at least that output. The image is empty if and only if the domain itself is the empty set $\emptyset$.
\end{recoverybox}

\subsection{Connection to Software Engineering}

In a programming language with types, each function declares the type of its input and the type of its output. This declaration, called the function's \emph{type signature}, plays the role of domain and codomain:
\begin{center}
\texttt{function processData(x: InputType): ReturnType}
\end{center}
Declaring \texttt{ReturnType} as \texttt{int64} (a 64-bit integer) does not mean the function produces every possible 64-bit integer; it promises that whatever it returns lies in that set. The codomain is the declared type; the image is the set of values the function ever returns.

The compiler (the program that translates source code into a runnable program) checks this type promise. It does not check the two conditions of the definition, which programmers must ensure themselves:
\begin{itemize}
\item A function that crashes, stops with an error that nothing catches, or runs forever on some valid inputs fails total definition. In computer science, such procedures are called \emph{partial functions}: they produce an output only for some inputs.
\item A function whose return value depends on something other than its input, such as a global variable that other code can change or the current time, violates single-valuedness: the same input can give different outputs on different calls. A function that always returns the same output for the same input (and changes nothing else) is called a \emph{pure function}. Pure functions are easier to test, and their results can be stored and reused instead of recomputed.
\end{itemize}
Figure~\ref{fig:fn-partial-impure} shows one small program of each kind.

\subsection{Properties of functions and the transition to injectivity and surjectivity}

Because a function need not have a formula, the same definition covers a lookup table, a rule given by cases (such as the Dirichlet function), and a reordering of the items in a finite list. Functions are the standard way to relate one set to another.

Knowing that an assignment $f: A \to B$ is a function tells you little about how much information it keeps or which outputs it reaches:
\begin{itemize}
\item \textbf{Information loss:} A constant function (one with the same output for every input) maps every element of a domain to a single value, discarding all distinctions between inputs.
\item \textbf{Coverage gaps:} The codomain could be the entire real line $\R$, while the actual outputs form only a small subset.
\item \textbf{Irreversibility:} If multiple inputs produce the same output, one cannot trace an output backward to a unique input.
\end{itemize}

\subsection{Exercises}

\begin{enumerate}
\item \textbf{Checking the Contract.} Determine whether each proposed rule defines a valid function. If not, identify which condition fails (total definition or single-valuedness):
\begin{enumerate}[label=(\alph*)]
\item $f: \R \to \R$ defined by $f(x) = 1/(x^2 - 4)$.
\item $g: \Q \to \Z$ defined by $g(p/q) = p + q$, where $p, q \in \Z$ with $q \neq 0$.
\item $h: \R \to \R$ defined by $h(x) = y$ where $y^2 = x$.
\item $k: \Z \to \Z$ defined by $k(n) = \sqrt{n^2}$.
\end{enumerate}

\item \textbf{Well-Definedness on Fractions.} When an input can be represented in multiple ways, single-valuedness requires checking that the output does not depend on the choice of representation. A rule that passes this check is called \emph{well-defined}:
\begin{enumerate}[label=(\alph*)]
\item Let $f: \Q \to \Q$ be defined by $f(p/q) = p^2 / q^2$. Prove that $f$ is a well-defined function: show that if $p_1/q_1 = p_2/q_2$, then $f(p_1/q_1) = f(p_2/q_2)$.
\item Contrast this with $g(p/q) = p + q$ from Exercise~1(b) by finding two equivalent fractions whose outputs disagree.
\end{enumerate}

\item \textbf{Determining the Image.} Let $f: \R \setminus \{1\} \to \R$ be the function given by 
\[
f(x) = \frac{2x+1}{x-1}.
\]
\begin{enumerate}[label=(\alph*)]
\item Prove that the number $2$ is not in the image of $f$.
\item Find the full image $\operatorname{im}(f)$, and prove that every real number $y \neq 2$ is in the image.
\end{enumerate}

\item \textbf{Counting Functions Between Finite Sets.} Let $A$ and $B$ be finite sets with $|A| = m$ elements and $|B| = n$ elements:
\begin{enumerate}[label=(\alph*)]
\item How many distinct functions exist from $A$ to $B$? Explain why the answer is $n^m$ and not $m^n$ using the definition of a function.
\item If $A = \{1, 2, 3\}$ and $B = \{a, b\}$, how many distinct functions exist from $A$ to $B$? How many exist from $B$ to $A$?
\end{enumerate}

\item \textbf{Equality of Functions.} Two functions $f: A \to B$ and $g: C \to D$ are defined to be equal ($f = g$) if and only if they have the same domain ($A = C$), the same codomain ($B = D$), and the same values ($f(x) = g(x)$ for all $x \in A$).
Consider the two functions
\[
f: \R \setminus \{2\} \to \R, \quad f(x) = \frac{x^2 - 4}{x - 2}, \qquad\text{and}\qquad g: \R \to \R, \quad g(x) = x + 2.
\]
Are $f$ and $g$ equal as functions? Explain why or why not.

\item \textbf{Images and Unions.} Let $f: A \to B$ be a function. For any subset $S \subseteq A$, define the image of $S$ by $f(S) = \{f(x) \in B : x \in S\}$. Prove using element chasing that for any two subsets $S_1, S_2 \subseteq A$,
\[
f(S_1 \cup S_2) = f(S_1) \cup f(S_2).
\]
\end{enumerate}
