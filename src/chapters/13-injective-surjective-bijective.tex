\section{Injective, Surjective, Bijective}
\chapterline

In Chapter~12, we viewed a function $f: A \to B$ as an assignment guaranteeing that every input in $A$ is paired with exactly one output in $B$. But that definition leaves open fundamental questions: a function might send many inputs to the same output, or miss large parts of the codomain entirely.

To understand how a mapping behaves, we ask three questions:
\begin{enumerate}[label=\arabic*.]
\item \textbf{Do distinct inputs always produce distinct outputs?} Or can different inputs collide at the same output?
\item \textbf{Does the mapping cover the entire codomain?} Or are some target elements missed?
\item \textbf{Can the process be run in reverse?} Can each output be traced backward to a unique input?
\end{enumerate}

These three questions define the core properties of mapping theory: \emph{injectivity} (no collisions), \emph{surjectivity} (full coverage), and \emph{bijectivity} (a perfect two-way pairing).

\begin{historybox}
Before the late nineteenth century, mathematicians had no universal vocabulary for classifying mappings. Functions were treated primarily as formulas, and whether an equation could be reversed was settled case by case. The language of injectivity, surjectivity, and bijectivity developed when Richard Dedekind and Georg Cantor investigated how to compare sizes of collections without counting them one by one.

In his 1888 treatise \emph{Was sind und was sollen die Zahlen?} (``What are numbers and what should they be?''), Dedekind offered a new characterization: \emph{a set $S$ is infinite if and only if there exists an injective function $f: S \to S$ that is not surjective.} An infinite set can be mapped injectively into a proper subset of itself without collisions.

Simultaneously, Cantor used bijections to define \emph{cardinality}: two sets have the same cardinality precisely when a bijection pairs their elements. Cantor showed that infinities come in distinct sizes: the counting numbers $\N$ cannot be put in bijection with the real numbers $\R$.

In the 1930s, the Bourbaki group codified the modern terms \emph{injection}, \emph{surjection}, and \emph{bijection}.
\end{historybox}

\subsection{Injectivity: Collision-Free Mappings}

\begin{definition}[Injective]
A function $f: A \to B$ is \textbf{injective} (or \textbf{one-to-one}) if for all $a_1, a_2 \in A$,
\[
f(a_1) = f(a_2) \implies a_1 = a_2.
\]
Equivalently, by contrapositive:
\[
a_1 \neq a_2 \implies f(a_1) \neq f(a_2).
\]
\end{definition}

An injective map preserves distinctions. If you take two genuinely distinct inputs, their outputs remain distinct. No two input arrows ever crash into the same destination point.

\begin{example}
The linear function $f: \R \to \R$ defined by $f(x) = 3x - 5$ is injective.
To prove this, we follow the definition directly: assume $f(a_1) = f(a_2)$ and deduce $a_1 = a_2$:
\[
3a_1 - 5 = 3a_2 - 5 \implies 3a_1 = 3a_2 \implies a_1 = a_2.
\]
Since $f(a_1) = f(a_2)$ forces $a_1 = a_2$, $f$ never merges distinct inputs.
\end{example}

\begin{example}[A Collision Failure]
The function $g: \R \to \R$ given by $g(x) = x^2$ fails to be injective. A single concrete counterexample suffices: $g(2) = 4$ and $g(-2) = 4$, yet $2 \neq -2$. The sign information is erased.
\end{example}

\begin{recoverybox}
\textbf{Pause and think:} Look closely at the two equivalent ways to define injectivity:
\[
f(a_1) = f(a_2) \implies a_1 = a_2 \qquad \text{versus} \qquad a_1 \neq a_2 \implies f(a_1) \neq f(a_2).
\]
The second statement reflects the direct geometric intuition: start with distinct inputs, get distinct outputs. Why, then, do mathematicians almost always prove injectivity using the first statement? Because assuming equality ($f(a_1) = f(a_2)$) gives you an equation with an equals sign that you can manipulate, factor, and simplify. By contrast, non-equality ($\neq$) has very few algebraic properties and is awkward to handle in deductively linked steps.
\end{recoverybox}

\subsection{Surjectivity: Covering the Target Space}

\begin{definition}[Surjective]
A function $f: A \to B$ is \textbf{surjective} (or \textbf{onto}) if for every element $b \in B$, there exists at least one element $a \in A$ such that
\[
f(a) = b.
\]
In set language: $\operatorname{im}(f) = B$. Recall from Chapter~12 that the image $\operatorname{im}(f) = \{f(a) \in B : a \in A\}$ is the actual set of outputs achieved by the mapping. Surjectivity guarantees that the image completely fills the designated codomain: no target elements are left unreached.
\end{definition}

\begin{example}
The cubic function $f: \R \to \R$ given by $f(x) = x^3$ is surjective.
To prove this, let $y \in \R$ be an arbitrary element of the codomain. We must exhibit an input $x \in \R$ satisfying $f(x) = y$.
We choose $x = \sqrt[3]{y}$. Since every real number has a unique real cube root, $x \in \R$, and
\[
f(x) = (\sqrt[3]{y})^3 = y.
\]
Thus every target $y$ is hit, and $f$ is surjective.
\end{example}

\begin{example}[An Uncovered Target]
The function $g: \R \to \R$ given by $g(x) = x^2$ is not surjective. Consider $y = -1 \in \R$. Since $x^2 \ge 0$ for all real numbers $x$, there is no real input satisfying $x^2 = -1$. No negative number in the codomain is ever reached.
\end{example}

\begin{recoverybox}
\textbf{Pause and think:} Notice that surjectivity is not an intrinsic property of a formula; it depends entirely on the declared codomain! If we replace the codomain $\R$ with the non-negative real numbers $[0, \infty)$, the function $h: \R \to [0, \infty)$ defined by $h(x) = x^2$ becomes fully surjective. Every $y \ge 0$ is reached by $x = \sqrt{y} \in \R$. Whenever you test for surjectivity, always check the declared codomain.
\end{recoverybox}

\subsection{Bijectivity: The Reversible Pairing}

\begin{definition}[Bijective]
A function $f: A \to B$ is \textbf{bijective} (or a \textbf{one-to-one correspondence}) if it is both injective and surjective.
\end{definition}

When a function is bijective, every single target in $B$ receives \emph{exactly one} arrow from $A$:
\begin{itemize}
\item Because $f$ is surjective, every target receives \textbf{at least one} arrow.
\item Because $f$ is injective, no target receives \textbf{more than one} arrow.
\end{itemize}
This establishes a one-to-one correspondence between the elements of $A$ and the elements of $B$.

\begin{theorem}
A function $f: A \to B$ is bijective if and only if there exists an inverse function $g: B \to A$ such that
\[
g(f(a)) = a \quad \text{for all } a \in A, \qquad \text{and} \qquad f(g(b)) = b \quad \text{for all } b \in B.
\]
\end{theorem}

We write $g = f^{-1}$. Why does the existence of an inverse require \emph{both} injectivity and surjectivity? Figure~\ref{13:fig-why-invertibility-needs-both} shows what happens when we reverse the arrows of a mapping:
\begin{itemize}
\item If $f$ is \textbf{not injective}, two inputs merge onto the same target. Turning the arrows around forces that single target to branch out toward two distinct destinations. The reversed rule fails \emph{single-valuedness}, so it is not a function.
\item If $f$ is \textbf{not surjective}, some targets in $B$ receive no incoming arrows at all. Turning the arrows around leaves those elements completely stranded with no outgoing path. The reversed rule fails \emph{total definition}, so it is not a function.
\end{itemize}
Only when every target in $B$ receives \emph{exactly one} incoming arrow does turning the arrows around produce a legitimate, lawful function from $B$ back to $A$.

\begin{proof}
We prove both directions of the equivalence.

($\implies$) Suppose $f$ is bijective. We must construct an inverse function $g: B \to A$ satisfying $g(f(a)) = a$ for all $a \in A$ and $f(g(b)) = b$ for all $b \in B$.

Let $b \in B$ be an arbitrary element of the codomain. Because $f$ is surjective, there exists at least one element $a \in A$ such that $f(a) = b$. Because $f$ is injective, this element $a$ is unique: if some $a' \in A$ also satisfies $f(a') = b$, then $f(a) = f(a')$, which forces $a = a'$. We may therefore define the rule $g: B \to A$ by setting $g(b) = a$. 

Because every $b \in B$ has such an $a$ (surjectivity) and only one such $a$ (injectivity), $g$ is a genuine, well-defined function from $B$ to $A$. To verify the cancellation properties:
\begin{itemize}
\item For any $b \in B$, $g(b)$ is the element $a$ such that $f(a) = b$, so evaluating $f$ gives $f(g(b)) = f(a) = b$.
\item For any $a \in A$, let $b = f(a)$. Then by our construction, $g(b)$ is the unique element that maps to $b$, which is $a$. Thus $g(f(a)) = g(b) = a$.
\end{itemize}

($\impliedby$) Conversely, suppose there exists a function $g: B \to A$ such that $g(f(a)) = a$ for all $a \in A$ and $f(g(b)) = b$ for all $b \in B$.
\begin{itemize}
\item \textbf{Injectivity:} Let $a_1, a_2 \in A$ and assume $f(a_1) = f(a_2)$. Apply $g$ to both sides:
\[
g(f(a_1)) = g(f(a_2)).
\]
Since $g(f(a)) = a$ for every input, the left side simplifies to $a_1$ and the right side simplifies to $a_2$. Hence $a_1 = a_2$, proving that $f$ is injective.
\item \textbf{Surjectivity:} Let $b \in B$ be arbitrary. We need to find an input $a \in A$ such that $f(a) = b$. Set $a = g(b) \in A$. Then $f(a) = f(g(b)) = b$. Every target element is reached, so $f$ is surjective.
\end{itemize}
Because $f$ is both injective and surjective, it is bijective.
\end{proof}

\subsubsection{A Geometric Bridge: The Horizontal Line Test}

If you have studied calculus, you likely encountered the ``horizontal line test'' to determine whether a graph $y = f(x)$ has an inverse. We can now see the exact logical machinery beneath that rule.

When you graph a real function $f: \R \to \R$, each horizontal line $y = c$ represents a single target value $c$ in the codomain. The intersection points $(x, c)$ between this line and the graph are the inputs that hit $c$:
\begin{itemize}
\item \textbf{Injective $\iff$ Every horizontal line intersects the graph at most once.} If a line hits two or more times, multiple inputs share that output height (a collision).
\item \textbf{Surjective $\iff$ Every horizontal line intersects the graph at least once.} If a line misses the graph entirely, that height is an uncovered target.
\item \textbf{Bijective $\iff$ Every horizontal line intersects the graph exactly once.} Every target height corresponds to a unique input, allowing you to reflect the graph across the line $y = x$ to obtain the graph of the inverse function $f^{-1}$.
\end{itemize}
Contrast this with the \textbf{Vertical Line Test} from Chapter~12: every vertical line $x = c$ must cross the graph exactly once simply for $f$ to be a valid function (single-valued and totally defined). The vertical test ensures a forward mapping exists; the horizontal test ensures it can be cleanly reversed.

\begin{intuitionbox}
For finite sets, injectivity says $|A| \le |B|$ (the Pigeonhole Principle: you cannot fit $n$ birds into fewer than $n$ holes without sharing). Surjectivity says $|A| \ge |B|$ (you need at least as many birds as nests to fill every nest). Therefore, bijectivity implies $|A| = |B|$.

For infinite sets, this exact principle resolves a paradox that stalled mathematics for centuries. In 1638, Galileo Galilei noticed in \emph{Two New Sciences} that every positive integer $n$ can be paired with its square $n^2$ ($1 \leftrightarrow 1, 2 \leftrightarrow 4, 3 \leftrightarrow 9$). This mapping is an exact bijection! Yet the squares become sparser and sparser, so most integers are not squares. Trapped by Euclid's classical axiom that ``the whole is greater than the part,'' Galileo concluded that one cannot speak of infinite sets being greater, lesser, or equal to one another. Dedekind and Cantor reversed this perspective: Euclid's axiom holds only for finite sets; for infinite sets, bijectivity \emph{is} the definition of equal cardinality!
\end{intuitionbox}

\begin{recoverybox}
\textbf{Pause and think:} Suppose $A$ and $B$ are finite sets of the same size: $|A| = |B| = n$. If a function $f: A \to B$ is injective, can it fail to be surjective?
No! Because $f$ is injective, its $n$ inputs land on $n$ distinct outputs in $B$. Since $B$ only has $n$ elements in total, those outputs must account for every single element of $B$. Thus, for finite sets of equal size, injectivity automatically guarantees surjectivity (and vice versa). But as Galileo discovered, for infinite sets this equivalence collapses completely: $f(n) = 2n$ from $\N$ to $\N$ is injective, but it misses all odd numbers!
\end{recoverybox}

\subsection{Standard Proof Blueprints}

When writing proofs, standard approaches apply:

\begin{focusbox}
\textbf{To prove that $f: A \to B$ is injective:}
\begin{enumerate}
\item Begin: ``Let $a_1, a_2 \in A$ and assume $f(a_1) = f(a_2)$.''
\item Use algebra and the definition of $f$ to unpack the equation.
\item End: ``Therefore $a_1 = a_2$. Hence $f$ is injective.''
\end{enumerate}

\textbf{To prove that $f: A \to B$ is surjective:}
\begin{enumerate}
\item Begin: ``Let $b \in B$ be an arbitrary element of the codomain.''
\item (On scratch paper, solve $f(a) = b$ for $a$.)
\item In your written proof: Define $a$, verify that $a \in A$, and evaluate: ``$f(a) = \dots = b$.''
\item End: ``Since $b \in B$ was arbitrary, $f$ is surjective.''
\end{enumerate}
\end{focusbox}

\begin{labbox}
Consider $f: \R \setminus \{2\} \to \R \setminus \{3\}$ given by
\[
f(x) = \frac{3x - 1}{x - 2}.
\]
\textbf{1. Injectivity:} Assume $f(x_1) = f(x_2)$:
\[
\frac{3x_1 - 1}{x_1 - 2} = \frac{3x_2 - 1}{x_2 - 2} \implies (3x_1 - 1)(x_2 - 2) = (3x_2 - 1)(x_1 - 2).
\]
Expanding both sides:
\[
3x_1 x_2 - 6x_1 - x_2 + 2 = 3x_1 x_2 - x_1 - 6x_2 + 2.
\]
Subtracting common terms yields $-6x_1 - x_2 = -x_1 - 6x_2$, which simplifies to $5x_2 = 5x_1$, so $x_1 = x_2$.

\textbf{2. Surjectivity:} Given an arbitrary $y \in \R \setminus \{3\}$, solve $y = \frac{3x - 1}{x - 2}$ for $x$:
\[
y(x - 2) = 3x - 1 \implies yx - 2y = 3x - 1 \implies x(y - 3) = 2y - 1 \implies x = \frac{2y - 1}{y - 3}.
\]
Because $y \neq 3$, the denominator is non-zero. If $x = 2$, then $2y - 1 = 2(y - 3) = 2y - 6$, leading to $-1 = -6$, an impossibility. Thus $x \in \R \setminus \{2\}$. Finally, evaluate $f(x)$ directly to verify the output:
\[
f(x) = f\left(\frac{2y - 1}{y - 3}\right) = \frac{3\left(\frac{2y - 1}{y - 3}\right) - 1}{\left(\frac{2y - 1}{y - 3}\right) - 2} = \frac{\frac{3(2y - 1) - (y - 3)}{y - 3}}{\frac{(2y - 1) - 2(y - 3)}{y - 3}} = \frac{6y - 3 - y + 3}{2y - 1 - 2y + 6} = \frac{5y}{5} = y.
\]
Because $y \in \R \setminus \{3\}$ was arbitrary, $f$ is surjective.
\end{labbox}

\begin{trapbox}
\textbf{Scratch work is not a proof of surjectivity.} When proving that $f: A \to B$ is surjective, your scratch work begins by setting $f(x) = y$ and solving for $x$. That algebra is essential for discovering the right input, but presenting it in that order assumes what you are trying to prove: that such an $x$ already exists!

In your formal proof, you must present the reasoning in the deductive order:
\begin{enumerate}
\item Start with an arbitrary target $y \in B$.
\item Introduce your candidate: ``Define $x = \dots$'' (using the formula found on scratch paper).
\item Verify that this $x$ actually lives in the domain $A$ (check denominators, signs, intervals).
\item Evaluate $f(x)$ and compute step by step until it simplifies to $y$.
\end{enumerate}
\end{trapbox}

\subsection{Finite Sets: The Pigeonhole Principle and Double Counting}

When we restrict our attention from arbitrary spaces to finite collections, the mapping properties of injectivity, surjectivity, and bijectivity give concrete relations between the sizes of the sets.

Consider two non-empty finite sets $A$ and $B$, with sizes $|A| = m$ and $|B| = n$.
An injective function $f: A \to B$ demands that every input element $a \in A$ receives its own distinct destination $f(a) \in B$. If each of the $m$ inputs requires an exclusive target, there must be at least as many targets as inputs:
\[
f \text{ is injective} \implies |A| \le |B|.
\]
Now state the contrapositive of this implication:
\[
|A| > |B| \implies f \text{ is not injective}.
\]
This simple observation is among the most versatile tools in discrete mathematics. If you attempt to map a larger set into a strictly smaller set, an output collision is mathematically unavoidable: there must exist two distinct inputs $a_1 \neq a_2 \in A$ that land on the exact same output $f(a_1) = f(a_2)$. 

In 1834, Peter Gustav Lejeune Dirichlet formalized this observation as the \emph{Schubfachprinzip} (``drawer principle''), known in English as the \textbf{Pigeonhole Principle}.

\subsubsection{The Generalized Pigeonhole Principle}

What happens when the domain is not just slightly larger than the codomain, but many times larger? If $10$ items are distributed among $3$ boxes, at least one box must receive not merely $2$ items, but at least $4$.

\begin{theorem}[Generalized Pigeonhole Principle]
Let $A$ and $B$ be non-empty finite sets with $|A| = m$ and $|B| = n$. For any function $f: A \to B$, there exists at least one element $b \in B$ whose preimage contains at least $\lceil m/n \rceil$ elements:
\[
|f^{-1}(\{b\})| \ge \left\lceil \frac{m}{n} \right\rceil.
\]
Here $\lceil x \rceil$ denotes the \emph{ceiling} of $x$---the smallest integer greater than or equal to $x$ (it rounds $x$ up to the next whole number). The set $f^{-1}(\{b\}) = \{a \in A : f(a) = b\}$ collects all inputs that land on $b$, and is called the \emph{fiber} (or \emph{preimage}) of $b$.
\end{theorem}

\begin{proof}
We proceed by contradiction. Suppose the conclusion is false: every target element $b \in B$ satisfies $|f^{-1}(\{b\})| \le \lceil m/n \rceil - 1$.
Because $f$ is a well-defined function, every input $a \in A$ has exactly one output $f(a)$, meaning each input belongs to exactly one fiber $f^{-1}(\{f(a)\})$. The fibers are mutually disjoint and their union is the entire domain $A$---they form a \emph{partition} of $A$. Summing the sizes of these fibers over all $n$ targets in $B$:
\[
m = |A| = \sum_{b \in B} |f^{-1}(\{b\})| \le \sum_{b \in B} \left( \left\lceil \frac{m}{n} \right\rceil - 1 \right) = n \left( \left\lceil \frac{m}{n} \right\rceil - 1 \right).
\]
By definition of the ceiling function, $\lceil x \rceil - 1 < x$ for any real number $x$. Setting $x = m/n$, we obtain:
\[
n \left( \left\lceil \frac{m}{n} \right\rceil - 1 \right) < n \cdot \frac{m}{n} = m.
\]
Combining these inequalities gives $m < m$, an impossibility. Therefore, at least one target $b \in B$ must satisfy $|f^{-1}(\{b\})| \ge \lceil m/n \rceil$.
\end{proof}

\begin{intuitionbox}
To minimize the maximum number of items in any single box, we distribute the $m$ items as evenly as possible. The most even distribution of $m$ items across $n$ boxes assigns either $\lfloor m/n \rfloor$ or $\lceil m/n \rceil$ items to each box. 

For $7$ items placed into $3$ boxes (illustrated in Figure~\ref{13:fig-pigeonhole-doublecount}, Panel~A), the most even distribution is $(3, 2, 2)$. If every box held at most $2$ items, the total number of items across all three boxes would be at most $3 \times 2 = 6$, leaving the 7th item unaccounted for. Thus at least one box must contain at least $\lceil 7/3 \rceil = 3$ items.
\end{intuitionbox}

Applying the Pigeonhole Principle often requires choosing the pigeonholes appropriately. In many problems, the boxes must be constructed from the mathematical context.

\begin{example}[Differences Divisible by $n$]
Let $n \in \N$ and let $S \subset \Z$ be any collection of $n+1$ distinct integers. Prove that there exist two distinct integers $x, y \in S$ whose difference $x - y$ is a multiple of $n$.

\textbf{Proof.}
By the division algorithm, dividing any integer by $n$ yields a remainder in the set:
\[
R = \{0, 1, 2, \dots, n-1\}.
\]
The set $R$ contains exactly $n$ possible remainders. These $n$ remainders are our pigeonholes.

Define the mapping $f: S \to R$ by $f(z) = z \bmod n$. The domain $S$ contains $n+1$ elements (the pigeons), while the codomain $R$ contains $n$ elements (the pigeonholes). 

Because $|S| = n + 1 > n = |R|$, the function $f$ cannot be injective. There exist distinct elements $x, y \in S$ such that $f(x) = f(y)$. Hence $x$ and $y$ share the exact same remainder $r \in R$:
\[
x = q_1 n + r \quad \text{and} \quad y = q_2 n + r \quad \text{for some } q_1, q_2 \in \Z.
\]
Subtracting the two expressions:
\[
x - y = (q_1 n + r) - (q_2 n + r) = (q_1 - q_2)n.
\]
Since $q_1 - q_2$ is an integer, $x - y$ is an exact multiple of $n$. 

To see this in action, pick $n = 5$ and choose $6$ arbitrary integers: $S = \{14, 23, 37, 51, 69, 93\}$. Computing each remainder modulo $5$:
\[
14 \equiv 4, \quad 23 \equiv 3, \quad 37 \equiv 2, \quad 51 \equiv 1, \quad 69 \equiv 4, \quad 93 \equiv 3 \pmod 5.
\]
Both $14$ and $69$ land in remainder box $4$; their difference $69 - 14 = 55 = 5 \times 11$ is a multiple of $5$. Both $23$ and $93$ land in remainder box $3$; their difference $93 - 23 = 70 = 5 \times 14$ is also a multiple of $5$. The Pigeonhole Principle guaranteed a collision before we computed a single remainder.
\end{example}

\begin{example}[Points in a $2 \times 2$ Square]
Suppose $5$ points are placed inside a $2 \times 2$ square $Q = [0, 2] \times [0, 2]$ in the plane. Prove that at least two of the points must lie within a Euclidean distance of at most $\sqrt{2}$ of each other.

\textbf{Proof.}
We partition the continuous $2 \times 2$ square into four $1 \times 1$ sub-squares:
\[
Q_1 = [0, 1] \times [0, 1], \quad Q_2 = [1, 2] \times [0, 1], \quad Q_3 = [0, 1] \times [1, 2], \quad Q_4 = [1, 2] \times [1, 2].
\]
If a point lies on an internal boundary shared by multiple sub-squares, assign it to any one of the adjacent squares arbitrarily. 

We have $5$ points and $4$ sub-squares. By the Pigeonhole Principle, at least one sub-square $Q_k$ must contain at least $\lceil 5/4 \rceil = 2$ points. Let these two points be $P_1 = (x_1, y_1)$ and $P_2 = (x_2, y_2)$.

Because both points lie inside the same $1 \times 1$ square $Q_k$, their horizontal and vertical coordinate separations are bounded:
\[
|x_1 - x_2| \le 1 \qquad \text{and} \qquad |y_1 - y_2| \le 1.
\]
The Euclidean distance $d(P_1, P_2)$ between them is bounded by the diagonal of the unit square:
\[
d(P_1, P_2) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2} \le \sqrt{1^2 + 1^2} = \sqrt{2} \approx 1.414.
\]
Observe the geometric constraint at work: even if four points are placed at the corners $(0,0), (2,0), (0,2), (2,2)$ to maximize their separation, any fifth point must enter an already occupied quadrant, forcing a separation of at most $\sqrt{2}$.
\end{example}

\subsubsection{Double Counting: Counting a 0--1 Grid by Rows vs. by Columns}

A bijection proves that $|A| = |B|$ by building a one-to-one correspondence between two sets. But what if we wish to establish an equality between two complicated combinatorial formulas where an explicit element-by-element matching is elusive?

The technique of \textbf{Double Counting} (or two-way counting) provides the answer. Instead of matching elements directly, we count the size of a single set of relational pairs in two distinct ways.

Let $A$ and $B$ be finite sets, and let $R \subseteq A \times B$ be a relation between them (a rule specifying which pairs $(a, b)$ are linked). We encode $R$ as an \emph{incidence matrix} $M \in \{0, 1\}^{|A| \times |B|}$---simply a rectangular grid of $0$s and $1$s where a $1$ signals that $a$ and $b$ are related, and a $0$ signals that they are not:
\[
M_{a, b} = \begin{cases} 1 & \text{if } (a, b) \in R, \\ 0 & \text{if } (a, b) \notin R. \end{cases}
\]
Now ask a simple question: \emph{How many total $1$s are present in the table?}

We can tally the total sum $S$ in two legitimate ways:
\begin{enumerate}
\item \textbf{Row by Row (Horizontal Sum):} Sum the entries across each row first, obtaining the row total $\text{row}(a) = \sum_{b \in B} M_{a, b}$, and then add all row totals together:
\[
S = \sum_{a \in A} \text{row}(a) = \sum_{a \in A} \left( \sum_{b \in B} M_{a, b} \right).
\]
\item \textbf{Column by Column (Vertical Sum):} Sum the entries down each column first, obtaining the column total $\text{col}(b) = \sum_{a \in A} M_{a, b}$, and then add all column totals together:
\[
S = \sum_{b \in B} \text{col}(b) = \sum_{b \in B} \left( \sum_{a \in A} M_{a, b} \right).
\]
\end{enumerate}
Because finite addition is commutative and associative, changing the order of summation leaves the grand total unchanged. We obtain the universal identity:
\[
\sum_{a \in A} \text{row}(a) = \sum_{b \in B} \text{col}(b).
\]
This identity is illustrated in Figure~\ref{13:fig-pigeonhole-doublecount}, Panel~B: summing the rows yields $3 + 2 + 3 + 2 = 10$, and summing the columns yields $2 + 3 + 2 + 3 = 10$. Both summations arrive at the same total.

\begin{example}[Euler's Handshake Lemma]
In graph theory, a \emph{graph} $G = (V, E)$ consists of dots (vertices $V$) connected by line segments (edges $E$). The \emph{degree} $\deg(v)$ of a vertex is the number of edges attached to $v$---in human terms, how many hands that person shook. In any finite graph, the sum of all vertex degrees equals twice the number of edges:
\[
\sum_{v \in V} \deg(v) = 2|E|.
\]

\textbf{Proof.}
Construct an incidence table where rows correspond to vertices $v \in V$ and columns correspond to edges $e \in E$. Set the cell entry to $1$ if vertex $v$ is an endpoint of edge $e$, and $0$ otherwise:
\[
M_{v, e} = \begin{cases} 1 & \text{if } v \in e, \\ 0 & \text{if } v \notin e. \end{cases}
\]
We evaluate the total number of $1$s in $M$ in two ways:
\begin{itemize}
\item \textbf{Summing across rows:} For a fixed vertex $v$, the row sum counts how many edges have $v$ as an endpoint. By definition, this is the degree $\deg(v)$. Summing across all vertices gives $\sum_{v \in V} \deg(v)$.
\item \textbf{Summing down columns:} For a fixed edge $e = \{u, w\}$, the edge connects exactly $2$ endpoints. Thus every single column contains exactly two $1$s. Summing across all $|E|$ edges gives $\sum_{e \in E} 2 = 2|E|$.
\end{itemize}
Equating both expressions yields $\sum_{v \in V} \deg(v) = 2|E|$. 

An immediate structural consequence follows: because $2|E|$ is an even integer, the sum of all vertex degrees must be even. Hence, the number of vertices with odd degree must be even (at any gathering, the number of people who have shaken hands an odd number of times is always even).
\end{example}

\begin{example}[Counting Committee-Chair Pairs]
Let $n, k \in \N$ with $1 \le k \le n$. Recall that the binomial coefficient $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ (read ``$n$ choose $k$'') represents the number of ways to select an unordered team of $k$ individuals from a pool of $n$ available candidates. Prove combinatorially that:
\[
k \binom{n}{k} = n \binom{n-1}{k-1}.
\]

\textbf{Proof.}
Rather than expanding into factorials $\frac{n!}{(k-1)!(n-k)!}$ and canceling terms algebraically, we count a single set in two ways.

Suppose from a pool of $n$ people, we want to form a committee of $k$ members, and from within that committee, select one person to serve as chair. Define the set of valid configurations:
\[
\mathcal{S} = \{(C, p) : C \subseteq P, \, |C| = k, \, p \in C\},
\]
where $P$ is the population of $n$ people, $C$ is a committee of size $k$, and $p \in C$ is the designated chair. We compute $|\mathcal{S}|$ from two viewpoints:
\begin{itemize}
\item \textbf{Viewpoint 1 (Choose committee first, then select chair):}
There are $\binom{n}{k}$ ways to choose the committee $C$ of size $k$ from the $n$ candidates. Once $C$ is fixed, there are $k$ choices for which committee member serves as chair $p$. The number of pairs is:
\[
|\mathcal{S}| = \binom{n}{k} \times k = k \binom{n}{k}.
\]
\item \textbf{Viewpoint 2 (Choose chair first, then fill remaining seats):}
There are $n$ ways to select the chair $p$ from the entire pool of $n$ people. Once the chair is established, the remaining $k-1$ committee members must be selected from the remaining $n-1$ available candidates. This can be done in $\binom{n-1}{k-1}$ ways. The number of pairs is:
\[
|\mathcal{S}| = n \times \binom{n-1}{k-1} = n \binom{n-1}{k-1}.
\]
\end{itemize}
Both viewpoints count the exact same set $\mathcal{S}$ of chair-committee pairs. Therefore, the two expressions must be equal:
\[
k \binom{n}{k} = n \binom{n-1}{k-1}.
\]
Double counting provides a combinatorial proof of algebraic identities by viewing a single set from two different perspectives.
\end{example}

\subsection{Summary and Looking Ahead}

Classifying functions into injections, surjections, and bijections provides the basic framework for comparing sets and understanding mappings:
\begin{itemize}
\item \textbf{Invertibility:} A function has a two-way inverse if and only if it is a bijection.
\item \textbf{Structure-preserving maps:} In abstract algebra (Chapter~21), two algebraic structures are isomorphic if there exists a structure-preserving bijection between them.
\item \textbf{Comparing infinities:} In Chapter~19, bijections allow us to compare infinite sets, showing that while $\N$, $\Z$, and $\Q$ share the same cardinality, the continuum $\R$ is strictly larger.
\end{itemize}

So far, we have studied functions element by element. In geometry, calculus, and topology, however, we often need to understand how a function acts on entire subsets---such as intervals, regions, or solution sets. In Chapter~14, we study \textbf{Images and Preimages}, examining how functions transform subsets in both forward and backward directions.

\subsection{Exercises}

\paragraph{Warm-Up Mental Checks}
\begin{enumerate}[label=\arabic*.]
\item Can an injective function exist from a set with $5$ elements to a set with $4$ elements? Can a surjective function exist from a set with $4$ elements to a set with $5$ elements? Justify each answer in one sentence using the Pigeonhole Principle.
\item Suppose $f: A \to B$ is a bijection with inverse function $f^{-1}: B \to A$. Must $f^{-1}$ also be a bijection? What is $(f^{-1})^{-1}$?
\item Consider the rule $f(x) = x^2$. Explain how changing the domain and codomain can make this mapping:
\begin{enumerate}[label=(\alph*)]
\item Injective but not surjective.
\item Surjective but not injective.
\item Bijective.
\end{enumerate}
\end{enumerate}

\paragraph{Routine Practice}
\begin{enumerate}[resume]
\item For each function, determine whether it is injective, surjective, or bijective. Provide rigorous proofs or explicit counterexamples:
\begin{enumerate}[label=(\alph*)]
\item $f: \Z \to \Z$ defined by $f(n) = 2n + 3$.
\item $g: \Q \to \Q$ defined by $g(x) = 2x + 3$.
\item $h: \R \to \R$ defined by $h(x) = x^3 - x$.
\item $k: \R \setminus \{1\} \to \R \setminus \{2\}$ defined by $k(x) = \frac{2x + 1}{x - 1}$. Find an explicit formula for its inverse $k^{-1}(y)$.
\end{enumerate}
\item Let $f: A \to B$ and $g: B \to C$ be functions. Prove that if both $f$ and $g$ are injective, their composition $g \circ f: A \to C$ is injective.
\item Prove that if $g \circ f$ is surjective, then $g$ must be surjective. Must $f$ also be surjective? Provide a proof or a concrete finite counterexample.
\end{enumerate}

\paragraph{Deeper Explorations}
\begin{enumerate}[resume]
\item \textbf{(Dedekind's Finite vs.\ Infinite Sets)} Let $A$ be a non-empty finite set with $|A| = n$, and let $f: A \to A$ be a function from $A$ to itself.
\begin{enumerate}[label=(\alph*)]
\item Prove that $f$ is injective if and only if $f$ is surjective.

\end{enumerate}

Prove that there exist two chosen integers such that one divides the other. \end{enumerate}
