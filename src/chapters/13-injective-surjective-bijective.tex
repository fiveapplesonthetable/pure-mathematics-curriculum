\section{Injective, Surjective, Bijective}
\chapterline

In Chapter~12, we viewed a function $f: A \to B$ as an assignment guaranteeing that every input in $A$ is paired with exactly one output in $B$. That definition leaves two things open: a function might send many inputs to the same output, and it might miss large parts of the codomain.

To understand how a function (also called a \emph{mapping}) behaves, we ask three questions:
\begin{enumerate}[label=\arabic*.]
\item \textbf{Do distinct inputs always produce distinct outputs?} Or can different inputs collide at the same output?
\item \textbf{Does the mapping cover the entire codomain?} Or are some target elements missed?
\item \textbf{Can the process be run in reverse?} Can each output be traced backward to a unique input?
\end{enumerate}

The three properties these questions ask about are called \emph{injectivity} (no collisions), \emph{surjectivity} (full coverage), and \emph{bijectivity} (a perfect two-way pairing). Figure~\ref{13:fig-three-properties} shows a small example of each.

\begin{historybox}
Before the late nineteenth century, mathematicians had no shared vocabulary for classifying mappings. Functions were treated mainly as formulas, and whether an equation could be reversed was settled case by case. The language of injectivity, surjectivity, and bijectivity developed when Richard Dedekind and Georg Cantor investigated how to compare sizes of collections without counting them one by one.

In his 1888 treatise \emph{Was sind und was sollen die Zahlen?} (``What are numbers and what should they be?''), Dedekind offered a new characterization: \emph{a set $S$ is infinite if and only if there exists an injective function $f: S \to S$ that is not surjective.} So an infinite set can be matched, without collisions, with a \emph{proper subset} of itself (a subset that leaves out at least one element). For example, sending each counting number $n$ to $2n$ matches all the counting numbers with only the even ones.

Around the same time, Cantor used bijections to define \emph{cardinality}, the size of a set, including an infinite one: two sets have the same cardinality exactly when a bijection pairs their elements. Cantor showed that infinities come in distinct sizes: the counting numbers $\N$ cannot be put in bijection with the real numbers $\R$.

In the 1950s, the Bourbaki group (French mathematicians who published together under the invented name Nicolas Bourbaki) fixed the modern terms \emph{injection}, \emph{surjection}, and \emph{bijection}.
\end{historybox}

\subsection{Injectivity: Collision-Free Mappings}

\begin{definition}[Injective]
A function $f: A \to B$ is \textbf{injective} (or \textbf{one-to-one}) if for all $a_1, a_2 \in A$,
\[
f(a_1) = f(a_2) \implies a_1 = a_2.
\]
Equivalently, by contrapositive:
\[
a_1 \neq a_2 \implies f(a_1) \neq f(a_2).
\]
\end{definition}

An injective function keeps different inputs apart: two different inputs always have different outputs, so no two arrows land on the same point of $B$.

\begin{example}
The linear function $f: \R \to \R$ defined by $f(x) = 3x - 5$ is injective.
To prove this, we follow the definition directly: assume $f(a_1) = f(a_2)$ and deduce $a_1 = a_2$:
\begin{align*}
3a_1 - 5 &= 3a_2 - 5 \\
3a_1 &= 3a_2 && \text{(add $5$ to both sides)} \\
a_1 &= a_2. && \text{(divide both sides by $3$)}
\end{align*}
Since $f(a_1) = f(a_2)$ forces $a_1 = a_2$, $f$ never merges distinct inputs.
\end{example}

\begin{example}[A Collision Failure]
The function $g: \R \to \R$ given by $g(x) = x^2$ fails to be injective. A single concrete counterexample suffices: $g(2) = 4$ and $g(-2) = 4$, yet $2 \neq -2$. Squaring forgets the sign of the input.
\end{example}

\begin{recoverybox}
\textbf{Pause and think:} Compare the two equivalent ways to state injectivity:
\[
f(a_1) = f(a_2) \implies a_1 = a_2 \qquad \text{versus} \qquad a_1 \neq a_2 \implies f(a_1) \neq f(a_2).
\]
The second statement matches the picture: start with distinct inputs, get distinct outputs. Why, then, do mathematicians almost always prove injectivity using the first statement? Because assuming $f(a_1) = f(a_2)$ gives you an equation that you can manipulate, factor, and simplify. There are far fewer valid moves with $\neq$; for instance, $a \neq b$ and $b \neq c$ do not imply $a \neq c$.
\end{recoverybox}

\subsection{Surjectivity: Covering the Target Space}

\begin{definition}[Surjective]
A function $f: A \to B$ is \textbf{surjective} (or \textbf{onto}) if for every element $b \in B$, there exists at least one element $a \in A$ such that
\[
f(a) = b.
\]
In set language: $\operatorname{im}(f) = B$. Recall from Chapter~12 that the image
\[
\operatorname{im}(f) = \{f(a) \in B : a \in A\}
\]
is the actual set of outputs achieved by the mapping. Surjectivity says that the image fills the whole declared codomain: no target element is left unreached.
\end{definition}

\begin{example}
The cubic function $f: \R \to \R$ given by $f(x) = x^3$ is surjective.
To prove this, let $y \in \R$ be an arbitrary element of the codomain. We must exhibit an input $x \in \R$ satisfying $f(x) = y$.
We choose $x = \sqrt[3]{y}$. Since every real number has a unique real cube root, $x \in \R$, and
\[
f(x) = (\sqrt[3]{y})^3 = y.
\]
Thus every target $y$ is hit, and $f$ is surjective.
\end{example}

\begin{example}[An Uncovered Target]
The function $g: \R \to \R$ given by $g(x) = x^2$ is not surjective. Consider $y = -1 \in \R$. Since $x^2 \ge 0$ for all real numbers $x$, there is no real input satisfying $x^2 = -1$. No negative number in the codomain is ever reached.
\end{example}

\begin{recoverybox}
\textbf{Pause and think:} Surjectivity is not a property of a formula alone; it depends on the declared codomain. If we replace the codomain $\R$ with the non-negative real numbers $[0, \infty)$, the function $h: \R \to [0, \infty)$ defined by $h(x) = x^2$ is surjective. Every $y \ge 0$ is reached by $x = \sqrt{y} \in \R$. Whenever you test for surjectivity, always check the declared codomain. Figure~\ref{13:fig-codomain-matters} shows the two cases side by side.
\end{recoverybox}

\subsection{Bijectivity: The Reversible Pairing}

\begin{definition}[Bijective]
A function $f: A \to B$ is \textbf{bijective} (or a \textbf{one-to-one correspondence}) if it is both injective and surjective.
\end{definition}

When a function is bijective, every target in $B$ receives \emph{exactly one} arrow from $A$:
\begin{itemize}
\item Because $f$ is surjective, every target receives \textbf{at least one} arrow.
\item Because $f$ is injective, no target receives \textbf{more than one} arrow.
\end{itemize}
So each element of $A$ is paired with exactly one element of $B$, and each element of $B$ with exactly one element of $A$. This is what \emph{one-to-one correspondence} means.

\begin{theorem}
A function $f: A \to B$ is bijective if and only if there exists an inverse function $g: B \to A$ such that
\[
g(f(a)) = a \quad \text{for all } a \in A, \qquad \text{and} \qquad f(g(b)) = b \quad \text{for all } b \in B.
\]
\end{theorem}

Such a $g$ is called the \emph{inverse} of $f$, because it undoes $f$; we write $g = f^{-1}$ (read ``$f$ inverse''; it does not mean $1/f$). Why does the existence of an inverse require \emph{both} injectivity and surjectivity? Figure~\ref{13:fig-why-invertibility-needs-both} shows what happens when we reverse the arrows of a mapping:
\begin{itemize}
\item If $f$ is \textbf{not injective}, two inputs merge onto the same target. Turning the arrows around forces that single target to branch out toward two distinct destinations. The reversed rule fails \emph{single-valuedness}, so it is not a function.
\item If $f$ is \textbf{not surjective}, some targets in $B$ receive no incoming arrows at all. Turning the arrows around leaves those elements with no outgoing arrow. The reversed rule fails \emph{total definition}, so it is not a function.
\end{itemize}
Only when every target in $B$ receives \emph{exactly one} incoming arrow does turning the arrows around produce a function from $B$ back to $A$.

\begin{proof}
We prove both directions of the equivalence.

($\implies$) Suppose $f$ is bijective. We must construct an inverse function $g: B \to A$ satisfying $g(f(a)) = a$ for all $a \in A$ and $f(g(b)) = b$ for all $b \in B$.

Let $b \in B$ be an arbitrary element of the codomain. Because $f$ is surjective, there exists at least one element $a \in A$ such that $f(a) = b$. Because $f$ is injective, this element $a$ is unique: if some $a' \in A$ also satisfies $f(a') = b$, then $f(a) = f(a')$, which forces $a = a'$. We may therefore define the rule $g: B \to A$ by setting $g(b) = a$. 

Because every $b \in B$ has such an $a$ (surjectivity) and only one such $a$ (injectivity), $g$ is a function from $B$ to $A$. We check the two equations in the theorem:
\begin{itemize}
\item For any $b \in B$, $g(b)$ is the element $a$ such that $f(a) = b$, so evaluating $f$ gives $f(g(b)) = f(a) = b$.
\item For any $a \in A$, let $b = f(a)$. Then by our construction, $g(b)$ is the unique element that maps to $b$, which is $a$. Thus $g(f(a)) = g(b) = a$.
\end{itemize}

($\impliedby$) Conversely, suppose there exists a function $g: B \to A$ such that $g(f(a)) = a$ for all $a \in A$ and $f(g(b)) = b$ for all $b \in B$.
\begin{itemize}
\item \textbf{Injectivity:} Let $a_1, a_2 \in A$ and assume $f(a_1) = f(a_2)$. Apply $g$ to both sides:
\[
g(f(a_1)) = g(f(a_2)).
\]
Since $g(f(a)) = a$ for every input, the left side simplifies to $a_1$ and the right side simplifies to $a_2$. Hence $a_1 = a_2$, proving that $f$ is injective.
\item \textbf{Surjectivity:} Let $b \in B$ be arbitrary. We need to find an input $a \in A$ such that $f(a) = b$. Set $a = g(b) \in A$. Then $f(a) = f(g(b)) = b$. Every target element is reached, so $f$ is surjective.
\end{itemize}
Because $f$ is both injective and surjective, it is bijective.
\end{proof}

\subsubsection{A Geometric Bridge: The Horizontal Line Test}

If you have studied calculus, you may have met the ``horizontal line test'' for deciding whether a function $y = f(x)$ has an inverse. The three definitions explain why it works.

When you graph a real function $f: \R \to \R$, each horizontal line $y = c$ represents a single target value $c$ in the codomain. The intersection points $(x, c)$ between this line and the graph are the inputs that hit $c$:
\begin{itemize}
\item \textbf{Injective $\iff$ Every horizontal line intersects the graph at most once.} If a line hits two or more times, multiple inputs share that output height (a collision).
\item \textbf{Surjective $\iff$ Every horizontal line intersects the graph at least once.} If a line misses the graph entirely, that height is an uncovered target.
\item \textbf{Bijective $\iff$ Every horizontal line intersects the graph exactly once.} Every target height corresponds to a unique input, allowing you to reflect the graph across the line $y = x$ to obtain the graph of the inverse function $f^{-1}$ (Figure~\ref{13:fig-inverse-reflection}).
\end{itemize}
Contrast this with the \textbf{Vertical Line Test} from Chapter~12: every vertical line $x = c$ must cross the graph exactly once for $f$ to be a function at all (single-valued and totally defined). The vertical test checks that the forward rule is a function; the horizontal test checks that it can be reversed. Figure~\ref{13:fig-horizontal-line-test} shows one example of each case of the horizontal test.

\begin{intuitionbox}
Recall from Chapter~10 that $|A|$ is the number of elements of a finite set $A$. For finite sets, an injective $f: A \to B$ forces $|A| \le |B|$: you cannot put $n$ birds into fewer than $n$ nests without two sharing (this is the Pigeonhole Principle, proved later in this chapter). A surjective $f$ forces $|A| \ge |B|$: you need at least as many birds as nests to fill every nest. Therefore, a bijection forces $|A| = |B|$.

For infinite sets, the same idea settles a puzzle that stood for centuries. In 1638, Galileo Galilei noticed in \emph{Two New Sciences} that every positive integer $n$ can be paired with its square $n^2$ ($1 \leftrightarrow 1, 2 \leftrightarrow 4, 3 \leftrightarrow 9$). This pairing is a bijection from the positive integers to the perfect squares. Yet the squares become sparser and sparser, so most integers are not squares (Figure~\ref{13:fig-galileo}). Holding on to Euclid's axiom that ``the whole is greater than the part,'' Galileo concluded that one cannot speak of infinite sets being greater, lesser, or equal to one another. Dedekind and Cantor took the opposite view: Euclid's axiom holds only for finite sets; for infinite sets, bijectivity \emph{is} the definition of equal cardinality.
\end{intuitionbox}

\begin{recoverybox}
\textbf{Pause and think:} Suppose $A$ and $B$ are finite sets of the same size: $|A| = |B| = n$. If a function $f: A \to B$ is injective, can it fail to be surjective?
No. Because $f$ is injective, its $n$ inputs land on $n$ distinct outputs in $B$. Since $B$ only has $n$ elements in total, those outputs must account for every element of $B$. Thus, for finite sets of equal size, injectivity guarantees surjectivity (and the reverse is also true). For infinite sets this fails, as Galileo's example suggests: $f(n) = 2n$ from $\N$ to $\N$ is injective, but it misses all odd numbers.
\end{recoverybox}

\subsection{Standard Proof Blueprints}

The definitions give a fixed outline for each kind of proof:

\begin{focusbox}
\textbf{To prove that $f: A \to B$ is injective:}
\begin{enumerate}
\item Begin: ``Let $a_1, a_2 \in A$ and assume $f(a_1) = f(a_2)$.''
\item Use algebra and the definition of $f$ to unpack the equation.
\item End: ``Therefore $a_1 = a_2$. Hence $f$ is injective.''
\end{enumerate}

\textbf{To prove that $f: A \to B$ is surjective:}
\begin{enumerate}
\item Begin: ``Let $b \in B$ be an arbitrary element of the codomain.''
\item (On scratch paper, solve $f(a) = b$ for $a$.)
\item In your written proof: Define $a$, verify that $a \in A$, and evaluate: ``$f(a) = \dots = b$.''
\item End: ``Since $b \in B$ was arbitrary, $f$ is surjective.''
\end{enumerate}
\end{focusbox}

\begin{labbox}
Consider $f: \R \setminus \{2\} \to \R \setminus \{3\}$ given by
\[
f(x) = \frac{3x - 1}{x - 2}.
\]
Figure~\ref{13:fig-lab-graph} shows its graph. The curve never meets the vertical line $x = 2$ (that input is excluded from the domain) or the horizontal line $y = 3$ (that output is excluded from the codomain), and every other horizontal line meets it exactly once. The two parts below prove this.

\textbf{1. Injectivity:} Assume $f(x_1) = f(x_2)$. Both denominators $x_1 - 2$ and $x_2 - 2$ are non-zero, so we may multiply both sides by $(x_1 - 2)(x_2 - 2)$:
\begin{align*}
(3x_1 - 1)(x_2 - 2) &= (3x_2 - 1)(x_1 - 2) \\
3x_1 x_2 - 6x_1 - x_2 + 2 &= 3x_1 x_2 - x_1 - 6x_2 + 2 && \text{(expand both sides)} \\
-6x_1 - x_2 &= -x_1 - 6x_2 && \text{(subtract $3x_1x_2 + 2$)} \\
5x_2 &= 5x_1 && \text{(add $6x_1 + 6x_2$)} \\
x_1 &= x_2.
\end{align*}

\textbf{2. Surjectivity:} Let $y \in \R \setminus \{3\}$ be arbitrary. On scratch paper, solve $f(x) = y$ for $x$:
\begin{align*}
y(x - 2) &= 3x - 1 && \text{(multiply by $x - 2$)} \\
yx - 2y &= 3x - 1 \\
x(y - 3) &= 2y - 1 && \text{(collect the terms with $x$)} \\
x &= \frac{2y - 1}{y - 3}. && \text{(divide by $y - 3$)}
\end{align*}
Now the proof itself. Define $x = (2y - 1)/(y - 3)$. Because $y \neq 3$, the denominator is non-zero, so $x$ is a real number. If $x = 2$, then $2y - 1 = 2(y - 3) = 2y - 6$, leading to $-1 = -6$, an impossibility. Thus $x \in \R \setminus \{2\}$. Finally, evaluate $f(x)$ directly to verify the output:
\begin{align*}
f(x) &= \frac{3 \cdot \dfrac{2y - 1}{y - 3} - 1}{\dfrac{2y - 1}{y - 3} - 2} \\[4pt]
&= \frac{3(2y - 1) - (y - 3)}{(2y - 1) - 2(y - 3)} && \text{(multiply top and bottom by $y - 3$)} \\[4pt]
&= \frac{6y - 3 - y + 3}{2y - 1 - 2y + 6} = \frac{5y}{5} = y.
\end{align*}
Because $y \in \R \setminus \{3\}$ was arbitrary, $f$ is surjective.
\end{labbox}

\begin{trapbox}
\textbf{Scratch work is not a proof of surjectivity.} When proving that $f: A \to B$ is surjective, your scratch work begins by setting $f(x) = y$ and solving for $x$. That algebra is essential for discovering the right input, but presenting it in that order assumes what you are trying to prove: that such an $x$ already exists.

In your formal proof, you must present the reasoning in the deductive order:
\begin{enumerate}
\item Start with an arbitrary target $y \in B$.
\item Introduce your candidate: ``Define $x = \dots$'' (using the formula found on scratch paper).
\item Verify that this $x$ lies in the domain $A$ (check denominators, signs, intervals).
\item Evaluate $f(x)$ and compute step by step until it simplifies to $y$.
\end{enumerate}
\end{trapbox}

\subsection{Finite Sets: The Pigeonhole Principle and Double Counting}

For finite sets, injectivity, surjectivity and bijectivity turn into statements about the sizes of the sets.

Consider two non-empty finite sets $A$ and $B$, with sizes $|A| = m$ and $|B| = n$.
An injective function $f: A \to B$ demands that every input element $a \in A$ receives its own distinct destination $f(a) \in B$. If each of the $m$ inputs requires an exclusive target, there must be at least as many targets as inputs:
\[
f \text{ is injective} \implies |A| \le |B|.
\]
Now state the contrapositive of this implication:
\[
|A| > |B| \implies f \text{ is not injective}.
\]
This short fact settles a surprising number of counting problems. If you map a larger set into a strictly smaller set, a collision is unavoidable: there must exist two distinct inputs $a_1 \neq a_2 \in A$ that land on the same output, $f(a_1) = f(a_2)$.

In 1834, Peter Gustav Lejeune Dirichlet formalized this observation as the \emph{Schubfachprinzip} (``drawer principle''), known in English as the \textbf{Pigeonhole Principle}: if more pigeons than holes, then some hole holds at least two pigeons.

\subsubsection{The Generalized Pigeonhole Principle}

What happens when the domain is many times larger than the codomain? If $10$ items are distributed among $3$ boxes, at least one box must receive at least $4$ items, since three boxes holding at most $3$ items each hold at most $9$.

\begin{theorem}[Generalized Pigeonhole Principle]
Let $A$ and $B$ be non-empty finite sets with $|A| = m$ and $|B| = n$. For any function $f: A \to B$, there exists at least one element $b \in B$ that is the output of at least $\lceil m/n \rceil$ elements of $A$:
\[
|f^{-1}(\{b\})| \ge \left\lceil \frac{m}{n} \right\rceil.
\]
Here $\lceil x \rceil$ denotes the \emph{ceiling} of $x$---the smallest integer greater than or equal to $x$ (it rounds $x$ up to the next whole number). The set $f^{-1}(\{b\}) = \{a \in A : f(a) = b\}$ collects all inputs that land on $b$, and is called the \emph{fiber} (or \emph{preimage}) of $b$. This notation makes sense for every function, even one that has no inverse function $f^{-1}$.
\end{theorem}

\begin{proof}
We proceed by contradiction. Suppose the conclusion is false: every target element $b \in B$ satisfies $|f^{-1}(\{b\})| \le \lceil m/n \rceil - 1$.
Because $f$ is a well-defined function, every input $a \in A$ has exactly one output $f(a)$, meaning each input belongs to exactly one fiber $f^{-1}(\{f(a)\})$. The fibers are mutually disjoint and their union is the entire domain $A$---they form a \emph{partition} of $A$. We add up the sizes of these fibers over all $n$ targets in $B$ (the sum $\sum_{b \in B}$ has one term for each $b \in B$), and use the fact that $\lceil x \rceil - 1 < x$ for every real number $x$ (the ceiling exceeds $x$ by less than $1$), with $x = m/n$:
\begin{align*}
m = |A| &= \sum_{b \in B} |f^{-1}(\{b\})| && \text{(the fibers partition $A$)} \\
&\le \sum_{b \in B} \left( \left\lceil \frac{m}{n} \right\rceil - 1 \right) && \text{(our assumption)} \\
&= n \left( \left\lceil \frac{m}{n} \right\rceil - 1 \right) && \text{($n$ equal terms)} \\
&< n \cdot \frac{m}{n} && \text{(since $\lceil m/n \rceil - 1 < m/n$)} \\
&= m.
\end{align*}
This chain gives $m < m$, an impossibility. Therefore, at least one target $b \in B$ must satisfy $|f^{-1}(\{b\})| \ge \lceil m/n \rceil$.
\end{proof}

\begin{intuitionbox}
To minimize the maximum number of items in any single box, we distribute the $m$ items as evenly as possible. The most even distribution of $m$ items across $n$ boxes assigns either $\lfloor m/n \rfloor$ or $\lceil m/n \rceil$ items to each box, where $\lfloor x \rfloor$, the \emph{floor} of $x$, is $x$ rounded down to a whole number.

For $7$ items placed into $3$ boxes (Figure~\ref{13:fig-pigeonhole-doublecount}), the most even distribution is $(3, 2, 2)$. If every box held at most $2$ items, the total number of items across all three boxes would be at most $3 \times 2 = 6$, leaving the 7th item unaccounted for. Thus at least one box must contain at least $\lceil 7/3 \rceil = 3$ items.
\end{intuitionbox}

The hard part of using the Pigeonhole Principle is usually deciding what the boxes are. In the next two examples we have to invent them.

\begin{example}[Differences Divisible by $n$]
Let $n \in \N$ and let $S \subset \Z$ be any collection of $n+1$ distinct integers. Prove that there exist two distinct integers $x, y \in S$ whose difference $x - y$ is a multiple of $n$.

\textbf{Proof.}
Every integer $z$ can be written as $z = qn + r$ with $q$ an integer and $0 \le r < n$ (this fact is called the \emph{division algorithm}; $r$ is the remainder when $z$ is divided by $n$). So dividing any integer by $n$ yields a remainder in the set:
\[
R = \{0, 1, 2, \dots, n-1\}.
\]
The set $R$ contains exactly $n$ possible remainders. These $n$ remainders are our pigeonholes.

Define the mapping $f: S \to R$ by $f(z) = z \bmod n$, the unique non-negative remainder in $R$ upon dividing $z$ by $n$ (so even for negative integers, $(-1) \bmod 5 = 4$ since $-1 = (-1)\cdot 5 + 4$). The domain $S$ contains $n+1$ elements (the pigeons), while the codomain $R$ contains $n$ elements (the pigeonholes). 

Because $|S| = n + 1 > n = |R|$, the function $f$ cannot be injective. There exist distinct elements $x, y \in S$ such that $f(x) = f(y)$. Hence $x$ and $y$ share the same remainder $r \in R$:
\[
x = q_1 n + r \quad \text{and} \quad y = q_2 n + r \quad \text{for some } q_1, q_2 \in \Z.
\]
Subtracting the two expressions:
\[
x - y = (q_1 n + r) - (q_2 n + r) = (q_1 - q_2)n.
\]
Since $q_1 - q_2$ is an integer, $x - y$ is a multiple of $n$. 

To see this in action, pick $n = 5$ and choose $6$ arbitrary integers: $S = \{14, 23, 37, 51, 69, 93\}$. Computing each remainder on division by $5$ (we write $a \equiv r \pmod 5$, read ``$a$ is congruent to $r$ mod $5$'', when $a$ and $r$ leave the same remainder):
\[
14 \equiv 4, \quad 23 \equiv 3, \quad 37 \equiv 2, \quad 51 \equiv 1, \quad 69 \equiv 4, \quad 93 \equiv 3 \pmod 5.
\]
Both $14$ and $69$ land in remainder box $4$; their difference $69 - 14 = 55 = 5 \times 11$ is a multiple of $5$. Both $23$ and $93$ land in remainder box $3$; their difference $93 - 23 = 70 = 5 \times 14$ is also a multiple of $5$. Figure~\ref{13:fig-remainder-boxes} draws this map. The Pigeonhole Principle guaranteed a collision before we computed a single remainder.
\end{example}

\begin{example}[Points in a $2 \times 2$ Square]
Suppose $5$ points are placed inside a $2 \times 2$ square $Q = [0, 2] \times [0, 2]$ in the plane. Prove that at least two of the points must lie within distance $\sqrt{2}$ of each other (ordinary straight-line distance).

\textbf{Proof.}
We cut the $2 \times 2$ square into four $1 \times 1$ sub-squares:
\begin{align*}
Q_1 &= [0, 1] \times [0, 1], & Q_2 &= [1, 2] \times [0, 1], \\
Q_3 &= [0, 1] \times [1, 2], & Q_4 &= [1, 2] \times [1, 2].
\end{align*}
If a point lies on an internal boundary shared by multiple sub-squares, assign it to any one of the adjacent squares arbitrarily. 

We have $5$ points and $4$ sub-squares. By the Pigeonhole Principle, at least one sub-square $Q_k$ must contain at least $\lceil 5/4 \rceil = 2$ points. Let these two points be $P_1 = (x_1, y_1)$ and $P_2 = (x_2, y_2)$.

Because both points lie inside the same $1 \times 1$ square $Q_k$, their horizontal and vertical coordinate separations are bounded:
\[
|x_1 - x_2| \le 1 \qquad \text{and} \qquad |y_1 - y_2| \le 1.
\]
The distance $d(P_1, P_2)$ between them is bounded by the diagonal of the unit square:
\[
d(P_1, P_2) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2} \le \sqrt{1^2 + 1^2} = \sqrt{2} \approx 1.414.
\]
Figure~\ref{13:fig-square-pigeonhole} shows the argument: even if four points are placed at the corners $(0,0)$, $(2,0)$, $(0,2)$ and $(2,2)$ to keep them far apart, a fifth point must enter a sub-square that already holds a point, and those two points are at most $\sqrt{2}$ apart.
\end{example}

\subsubsection{Double Counting: Counting a 0--1 Grid by Rows vs. by Columns}

A bijection proves that $|A| = |B|$ by building a one-to-one correspondence between two sets. Sometimes, though, we want to show that two counting formulas are equal and no such matching is easy to find.

The technique of \textbf{Double Counting} (or two-way counting) handles this. Instead of matching elements, we count one set of pairs in two different ways and set the two answers equal.

Let $A$ and $B$ be finite sets, and let $R \subseteq A \times B$ be a relation between them (a rule specifying which pairs $(a, b)$ are linked). We record $R$ in an \emph{incidence matrix} $M$: a rectangular grid of $0$s and $1$s with one row for each $a \in A$ and one column for each $b \in B$. The entry $M_{a,b}$ in row $a$ and column $b$ is $1$ if $a$ and $b$ are related and $0$ if they are not:
\[
M_{a, b} = \begin{cases} 1 & \text{if } (a, b) \in R, \\ 0 & \text{if } (a, b) \notin R. \end{cases}
\]
Now ask: \emph{how many $1$s are in the table?}

We can count this total $S$ in two ways:
\begin{enumerate}
\item \textbf{Row by Row (Horizontal Sum):} Sum the entries across each row first, obtaining the row total $\operatorname{row}(a) = \sum_{b \in B} M_{a, b}$, and then add all row totals together:
\[
S = \sum_{a \in A} \operatorname{row}(a) = \sum_{a \in A} \left( \sum_{b \in B} M_{a, b} \right).
\]
\item \textbf{Column by Column (Vertical Sum):} Sum the entries down each column first, obtaining the column total $\operatorname{col}(b) = \sum_{a \in A} M_{a, b}$, and then add all column totals together:
\[
S = \sum_{b \in B} \operatorname{col}(b) = \sum_{b \in B} \left( \sum_{a \in A} M_{a, b} \right).
\]
\end{enumerate}
Adding finitely many numbers gives the same total in any order and with any grouping (addition is \emph{commutative} and \emph{associative}), so the two totals are equal:
\[
\sum_{a \in A} \operatorname{row}(a) = \sum_{b \in B} \operatorname{col}(b).
\]
Figure~\ref{13:fig-doublecount-grid} shows an example: summing the rows gives $3 + 2 + 3 + 2 = 10$, and summing the columns gives $2 + 3 + 2 + 3 = 10$.

\begin{example}[Euler's Handshake Lemma]
In graph theory, a \emph{graph} $G = (V, E)$ consists of dots (vertices $V$) connected by line segments (edges $E$). The \emph{degree} $\deg(v)$ of a vertex is the number of edges attached to $v$---in human terms, how many hands that person shook. Each edge joins two different vertices, so we can think of an edge $e$ as the set $\{u, w\}$ of its two endpoints, and write $v \in e$ when $v$ is an endpoint of $e$. Figure~\ref{13:fig-handshake} shows a small example. In any finite graph, the sum of all vertex degrees equals twice the number of edges:
\[
\sum_{v \in V} \deg(v) = 2|E|.
\]

\textbf{Proof.}
Construct an incidence table where rows correspond to vertices $v \in V$ and columns correspond to edges $e \in E$. Set the cell entry to $1$ if vertex $v$ is an endpoint of edge $e$, and $0$ otherwise (the right half of Figure~\ref{13:fig-handshake} shows this table for the small example):
\[
M_{v, e} = \begin{cases} 1 & \text{if } v \in e, \\ 0 & \text{if } v \notin e. \end{cases}
\]
We evaluate the total number of $1$s in $M$ in two ways:
\begin{itemize}
\item \textbf{Summing across rows:} For a fixed vertex $v$, the row sum counts how many edges have $v$ as an endpoint. By definition, this is the degree $\deg(v)$. Summing across all vertices gives $\sum_{v \in V} \deg(v)$.
\item \textbf{Summing down columns:} For a fixed edge $e = \{u, w\}$, the edge connects exactly $2$ endpoints. Thus every column contains exactly two $1$s. Summing across all $|E|$ edges gives $\sum_{e \in E} 2 = 2|E|$.
\end{itemize}
Equating both expressions yields $\sum_{v \in V} \deg(v) = 2|E|$. 

A consequence: because $2|E|$ is an even integer, the sum of all vertex degrees must be even. Hence, the number of vertices with odd degree must be even (at any gathering, the number of people who have shaken hands an odd number of times is always even).
\end{example}

\begin{example}[Counting Committee-Chair Pairs]
Let $n, k \in \N$ with $1 \le k \le n$. Write $n! = 1 \cdot 2 \cdots n$ (read ``$n$ factorial''), with $0! = 1$. The binomial coefficient
\[
\binom{n}{k} = \frac{n!}{k!\,(n-k)!}
\]
(read ``$n$ choose $k$'') is the number of ways to select a team of $k$ people from a pool of $n$ candidates, where the order of selection does not matter. Prove, by counting rather than by algebra, that:
\[
k \binom{n}{k} = n \binom{n-1}{k-1}.
\]

\textbf{Proof.}
Rather than expanding both sides into factorials (each equals $n!/\bigl((k-1)!\,(n-k)!\bigr)$) and canceling terms, we count a single set in two ways.

Suppose from a pool of $n$ people, we want to form a committee of $k$ members, and from within that committee, select one person to serve as chair. Define the set of valid configurations:
\[
\mathcal{S} = \{(C, p) : C \subseteq P, \, |C| = k, \, p \in C\},
\]
where $P$ is the population of $n$ people, $C$ is a committee of size $k$, and $p \in C$ is the designated chair. Figure~\ref{13:fig-committee-grid} lists every such pair for $n = 4$ and $k = 2$. We compute $|\mathcal{S}|$ from two viewpoints:
\begin{itemize}
\item \textbf{Viewpoint 1 (Choose committee first, then select chair):}
There are $\binom{n}{k}$ ways to choose the committee $C$ of size $k$ from the $n$ candidates. Once $C$ is fixed, there are $k$ choices for which committee member serves as chair $p$. The number of pairs is:
\[
|\mathcal{S}| = \binom{n}{k} \times k = k \binom{n}{k}.
\]
\item \textbf{Viewpoint 2 (Choose chair first, then fill remaining seats):}
There are $n$ ways to select the chair $p$ from the entire pool of $n$ people. Once the chair is established, the remaining $k-1$ committee members must be selected from the remaining $n-1$ available candidates. This can be done in $\binom{n-1}{k-1}$ ways. The number of pairs is:
\[
|\mathcal{S}| = n \times \binom{n-1}{k-1} = n \binom{n-1}{k-1}.
\]
\end{itemize}
Both viewpoints count the same set $\mathcal{S}$ of chair-committee pairs. Therefore, the two expressions must be equal:
\[
k \binom{n}{k} = n \binom{n-1}{k-1}.
\]
A proof like this, which shows two formulas are equal because they count the same set, is called a \emph{combinatorial proof}.
\end{example}

\subsection{Summary and Looking Ahead}

Injections, surjections and bijections come back throughout the book:
\begin{itemize}
\item \textbf{Invertibility:} A function has a two-way inverse if and only if it is a bijection.
\item \textbf{Structure-preserving maps:} In abstract algebra (Chapter~21), two algebraic structures (sets with operations, such as the integers with addition) count as ``the same'', or \emph{isomorphic}, if there is a bijection between them that respects the operations.
\item \textbf{Comparing infinities:} In Chapter~19, bijections allow us to compare infinite sets, showing that while $\N$, $\Z$, and $\Q$ share the same cardinality, the real numbers $\R$ form a strictly larger set.
\end{itemize}

So far, we have studied functions element by element. In geometry and calculus, however, we often need to understand how a function acts on entire subsets---such as intervals, regions, or solution sets. In Chapter~14, we study \textbf{Images and Preimages}, examining how functions transform subsets in both forward and backward directions.

\subsection{Exercises}

\paragraph{Warm-Up Mental Checks}
\begin{enumerate}[label=\arabic*.]
\item Can an injective function exist from a set with $5$ elements to a set with $4$ elements? Can a surjective function exist from a set with $4$ elements to a set with $5$ elements? Justify each answer in one sentence using the Pigeonhole Principle.
\item Suppose $f: A \to B$ is a bijection with inverse function $f^{-1}: B \to A$. Must $f^{-1}$ also be a bijection? What is $(f^{-1})^{-1}$?
\item Consider the rule $f(x) = x^2$. Explain how changing the domain and codomain can make this mapping:
\begin{enumerate}[label=(\alph*)]
\item Injective but not surjective.
\item Surjective but not injective.
\item Bijective.
\end{enumerate}
\end{enumerate}

\paragraph{Routine Practice}
\begin{enumerate}[resume]
\item For each function, determine whether it is injective, surjective, or bijective. Provide rigorous proofs or explicit counterexamples:
\begin{enumerate}[label=(\alph*)]
\item $f: \Z \to \Z$ defined by $f(n) = 2n + 3$.
\item $g: \Q \to \Q$ defined by $g(x) = 2x + 3$.
\item $h: \R \to \R$ defined by $h(x) = x^3 - x$.
\item $k: \R \setminus \{1\} \to \R \setminus \{2\}$ defined by $k(x) = \dfrac{2x + 1}{x - 1}$. Find an explicit formula for its inverse $k^{-1}(y)$.
\end{enumerate}
\item Let $f: A \to B$ and $g: B \to C$ be functions. Their \emph{composition} $g \circ f: A \to C$ is the function that applies $f$ first and then $g$: $(g \circ f)(a) = g(f(a))$. Prove that if both $f$ and $g$ are injective, then $g \circ f$ is injective.
\item Prove that if $g \circ f$ is surjective, then $g$ must be surjective. Must $f$ also be surjective? Provide a proof or a concrete finite counterexample.
\end{enumerate}

\paragraph{Deeper Explorations}
\begin{enumerate}[resume]
\item \textbf{(Dedekind's Finite vs.\ Infinite Sets)} Let $A$ be a non-empty finite set with $|A| = n$, and let $f: A \to A$ be a function from $A$ to itself.
\begin{enumerate}[label=(\alph*)]
\item Prove that $f$ is injective if and only if $f$ is surjective.
\item Give an explicit example of a function $g: \N \to \N$ that is injective but not surjective. Explain how this connects to Dedekind's definition of an infinite set from the history box.
\end{enumerate}
\item \textbf{(Divisibility in a Subset of Integers)} Suppose $n+1$ distinct integers are chosen from the set $\{1, 2, \dots, 2n\}$. Prove that there exist two chosen integers such that one divides the other. (\emph{Hint:} Write each chosen integer in the form $2^k \cdot m$, where $m$ is an odd positive integer, and identify the $n$ possible odd parts as the pigeonholes.)
\item \textbf{(Double Counting Triangular Numbers)} Use double counting to prove the identity $\sum_{k=1}^{n} k = \binom{n+1}{2}$ by counting pairs of integers $\{x, y\} \subseteq \{1, 2, \dots, n+1\}$ with $x < y$, grouped by the value of the larger element $y$.
\end{enumerate}
