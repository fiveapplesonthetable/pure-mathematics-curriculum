\section{Second Pass: Relations, Classification, and Quotients}
\chapterline

In Chapter~32, we used a function to split its domain into fibers: groups of inputs that share the same output. But that required a target space and a map to be given in advance. Often we want to reshape a space from within: gluing boundaries together to form a torus, ignoring fine-grained distinctions, or grouping integers by remainder.

The tool for this is the \emph{equivalence relation}: a rule that says which differences to keep track of and which elements to treat as the same object.

\begin{historybox}
In 1801, a 24-year-old Carl Friedrich Gauss published \emph{Disquisitiones Arithmeticae}, tackling a problem that had slowed number theory for generations: mathematicians treated division remainders ($a = qm + r$) as individual numerical values rather than mathematical objects with their own arithmetic laws. Gauss introduced modular congruence: $a \equiv b \pmod m$, meaning $a$ and $b$ leave the same remainder when divided by $m$, just like hours wrapping around a clock dial. Rather than computing with single integers, Gauss recognized that congruence bundles the infinite integers $\Z$ into a finite system of cyclical classes. Contemporaries questioned the notation, asking why one could not keep writing the equation $a - b = km$. Gauss proved that congruences behave like equality itself, allowing one to add and multiply whole classes of numbers: $[a] + [b] = [a+b]$.

A century later in 1920s G\"ottingen, Emmy Noether made equivalence classes a central tool of abstract algebra. Earlier nineteenth-century algebra relied heavily on explicit, coordinate-dependent polynomial computations. Leopold Kronecker resisted non-constructive sets and abstract classes (stating, ``God made the integers, all else is the work of man''), while Paul Gordan initially questioned abstract methods in invariant theory, the study of polynomial expressions that stay unchanged when the variables are transformed (he called Hilbert's non-constructive proof ``theology, not mathematics''). Noether developed a structural approach. She recognized that whenever a homomorphism $\phi$ connects algebraic systems, the kernel $\ker(\phi)$ (the collection of all inputs that map to the identity) induces an equivalence relation. Its quotient structure $G/\ker(\phi)$---the space formed by regarding each fiber as a single element---is isomorphic to the image. Her First Isomorphism Theorem, $G/\ker\phi \cong \operatorname{im}\phi$, replaced lengthy coordinate computations with structural arguments.

The general \emph{classification problem} is still open: given an equivalence relation, can we decide which class an object belongs to by computing concrete labels for it, such as numbers, that are equal exactly for equivalent objects? (Such labels are called \emph{invariants}.) In modern descriptive set theory (the study of infinite sets that can be described by explicit formulas), Alexander Kechris and Greg Hjorth in the 1990s investigated when such invariants exist. They discovered the phenomenon of \emph{turbulence}: many natural equivalence relations, including some that arise in the study of chaotic motion, are provably so complex that no collection of numbers or discrete tags can ever tell their classes apart. The boundary between classifiable equivalence relations and turbulent ones remains an active area in mathematical logic.
\end{historybox}

\subsection{The Equivalence Machine: Reflexive, Symmetric, Transitive}

Before we can build equivalence classes, we need the general concept of a relation. A \emph{binary relation} $\sim$ on a set $A$ is a rule that inspects ordered pairs: given two elements $a, b \in A$, the relation declares either ``yes, $a$ is related to $b$'' (written $a \sim b$) or ``no, they are not'' ($a \nsim b$). Formally, $\sim$ is a subset of the Cartesian product $A \times A$, consisting of all pairs $(a, b)$ that satisfy the condition. So a relation on a small set can be drawn as a grid with a dot for each related pair, or as arrows between elements (Figure~\ref{33:fig-relation-grid} below).

A binary relation in general can be any set of pairs at all. For a relation to behave like equality (``these two count as the same''), it must satisfy three laws:
\begin{enumerate}
  \item \textbf{Reflexivity}: For all $a \in A$, $a \sim a$. (Every element is related to itself.)
  \item \textbf{Symmetry}: For all $a, b \in A$, if $a \sim b$, then $b \sim a$. (The relation works the same in both directions.)
  \item \textbf{Transitivity}: For all $a, b, c \in A$, if $a \sim b$ and $b \sim c$, then $a \sim c$. (Connections chain across intermediate elements.)
\end{enumerate}
A relation with all three properties is an \emph{equivalence relation}.

To see why all three are needed, look at relations where some of the rules fail:
\begin{itemize}
  \item \textbf{Strict inequality ($<$) on $\R$}: Transitivity holds ($1 < 2$ and $2 < 5$ give $1 < 5$), but reflexivity fails ($1 \not< 1$) and symmetry fails ($1 < 2$ but $2 \not< 1$).
  \item \textbf{Proximity (``within $1$ kilometer'')}: This relation is reflexive (you are within $0$ km of yourself) and symmetric (if Alice is near Bob, Bob is near Alice). But transitivity fails: Alice is $800$ meters from Bob, and Bob is $800$ meters from Charlie, yet Alice can be $1600$ meters from Charlie. Because transitivity fails, geographic proximity does not divide a population into disjoint subsets; instead, proximity neighborhoods overlap.
\end{itemize}

\begin{recoverybox}
\textbf{Mental check:} Let $A = \{1, 2, 3\}$. Consider the relation
\[
R = \{(1, 1), (2, 2), (3, 3), (1, 2), (2, 1)\} \subseteq A \times A.
\]
\begin{enumerate}[label=(\alph*)]
  \item Verify whether $R$ is reflexive, symmetric, and transitive.
  \item Find the equivalence class $[a] = \{x \in A : x \sim a\}$ for each element $a \in A$.
\end{enumerate}
\emph{Answer:} (a) Reflexivity holds because $(1, 1), (2, 2)$, and $(3, 3)$ all belong to $R$. Symmetry holds because the only off-diagonal pairs are $(1, 2)$ and $(2, 1)$, which mirror each other. For transitivity, chaining $(1, 2)$ and $(2, 1)$ requires $(1, 1) \in R$ (present), and chaining $(2, 1)$ and $(1, 2)$ requires $(2, 2) \in R$ (present). Thus $R$ is an equivalence relation. (b) For $1$, all elements related to $1$ are $[1] = \{1, 2\}$. Similarly, $[2] = \{1, 2\} = [1]$. For $3$, no off-diagonal pairs touch $3$, so $[3] = \{3\}$. The distinct classes $\{[1], [3]\} = \{\{1, 2\}, \{3\}\}$ partition $\{1, 2, 3\}$ into two disjoint blocks. Figure~\ref{33:fig-relation-grid} draws $R$ in two ways.
\end{recoverybox}

\begin{theorem}[The Fundamental Partition Theorem]
Let $\sim$ be an equivalence relation on a non-empty set $A$. Then the collection of equivalence classes $\{[a] : a \in A\}$ forms a partition of $A$:
\begin{enumerate}
  \item \textbf{Exhaustion}: Every element $x \in A$ belongs to at least one equivalence class ($x \in [x]$).
  \item \textbf{Disjointness}: Any two equivalence classes $[a]$ and $[b]$ are either completely identical or completely disjoint:
  \[
  [a] = [b] \quad \text{or} \quad [a] \cap [b] = \emptyset.
  \]
\end{enumerate}
Conversely, every partition of $A$ into non-empty disjoint blocks defines a unique equivalence relation whose classes are precisely the blocks of the partition.
\end{theorem}

\begin{proof}
Item (1) follows from reflexivity: for any $x \in A$, $x \sim x$, so $x \in [x]$.

For item (2), suppose $[a] \cap [b] \neq \emptyset$. We must prove that $[a] = [b]$.

Since the intersection is non-empty, choose an element $c \in [a] \cap [b]$. By definition of equivalence classes:
\[
c \sim a \quad \text{and} \quad c \sim b.
\]
By symmetry, $c \sim a$ implies $a \sim c$. Since $a \sim c$ and $c \sim b$, transitivity yields $a \sim b$.

Now let $y \in [a]$ be arbitrary. Then $y \sim a$. Because $y \sim a$ and $a \sim b$, transitivity guarantees that $y \sim b$, which means $y \in [b]$. Since $y$ was arbitrary, this establishes $[a] \subseteq [b]$.

By an identical argument swapping the roles of $a$ and $b$ (noting $b \sim a$ by symmetry), we obtain $[b] \subseteq [a]$. By mutual subset inclusion, $[a] = [b]$.

Finally, for the converse: given a partition $\mathcal{P} = \{B_i\}_{i \in I}$ of $A$, declare $x \sim y$ if and only if $x$ and $y$ lie in the same block $B_i$. Since each $x$ lies in a unique block, $x$ shares its block with itself (reflexive), sharing a block is mutual (symmetric), and if $x, y \in B_i$ and $y, z \in B_j$, uniqueness of the block containing $y$ forces $B_i = B_j$, so $x, z \in B_i$ (transitive). The equivalence classes are exactly the sets $B_i$.
\end{proof}

\subsection{The Well-Definedness Trap and Wild Quotients}

Passing from individual elements to equivalence classes introduces two classic hazards:

\begin{itemize}
  \item \textbf{The Well-Definedness Criterion}: Formulas on a quotient set $X/\!\sim$ (the set of all equivalence classes, Chapter~15) are almost always written by picking a representative $a$ of the class $[a]$ and applying some rule $f(a)$. Because a single class $[a]$ has many different names, you have to check that picking another representative $a' \sim a$ produces the exact same result:
  \[
  a \sim a' \implies f(a) = f(a').
  \]
  If that check fails, the proposed rule $F([a]) = f(a)$ depends on the name you picked rather than the class itself, so it is not \emph{well-defined} and does not define a function at all. For example, the rational numbers $\Q$ can be built as classes $[(p, q)]$ of integer pairs with $q \neq 0$ (think of $(p, q)$ as the fraction $p/q$), under the relation
  \[
  (p, q) \sim (r, s) \iff ps = qr.
  \]
  Attempting to define the ``numerator'' by $N([(p, q)]) = p$ is invalid, because one class has two names that give different answers:
  \[
  [(1, 2)] = [(2, 4)], \quad\text{but}\quad N([(1, 2)]) = 1 \neq 2 = N([(2, 4)]).
  \]
  Figure~\ref{33:fig-rationals-lattice} shows why: a class is a whole line of integer points through the origin, and the numerator changes as you move along the line. In contrast, addition
  \[
  [(p, q)] + [(r, s)] = [(ps + qr,\, qs)]
  \]
  is well-defined: cross-multiplication confirms that replacing $(p, q)$ or $(r, s)$ with equivalent pairs leaves the resulting class unchanged. Try it with two names for $\tfrac12$:
  \begin{align*}
  [(1, 2)] + [(1, 3)] &= [(1 \cdot 3 + 2 \cdot 1,\, 2 \cdot 3)] = [(5, 6)],\\
  [(2, 4)] + [(1, 3)] &= [(2 \cdot 3 + 4 \cdot 1,\, 4 \cdot 3)] = [(10, 12)],
  \end{align*}
  and indeed $(10, 12) \sim (5, 6)$ because $10 \cdot 6 = 60 = 12 \cdot 5$.

  \item \textbf{Quotient Topologies and Lost Separation}: Recall from Chapter~22 that a topology on a set is its collection of open sets. When we glue the points of a space $X$ together, let $\pi$ be the map that sends each point $x$ to its class $[x]$. The quotient gets the \emph{quotient topology}: a set $U$ of classes counts as open exactly when $\pi^{-1}(U)$, the set of all original points lying in those classes, is open in $X$. A space is called \emph{Hausdorff} if any two distinct points can be placed inside two open sets that do not overlap; the real line and the plane are Hausdorff. Gluing can destroy this property even when the starting space is as ordinary as the real line.
  
  For example, consider the real line $\R$ and identify (declare equivalent) any two points that differ by a rational number: $x \sim y \iff x - y \in \Q$. The class of $x$ is the set $x + \Q = \{x + r : r \in \Q\}$, called a \emph{coset} of $\Q$ (as in Chapter~32). Each coset is dense in the real line: every open interval, however short, contains a point of every coset. By the definition of the quotient topology, a set $U$ in the quotient $\R/\Q$ is open exactly when $\pi^{-1}(U)$ is open in $\R$. If $U$ is non-empty, $\pi^{-1}(U)$ is a non-empty open subset of $\R$, so it contains some open interval, and therefore a point from every coset. But $\pi^{-1}(U)$ is a union of whole cosets (it collects everything that $\pi$ sends into $U$), so it must contain every coset entirely: $\pi^{-1}(U) = \R$, and $U$ is the whole space. As a result, the quotient topology on $\R/\Q$ is the indiscrete topology: the only open sets are the empty set and the entire space. No two distinct points can be separated by disjoint open sets, so the quotient is not Hausdorff. Figure~\ref{33:fig-dense-cosets} contrasts the two situations.

\begin{recoverybox}
\textbf{Mental check:} Consider $\Z/6\Z$, the integers modulo $6$. We want to define a map $H: \Z/6\Z \to \Z/m\Z$ using the rule $H([x]_6) = [x]_m$. For which values of $m \in \{2, 3, 4\}$ is $H$ well-defined?
\begin{enumerate}[label=(\alph*)]
  \item Test $m = 3$.
  \item Test $m = 4$.
\end{enumerate}
\emph{Answer:} (a) For $m = 3$, suppose $[x]_6 = [x']_6$. Then $x - x' = 6k = 3(2k)$ for some integer $k$. Thus $x \equiv x' \pmod 3$, which means $[x]_3 = [x']_3$. The map is well-defined. (b) For $m = 4$, in $\Z/6\Z$ we have $[0]_6 = [6]_6$. But $H([0]_6) = [0]_4$, while $H([6]_6) = [6]_4 = [2]_4$. Since $[0]_4 \neq [2]_4$, the rule produces conflicting outputs for the same class. In general, $H([x]_n) = [x]_m$ is well-defined if and only if $m$ divides $n$.
\end{recoverybox}

\subsection{Quotients: Turning Classes into Points}

Once we have partitioned a set $A$ into equivalence classes, we can treat each equivalence class as an element in its own right in a new space. 

This new space is the \emph{quotient set}, denoted $A/\!\sim$:
\[
A/\!\sim\; = \{[a] : a \in A\}.
\]
Accompanying this set is the \emph{canonical quotient map} (also called the canonical projection) $\pi: A \to A/\!\sim$, defined by $\pi(x) = [x]$, which sends each original element to its home class. The word ``canonical'' means that the map requires no arbitrary choices; the equivalence relation itself dictates where each point must go.

Figure~\ref{33:fig-clock-modular} shows this for arithmetic modulo $4$. The integers $\mathbb{Z}$ form an infinite line partitioned into four congruence classes modulo $4$. The canonical projection $\pi: \mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$ wraps the infinite line around a four-position clock dial, collapsing the infinite fiber $\{\dots, -4, 0, 4, 8, \dots\}$ into the single point $[0]$, and similarly for each remainder class.

\subsection{The First Isomorphism Theorem}

As Figure~\ref{33:fig-first-isomorphism} shows, any function $f: X \to Y$ induces an equivalence relation on its domain:
\[
x \sim x' \iff f(x) = f(x').
\]
The equivalence classes $[x]$ are precisely the \emph{fibers} of the function---the inverse images $f^{-1}(\{y\})$ of individual points in the target space. 

The canonical projection map $\pi: X \to X/\!\sim$ sends each element to its equivalence class. The induced map $\bar{f}$ then connects the quotient directly to the image:

\begin{theorem}[The First Isomorphism Theorem for Sets]
Let $f: X \to Y$ be a function. Define the fiber equivalence relation on $X$ by:
\[
x \sim x' \iff f(x) = f(x').
\]
Let $\pi: X \to X/\!\sim$ be the canonical quotient projection, $\pi(x) = [x]$. Then:
\begin{enumerate}
  \item There exists a unique function $\bar{f}: X/\!\sim\; \to \operatorname{im}(f)$ such that $f = \bar{f} \circ \pi$.
  \item The induced function $\bar{f}$ is a bijection, so $X/\!\sim$ and $\operatorname{im}(f)$ are isomorphic as sets (for sets, an isomorphism is a bijection):
  \[
  X/\!\sim\; \cong \operatorname{im}(f).
  \]
\end{enumerate}
\end{theorem}

\begin{proof}
To satisfy $f = \bar{f} \circ \pi$, we must have, for every $x \in X$,
\[
f(x) = \bar{f}\bigl(\pi(x)\bigr) = \bar{f}([x]).
\]
This determines the formula: we are forced to define $\bar{f}([x]) = f(x)$.

We check three properties:
\begin{enumerate}
  \item \textbf{Well-definedness}: If $[x] = [x']$, then $x \sim x'$. By definition of the relation, this means $f(x) = f(x')$. Hence $\bar{f}([x]) = \bar{f}([x'])$, so the output does not depend on which representative we picked. This proves existence and uniqueness of the map $\bar{f}$.
  \item \textbf{Injectivity}: Suppose $\bar{f}([x]) = \bar{f}([x'])$. By definition of $\bar{f}$, this means $f(x) = f(x')$. By definition of $\sim$, this gives $x \sim x'$, which implies $[x] = [x']$. So different classes never share an output.
  \item \textbf{Surjectivity}: Let $y \in \operatorname{im}(f)$ be arbitrary. By definition of the image, there exists some $x \in X$ such that $f(x) = y$. Then $\bar{f}([x]) = f(x) = y$. So every element of the image is an output of $\bar{f}$.
\end{enumerate}
Therefore, $\bar{f}$ is a well-defined bijection between $X/\!\sim$ and $\operatorname{im}(f)$.
\end{proof}

In abstract algebra, where $f: G \to H$ is a group homomorphism, the fiber over the identity $e_H$ is the kernel $\ker(f)$. The equivalence classes are the cosets $g\ker(f)$, classes are multiplied by $[a][b] = [ab]$, and $\bar{f}$ preserves the group operation because $f$ does:
\begin{align*}
\bar{f}([a][b]) &= \bar{f}([ab]) && \text{(how classes are multiplied)}\\
&= f(ab) && \text{(definition of } \bar{f}\text{)}\\
&= f(a)\,f(b) && \text{(} f \text{ is a homomorphism)}\\
&= \bar{f}([a])\,\bar{f}([b]) && \text{(definition of } \bar{f}\text{)}.
\end{align*}
The set bijection $\bar{f}$ yields a group isomorphism: $G/\ker(f) \cong \operatorname{im}(f)$.

To see the First Isomorphism Theorem geometrically before turning to boundary gluing, consider the squared-distance function $f: \mathbb{R}^2 \to [0, \infty)$ defined by $f(x, y) = x^2 + y^2$. Figure~\ref{33:fig-concentric-circles} illustrates how the fiber equivalence relation decomposes the plane into concentric circles centered at the origin. The canonical quotient projection $\pi$ identifies each circle with a single element, while the induced bijection $\bar{f}$ pairs each circle with its unique radius squared, yielding a quotient space identified with the half-line $[0, \infty)$.

As illustrated in Figure~\ref{33:fig-geometric-gluing}, three standard spaces come from simple identifications:
\begin{itemize}
  \item \textbf{The Circle $S^1$}: Take the unit interval $[0, 1] \subset \R$. Identify only the two boundary endpoints: $0 \sim 1$, leaving all interior points $t \sim t$ alone. The quotient is a closed loop: the circle $S^1$.
  \item \textbf{The Torus $T^2$}: Take the flat unit square $[0, 1] \times [0, 1]$. Glue the left edge to the right edge with matching orientation, meaning the arrows on the two edges point the same way ($(0, y) \sim (1, y)$), rolling the square into a hollow tube or cylinder. Then bend the tube and glue the bottom circular boundary to the top circular boundary ($(x, 0) \sim (x, 1)$). The resulting quotient is the 2-dimensional torus $T^2$, the surface of a doughnut.
  \item \textbf{The Möbius Strip}: Take $[0, 1] \times [0, 1]$ and glue the vertical ends with a half-twist: $(0, y) \sim (1, 1-y)$. The opposite arrowheads in the figure mean the strip must be given a half-twist before the ends meet. The resulting quotient is \emph{non-orientable}: a small clockwise circle drawn on the surface and slid once around the center line comes back as a counterclockwise circle. The surface has only one side, and its edge is a single loop.
\end{itemize}

\subsection{What Quotients Make Possible, and Their Limits}

Quotients made several major constructions possible:
\begin{enumerate}
  \item \textbf{Construction of the Continuum}: The real numbers $\R$ can be constructed rigorously from the rational numbers $\Q$. A Cauchy sequence is a sequence of fractions whose terms eventually stay as close to one another as you like; a null sequence is one that converges to zero. Declare two Cauchy sequences equivalent whenever their difference is a null sequence. The equivalence classes are the real numbers: the quotient fills in the gaps of $\Q$ (such as $\sqrt{2}$) and gives the real line $\R$.
  \item \textbf{Building Spaces by Gluing}: Manifolds (spaces that look like flat $\R^n$ near every point, as a sphere looks like a flat plane up close; Chapter~23) are often constructed by gluing simple flat pieces, such as triangles, along their edges and faces. For example, the real projective plane $\mathbb{RP}^2$ is built from a hemisphere by identifying each point $p$ on its boundary circle with the opposite point $-p$ (the \emph{antipodal} point, directly across the center).
  \item \textbf{Decomposition of Symmetries}: In group theory, quotient groups $G/N$ (built like $G/\ker\phi$ in Chapter~32) let algebraists break complicated groups into \emph{simple} groups: groups that cannot be broken down further, because their only quotients are the one-element group and the group itself. The Jordan--H\"older theorem guarantees that every finite group breaks down into such simple pieces in an essentially unique way, and this factoring motivated the decades-long Classification of Finite Simple Groups, the collaborative project that listed every possible finite simple group.
\end{enumerate}

\paragraph{Scope and Limitations.}
Quotient constructions also carry hazards:
\begin{itemize}
  \item \textbf{Badly Behaved Quotient Topologies}: A quotient of a smooth manifold can fail to be Hausdorff, as $\R/\Q$ did above, or fail to look like flat $\R^n$ near some point, creating sharp cone points (like the tip of a cone) or orbifolds (spaces that look locally like flat Euclidean space divided by a finite group of rotations).
  \item \textbf{Choosing Representatives and Non-Measurable Sets}: In an infinite quotient space, there is often no continuous or algorithmic rule to select a single representative from each class. To pick one anyway, mathematicians use the \emph{Axiom of Choice}, the rule of set theory that says: from any collection of non-empty sets, one can choose one element from each set, even when no recipe for the choice can be written down. In $\R/\Q$, using the Axiom of Choice to pick one representative from each coset, inside $[0, 1]$, gives the Vitali set: a subset of the real line so scattered that it cannot be assigned any consistent length or probability (it is \emph{non-measurable}).
\end{itemize}

\paragraph{Where We Go Next in the Book.}
Chapter~34 (\emph{Second Pass: Induction Beyond Formulas}) returns to induction. It goes past summation formulas to the Well-Ordering Principle (every non-empty set of natural numbers has a smallest element) and to structural induction, which proves facts about objects built step by step, such as trees and the expressions a compiler reads.

\subsection{Exercises}

\begin{enumerate}
  \item \textbf{Conceptual and Mental Warm-ups}:
  \begin{enumerate}
    \item If $\sim$ is an equivalence relation on a non-empty set $A$, can an equivalence class $[a]$ ever be empty? Explain using reflexivity.
    \item If $a \sim b$, what is $[a] \cap [b]$? What is $[a] \cup [b]$?
    \item Give a concrete relation on $\{1, 2, 3\}$ that is reflexive and symmetric, but fails transitivity.
  \end{enumerate}

  \item \textbf{Concentric Circles in $\R^2$}:
  Let $\sim$ be the relation on $\R^2$ defined by $(x_1, y_1) \sim (x_2, y_2)$ if and only if $x_1^2 + y_1^2 = x_2^2 + y_2^2$.
  \begin{enumerate}
    \item Verify that $\sim$ is an equivalence relation on $\R^2$.
    \item Describe the equivalence class $[(0, 0)]$. For any $(x_0, y_0) \neq (0, 0)$, what geometric shape is $[(x_0, y_0)]$?
    \item Consider the radius map $r: \R^2 \to [0, \infty)$ defined by $r(x, y) = \sqrt{x^2 + y^2}$. Show that $\sim$ is the fiber relation of $r$, and deduce that $\R^2/\!\sim\; \cong [0, \infty)$ as sets.
  \end{enumerate}

  \item \textbf{Modular Congruence on $\Z$}:
  Define a relation on $\Z$ by $a \sim b \iff 4 \mid (a - b)$.
  \begin{enumerate}
    \item Prove that $\sim$ is an equivalence relation.
    \item Write out the four distinct equivalence classes $[0], [1], [2], [3]$ using set notation.
    \item Prove that class addition $[a] + [b] = [a+b]$ and class multiplication $[a] \cdot [b] = [ab]$ are well-defined: if $a \sim a'$ and $b \sim b'$, prove that $(a+b) \sim (a'+b')$ and $(ab) \sim (a'b')$.
  \end{enumerate}

  \item \textbf{The Exponential Map and the Circle}:
  Let $\C^\times$ denote the nonzero complex numbers, and let $f: \R \to \C^\times$ be the map
  \[
  f(t) = e^{2\pi i t} = \cos(2\pi t) + i \sin(2\pi t).
  \]
  \begin{enumerate}
    \item Identify the image $\operatorname{im}(f) \subset \C^\times$.
    \item Show that $f(s) = f(t)$ if and only if $s - t \in \Z$.
    \item Apply the First Isomorphism Theorem for Sets to conclude that $\R/\Z \cong S^1$.
  \end{enumerate}

  \item \textbf{Constructing the Rational Numbers $\Q$ (Challenge)}:
  Let $S = \Z \times (\Z \setminus \{0\})$, the set of pairs of integers $(p, q)$ with nonzero denominator $q$. Define a relation on $S$ by:
  \[
  (p, q) \sim (r, s) \iff ps = qr.
  \]
  \begin{enumerate}
    \item Prove that $\sim$ is an equivalence relation on $S$. (Be careful: where exactly does your proof of transitivity use the fact that denominators are nonzero?)
    \item Define addition on equivalence classes by $[(p, q)] + [(r, s)] = [(ps + qr, qs)]$. Prove that this operation is well-defined.
    \item Why does the formula $N([(p, q)]) = p$ fail to define a function on $S/\!\sim$?
  \end{enumerate}

  \item \textbf{The Real Projective Line $\mathbb{RP}^1$ (Geometry Challenge)}:
  On the punctured plane $V = \R^2 \setminus \{(0, 0)\}$, define two nonzero vectors to be equivalent, $v_1 \sim v_2$, if there exists a nonzero real number $\lambda \in \R^\times$ such that $v_1 = \lambda v_2$. The quotient $\mathbb{RP}^1 := V/\!\sim$ is called the \emph{real projective line}.
  \begin{enumerate}
    \item Prove that $\sim$ is an equivalence relation.
    \item Show that each equivalence class $[(x, y)]$ is an entire straight line passing through the origin (minus the origin itself).
    \item Show that each equivalence class $[(x, y)]$ intersects the unit circle $S^1 = \{(x, y) \in \R^2 : x^2 + y^2 = 1\}$ in exactly two antipodal (opposite) points,
    \[
    \pm \frac{(x, y)}{\sqrt{x^2 + y^2}}.
    \]
    Conclude that $\mathbb{RP}^1 \cong S^1/(p \sim -p)$. (Figure~\ref{33:fig-projective-line} shows the picture.)
  \end{enumerate}
