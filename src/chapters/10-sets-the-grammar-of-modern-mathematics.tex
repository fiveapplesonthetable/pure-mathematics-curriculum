\section{Sets: The Grammar of Modern Mathematics}
\chapterline

Earlier chapters used collections freely: the even integers, the interval $(0, 1)$ (all real numbers strictly between $0$ and $1$), the vertices of a cube. Mathematics handles every such collection with one idea, the \textbf{set}.

A set is a collection of distinct objects that is \emph{well defined}: for any object, there is a definite yes-or-no answer to whether it belongs. The objects belonging to a set are called its \textbf{elements} (or members). We write:
\begin{align*}
x \in A &\quad \text{to assert that } x \text{ is an element of } A, \\
x \notin A &\quad \text{to assert that } x \text{ is not an element of } A.
\end{align*}

Most objects in later mathematics are built as sets with some extra structure. For example, the plane is the set of its points together with a way of measuring distance, and the symmetries of a square form a set together with a rule for combining two symmetries into one.

\begin{historybox}
In the 1870s, the German mathematician Georg Cantor invented set theory while studying a concrete puzzle in calculus: can a complicated curve always be represented in a unique way by adding up infinite sine and cosine waves (a trigonometric series)? To track the tricky points where two representations might disagree, Cantor found himself repeatedly collecting points, then collecting the points that those points crowd toward, and collecting the results again. He realized that to work rigorously with infinite collections, mathematics needed a language that could treat infinite collections not as vague ongoing processes, but as completed objects in their own right.

Cantor's bold step provoked fierce resistance. Prominent contemporaries viewed infinite sets as unnatural or dangerous; Leopold Kronecker argued that ``God made the integers, all else is the work of man,'' while Henri Poincar\'e warned that future generations would regard set theory as a disease from which mathematics had recovered.

At the turn of the twentieth century, Gottlob Frege sought to silence the critics by grounding all of arithmetic in set theory in his two-volume \emph{Grundgesetze der Arithmetik} (\emph{Basic Laws of Arithmetic}). Frege relied on what seemed like an obvious truth, called \emph{Unrestricted Comprehension}: any condition you can state describes a set, namely the set of all objects that satisfy it. Set theory built on this rule, without further restrictions, is now called \emph{naive set theory}. In June 1902, the British philosopher Bertrand Russell sent Frege a brief letter that showed naive set theory contradicts itself. Russell asked: what happens if you consider the set $R$ of all sets that do not contain themselves?
\[
R = \{x : x \notin x\}.
\]
(Read this as ``the set of all $x$ such that $x \notin x$.'') If $R$ is not an element of itself, it meets the entrance condition, so it must belong to $R$. But if $R$ does belong to $R$, it fails the condition, so it cannot belong to $R$. Either answer leads to a contradiction, so no such set can exist, yet Frege's rule said it must. Frege wrote in an appendix that a scientist can hardly meet with anything more undesirable than having their foundation collapse just as the work is finished.

Mathematicians led by Ernst Zermelo (1908) and Adolf Fraenkel (1922) repaired the foundation with \emph{axiomatic set theory}: a short list of basic rules (\emph{axioms}), accepted without proof, that say exactly which sets exist. The standard list today is called ZFC (Zermelo--Fraenkel set theory with the Axiom of Choice; the Axiom of Choice is one extra rule that we will not need here). Under ZFC, a condition alone does not create a set. A condition $P(x)$ may only pick out elements from an \emph{already existing} set $A$, giving the set $\{x \in A : P(x)\}$ of elements of $A$ that satisfy $P$. This rule is called \emph{Restricted Comprehension}, and it blocks Russell's construction. Most of mathematics today is built on ZFC.
\end{historybox}

\subsection{Describing sets: roster, rule, and the empty set}

How do we write down a set? There are two main ways:

\begin{enumerate}
\item \textbf{Roster notation (listing elements)}: When a set is small or has an obvious finite pattern, we list its members between curly braces:
\[
A = \{2, \, 4, \, 6, \, 8\}.
\]
In roster notation, two rules hold:
\begin{itemize}
\item \emph{Order does not matter}: $\{1, 2\} = \{2, 1\}$. A set is an unordered container, like a bag of marbles.
\item \emph{Repetition is ignored}: $\{1, 2, 2, 3\} = \{1, 2, 3\}$. An element is either in the container or it is not; you cannot put an element into a set ``twice.''
\end{itemize}

\item \textbf{Set-builder notation (filtering by a rule)}: When a set is large or infinite, listing elements becomes impossible. Instead, we define the set by stating a membership condition that acts as a sieve:
\[
S = \{x \in U : P(x)\}.
\]
Read aloud, this means the set of all elements $x$ in $U$ such that condition $P(x)$ holds. Here $U$ is the \emph{universe}: the larger set we are choosing elements from (the domain of discourse of Chapter~2). The colon ``$:$'' (or vertical bar ``$\mid$'') stands for ``such that.'' For instance, consider the set
\[
E = \{n \in \Z : n \ge 0 \text{ and } 2 \mid n\}.
\]
This condition filters the integers $\Z$ (using $2 \mid n$, ``$2$ divides $n$,'' from Chapter~6) to produce the non-negative even integers $\{0, 2, 4, 6, \dots\}$. Figure~\ref{10:fig-setbuilder-sieve} shows the filter at work on a stretch of the integers.
\end{enumerate}

What happens when our filter catches nothing at all? For example, consider the set of all real numbers whose square is negative: $\{x \in \R : x^2 < 0\}$. No real number satisfies this condition. The result is the \textbf{empty set}, denoted $\emptyset$ or $\{\}$.

The empty set is a legitimate, well-defined mathematical object rather than an error. Think of an empty cardboard box. The box exists; it contains zero items.

An important property of the empty set is that:
\[
\emptyset \subseteq A \quad \text{for every set } A.
\]
Why? Recall the definition of subset from Chapter~7 (restated in the next section): $\emptyset \subseteq A$ means
\[
\forall x, \, (x \in \emptyset \implies x \in A).
\]
Because the premise $x \in \emptyset$ is always false (the empty set contains no elements), the conditional statement is \emph{vacuously true} (a principle we explored in Chapters~5 and~7). To disprove $\emptyset \subseteq A$, you would have to find a counterexample---an element belonging to $\emptyset$ that fails to belong to $A$. Since $\emptyset$ has no elements, no such counterexample can ever exist.

\subsection{Element versus subset}

A common early mistake in set theory is to confuse \textbf{membership} ($\in$) with \textbf{containment} ($\subseteq$).

\begin{itemize}
\item \textbf{Membership ($x \in A$)}: A relation between an individual object and a container. $x$ is one of the items sitting directly inside the box $A$.
\item \textbf{Subset ($A \subseteq B$)}: A relation between two containers. $A \subseteq B$ means that \emph{every} element of $A$ is also an element of $B$:
\[
A \subseteq B \iff \forall x, \, (x \in A \implies x \in B).
\]
\end{itemize}

To see the distinction concretely, consider the set:
\[
S = \bigl\{1, \, 2, \, \{3, 4\}\bigr\}.
\]
The set $S$ has exactly \emph{three} elements: the number $1$, the number $2$, and the package $\{3, 4\}$.
\begin{itemize}
\item $1 \in S$ is \textbf{True} ($1$ is an element of $S$).
\item $\{1\} \subseteq S$ is \textbf{True} (because its only element, $1$, belongs to $S$).
\item $\{1\} \in S$ is \textbf{False} (the number $1$ is inside $S$, but the \emph{singleton} $\{1\}$, a set with exactly one element, is not).
\item $\{3, 4\} \in S$ is \textbf{True} (the package $\{3, 4\}$ is an element of $S$).
\item $\{3, 4\} \subseteq S$ is \textbf{False} (because $3 \notin S$ and $4 \notin S$; the numbers $3$ and $4$ are elements of the inner set, not of $S$).
\item $\bigl\{\{3, 4\}\bigr\} \subseteq S$ is \textbf{True} (a set whose sole element is the package $\{3, 4\}$).
\end{itemize}

Think of a box containing an apple, an orange, and a sealed envelope with two photographs inside. The apple is an element of the box. The envelope is an element of the box. But the photographs are \emph{not} elements of the outer box; they are elements of the envelope. Figure~\ref{10:fig-element-vs-subset} draws $S$ the same way, with $\{3, 4\}$ as the envelope.

\begin{trapbox}
A frequent beginner trap is confusing the empty set $\emptyset$ with the singleton set $\{\emptyset\}$. Think of $\emptyset$ as an empty cardboard box. The set $\{\emptyset\}$ is a box that contains an empty box (Figure~\ref{10:fig-empty-boxes}). Writing $|X|$ for the number of elements of a finite set $X$, the box $\emptyset$ contains zero items ($|\emptyset| = 0$), whereas $\{\emptyset\}$ contains one item ($|\{\emptyset\}| = 1$), namely the empty box. Therefore, $\emptyset \in \{\emptyset\}$ is true, but $\emptyset \in \emptyset$ is false.
\end{trapbox}

\subsection{The power set: all possible sub-collections}

Once we have a set $A$, we can ask: what are all the different sub-collections we can form from its elements?

\begin{definition}
For any set $A$, the \emph{power set} of $A$, denoted $\pow(A)$, is the set of all subsets of $A$:
\[
\pow(A) = \{X : X \subseteq A\}.
\]
\end{definition}

The elements of $\pow(A)$ are themselves sets, one level up from the elements of $A$.

For example, let $A = \{1, 2\}$. To list all subsets of $A$, we organize them by size:
\begin{itemize}
\item Size $0$: The empty set $\emptyset$.
\item Size $1$: The singletons $\{1\}$ and $\{2\}$.
\item Size $2$: The full set $\{1, 2\}$.
\end{itemize}
Putting these subsets into a single collection gives:
\[
\pow(A) = \bigl\{\emptyset, \, \{1\}, \, \{2\}, \, \{1, 2\}\bigr\}.
\]
Here $A$ has $2$ elements, and $\pow(A)$ has $4 = 2^2$ elements. The reason is as follows.

To build any subset of a set with $n$ elements, you examine each element one by one and make a two-way choice: include this element, or leave it out. For each of the $n$ elements, there are $2$ options, and each choice can be made regardless of the others:
\[
\underbrace{2 \times 2 \times \cdots \times 2}_{n \text{ choices}} = 2^n \text{ possible subsets}.
\]
Therefore, if a finite set $A$ has $n$ elements, its power set $\pow(A)$ has exactly $2^n$ elements. Writing $|A|$ for the number of elements of a finite set $A$ (its \emph{size}), a finite set $A$ has $2^{|A|}$ subsets. For this reason many authors also write $2^A$ as an alternative notation for $\pow(A)$.

\subsection{The four basic set operations}

Given two sets $A$ and $B$, we can combine them in four basic ways, pictured in Figure~\ref{10:fig-set-operations}:

\begin{itemize}
\item \textbf{Intersection ($A \cap B$)}: Common elements. An element belongs to $A \cap B$ if and only if it belongs to \emph{both} $A$ and $B$ simultaneously:
\[
A \cap B = \{x : x \in A \land x \in B\}.
\]
If two sets share no elements ($A \cap B = \emptyset$), we say they are \textbf{disjoint}---their containers have zero overlap.

\item \textbf{Union ($A \cup B$)}: Combined elements. An element belongs to $A \cup B$ if it belongs to $A$, to $B$, or to both:
\[
A \cup B = \{x : x \in A \lor x \in B\}.
\]
In mathematics, the word ``or'' is always inclusive unless stated otherwise.

\item \textbf{Set Difference ($A \setminus B$)}: Relative complement. Elements of $A$ that do not belong to $B$:
\[
A \setminus B = \{x : x \in A \land x \notin B\}.
\]
In general $A \setminus B$ is different from $B \setminus A$; order matters. For example, $\{1, 2\} \setminus \{2, 3\} = \{1\}$, but $\{2, 3\} \setminus \{1, 2\} = \{3\}$.

\item \textbf{Symmetric Difference ($A \triangle B$)}: Elements belonging to one set or the other, but \emph{not both}:
\begin{align*}
A \triangle B &= (A \setminus B) \cup (B \setminus A) \\
&= \{x : (x \in A \land x \notin B) \lor (x \in B \land x \notin A)\}.
\end{align*}
This matches the logical connective \emph{exclusive or} (XOR), which is true when exactly one of its two inputs is true; programmers meet it as a bitwise operator.
\end{itemize}

\subsection{Cartesian products: pairs and grids}

When we want to pair elements together in a specific order, a set is not enough, because sets ignore order: $\{1, 2\} = \{2, 1\}$. So mathematics uses the \textbf{ordered pair} $(a, b)$, where order matters:
\[
(a, b) = (c, d) \iff (a = c \text{ and } b = d).
\]
In particular, $(1, 2) \neq (2, 1)$.

\begin{definition}
The \emph{Cartesian product} of two sets $A$ and $B$, denoted $A \times B$, is the set of all ordered pairs whose first coordinate comes from $A$ and second coordinate comes from $B$:
\[
A \times B = \{(a, b) : a \in A \text{ and } b \in B\}.
\]
\end{definition}

If $A = \{1, 2, 3, 4\}$ and $B = \{u, v, w\}$, the Cartesian product $A \times B$ forms a grid of $4$ columns and $3$ rows containing $|A| \times |B| = 4 \times 3 = 12$ ordered pairs, as shown in Figure~\ref{10:fig-cartesian-grid}.

Fixing the first coordinate at $2$ picks out one vertical column:
\[
\{2\} \times B = \{(2, u), \, (2, v), \, (2, w)\}.
\]
In geometry and algebra, such a slice is called the \textbf{fiber} over $2$.

To prove that two sets $S$ and $T$ are equal ($S = T$), we use the method of \textbf{double containment} (or mutual containment). By the definition of set equality, $S$ and $T$ contain the exact same elements if and only if every element of $S$ belongs to $T$ and every element of $T$ belongs to $S$:
\[
S = T \iff (S \subseteq T \text{ and } T \subseteq S).
\]

This gives a two-step proof method:
\begin{enumerate}
\item \textbf{Direction 1 (Show $S \subseteq T$)}: Let $x \in S$ be an arbitrary element. Trace $x$ through the definitions and logical properties until you deduce that $x \in T$.
\item \textbf{Direction 2 (Show $T \subseteq S$)}: Let $x \in T$ be an arbitrary element. Trace $x$ through the definitions and logical properties until you deduce that $x \in S$.
\end{enumerate}

Here is the method applied to one identity.

\begin{theorem}
For any sets $A$ and $B$, $A \cap B = A \setminus (A \setminus B)$.
\end{theorem}

First, picture what this identity says. Start with the set $A$. The set difference $A \setminus B$ is the portion of $A$ outside $B$. Removing $A \setminus B$ from $A$ leaves exactly the elements of $A$ that do belong to $B$, which is $A \cap B$.

\begin{proof}
We establish equality by proving both containments:

\textbf{Direction 1: Show $A \cap B \subseteq A \setminus (A \setminus B)$.}

Let $x \in A \cap B$ be arbitrary. By definition of intersection, $x \in A$ and $x \in B$.

Now consider the set $A \setminus B = \{y : y \in A \land y \notin B\}$. For an element to belong to $A \setminus B$, it must satisfy both $y \in A$ and $y \notin B$. Because our element satisfies $x \in B$, it fails the second condition. Therefore, $x \notin (A \setminus B)$.

We now have two facts about $x$: we know $x \in A$, and we know $x \notin (A \setminus B)$. By definition of set difference, these two facts together mean:
\[
x \in A \setminus (A \setminus B).
\]
Since $x$ was arbitrary, every element of $A \cap B$ belongs to $A \setminus (A \setminus B)$. This establishes the first inclusion.

\textbf{Direction 2: Show $A \setminus (A \setminus B) \subseteq A \cap B$.}

Let $x \in A \setminus (A \setminus B)$ be arbitrary. By definition of set difference, this assumption directly tells us:
\[
x \in A \quad \text{and} \quad x \notin (A \setminus B).
\]
Now look at the second condition: $x \notin (A \setminus B)$. Recall that membership in $A \setminus B$ means $(x \in A \land x \notin B)$. To say that $x$ does not belong to $A \setminus B$ is to negate that conjunction:
\[
\neg(x \in A \land x \notin B).
\]
By De Morgan's laws of logic (Chapter~5), the negation of an ``AND'' statement is an ``OR'' statement:
\[
x \notin A \quad \lor \quad x \in B.
\]
We already know from our first condition that $x \in A$ is true. Therefore, the first branch of the ``OR'' ($x \notin A$) contradicts $x \in A$. This leaves only the second branch:
\[
x \in B.
\]
Having demonstrated that $x \in A$ and $x \in B$, by definition of intersection we conclude that $x \in A \cap B$. This establishes the second inclusion.

Having proved both $A \cap B \subseteq A \setminus (A \setminus B)$ and $A \setminus (A \setminus B) \subseteq A \cap B$, we conclude that $A \cap B = A \setminus (A \setminus B)$.
\end{proof}

\subsection{Sets as the foundation for relations and functions}

So far, our sets have been static: they tell us which elements belong to a collection, but not how collections transform or relate to one another. In Chapter~11 (\emph{Set Proofs: Element Chasing in Detail}), we practice element-chasing proofs on standard identities, and in Chapter~12 (\emph{Functions: Structured Promises, Not Just Formulas}), we study functions, which map elements from one set to another.

\subsection{Exercises}

\paragraph{Warm-Up and Mental Checks}
\begin{enumerate}
\item Let $S = \{a, \, \{b\}, \, \emptyset\}$. For each statement below, determine whether it is True or False, and justify your answer in one sentence:
\begin{multicols}{2}
\begin{enumerate}[label=(\alph*)]
\item $\emptyset \in S$
\item $\emptyset \subseteq S$
\item $b \in S$
\item $\{b\} \in S$
\item $\{b\} \subseteq S$
\item $\{\{b\}\} \subseteq S$
\end{enumerate}
\end{multicols}

\item For each set below, determine the number of elements in its power set $\pow(X)$:
\begin{enumerate}[label=(\alph*)]
\item $X = \emptyset$
\item $X = \{1, 2, 3\}$
\item $X = \pow(\emptyset)$
\item $X = \pow\bigl(\{1\}\bigr)$
\end{enumerate}
\end{enumerate}

\paragraph{Computational Practice}
\begin{enumerate}[resume]
\item Let $A = \{1, 2, 3\}$, $B = \{3, 4\}$, and $C = \{1, 4\}$.
\begin{enumerate}[label=(\alph*)]
\item Compute $A \cup B$, $A \cap B$, $A \setminus B$, and $A \triangle B$.
\item Write down all elements of the Cartesian product $B \times C$. How many elements does it have?
\item Write down the power set $\pow(B)$. How many elements does it have?
\end{enumerate}

\item For the set $A = \{1, 2, 3\}$, determine whether each statement is True or False. Explain your reasoning:
\begin{enumerate}[label=(\alph*)]
\item $\emptyset \in \pow(A)$.
\item $\emptyset \subseteq \pow(A)$.
\item $\{\emptyset\} \subseteq \pow(A)$.
\item $\{1, 2\} \in \pow(A)$.
\item $\{1, 2\} \subseteq \pow(A)$.
\end{enumerate}
\end{enumerate}

\paragraph{Proofs via Element Chasing}
\begin{enumerate}[resume]
\item Prove via element chasing that for any sets $A, B, C$:
\[
A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C).
\]
Show both inclusions:
\begin{align*}
A \setminus (B \cup C) &\subseteq (A \setminus B) \cap (A \setminus C) \quad \text{and} \\
(A \setminus B) \cap (A \setminus C) &\subseteq A \setminus (B \cup C).
\end{align*}

\item Prove that for any two sets $A$ and $B$, $A \subseteq B \iff A \cup B = B$.
(Hint: A biconditional statement $P \iff Q$ requires two separate arguments: first assume $A \subseteq B$ and show $A \cup B = B$ via double containment; then assume $A \cup B = B$ and show $A \subseteq B$.)

\item Prove that for any sets $A, B, C$:
\[
A \cap (B \setminus C) = (A \cap B) \setminus C.
\]
\end{enumerate}

\paragraph{Deeper Thinking}
\begin{enumerate}[resume]
\item \textbf{Russell's Barber Puzzle}: In a small village, the town barber shaves all men who do not shave themselves, and only those men. 
\begin{enumerate}[label=(\alph*)]
\item Does the barber shave himself? Explain why neither a ``yes'' nor a ``no'' answer is logically consistent.
\item How does this puzzle mirror Bertrand Russell's set $R = \{x : x \notin x\}$?
\item Explain how the ZFC restriction---that new sets must be formed from an already existing set $\{x \in A : P(x)\}$---prevents this paradox from arising in modern mathematics.
\end{enumerate}
\end{enumerate}
