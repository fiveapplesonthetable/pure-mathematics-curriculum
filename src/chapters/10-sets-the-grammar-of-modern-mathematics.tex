\section{Sets: The Grammar of Modern Mathematics}
\chapterline

When testing statements about numbers, functions, and shapes, we take for granted that we have collections to hold them: the even integers, the interval $(0, 1)$, or the vertices of a cube. In modern mathematics, these collections are unified under a single concept: \textbf{sets}.

A set is a well-defined collection of distinct objects. The objects belonging to a set are called its \textbf{elements} (or members). We write:
\begin{align*}
x \in A &\quad \text{to assert that } x \text{ is an element of } A, \\
x \notin A &\quad \text{to assert that } x \text{ is not an element of } A.
\end{align*}

Sets serve as the foundation for advanced mathematics: spaces are sets of points equipped with distance or topology; groups are sets of symmetries equipped with operations; and relations are sets of ordered pairs.

\begin{historybox}
In the 1870s, the German mathematician Georg Cantor invented set theory while studying a concrete puzzle in calculus: can a complicated curve always be represented in a unique way by adding up infinite sine and cosine waves (a trigonometric series)? To track the tricky points where two representations might disagree, Cantor found himself repeatedly collecting points, taking limits of those points, and collecting the results again. He realized that to work rigorously with infinite collections, mathematics needed a language that could treat infinite collections not as vague ongoing processes, but as completed objects in their own right.

Cantor's bold step provoked fierce resistance. Prominent contemporaries viewed infinite sets as unnatural or dangerous; Leopold Kronecker argued that ``God made the integers, all else is the work of man,'' while Henri Poincar\'e warned that future generations would regard set theory as a disease from which mathematics had recovered.

At the turn of the twentieth century, Gottlob Frege sought to silence the critics by grounding all of arithmetic in set theory within his monumental \emph{Grundgesetze der Arithmetik}. Frege relied on what seemed like an obvious truth: \emph{Unrestricted Comprehension}---the belief that any mathematical condition you can describe in words automatically forms a legitimate set. But in June 1902, the British philosopher Bertrand Russell sent Frege a brief letter that shattered naive set theory. Russell asked: what happens if you consider the set $R$ of all sets that do not contain themselves?
\[
R = \{x : x \notin x\}.
\]
If $R$ is not an element of itself, it meets the entrance criteria, so it must belong to $R$. But if $R$ does belong to $R$, it fails the condition, so it cannot belong to $R$! An inescapable contradiction had appeared at the heart of logic. Frege wrote in an appendix that a scientist can hardly meet with anything more undesirable than having their foundation collapse just as the work is finished.

Mathematicians led by Ernst Zermelo (1908) and Adolf Fraenkel (1922) repaired the foundation by formulating axiomatic set theory, known today as ZFC (Zermelo-Fraenkel set theory with the Axiom of Choice). Under ZFC, arbitrary collections cannot be formed freely; one may only specify subsets from an \emph{already existing} set ($\{x \in A : P(x)\}$), preventing self-referential paradoxes and the contradictory ``set of all sets.'' Axiomatic set theory provides the foundation for modern mathematics.
\end{historybox}

\subsection{Describing sets: roster, rule, and the empty set}

How do we actually write down a set? There are two primary ways:

\begin{enumerate}
\item \textbf{Roster notation (listing elements)}: When a set is small or has an obvious finite pattern, we simply list its members between curly braces:
\[
A = \{2, \, 4, \, 6, \, 8\}.
\]
In roster notation, two rules are paramount:
\begin{itemize}
\item \emph{Order does not matter}: $\{1, 2\} = \{2, 1\}$. A set is an unordered container, like a bag of marbles.
\item \emph{Repetition is ignored}: $\{1, 2, 2, 3\} = \{1, 2, 3\}$. An element is either in the container or it is not; you cannot put an element into a set ``twice.''
\end{itemize}

\item \textbf{Set-builder notation (filtering by a rule)}: When a set is large or infinite, listing elements becomes impossible. Instead, we define the set by stating a membership condition that acts as a sieve:
\[
S = \{x \in U : P(x)\},
\]
read aloud as: ``the set of all elements $x$ in the universe $U$ such that condition $P(x)$ holds.'' The colon ``$:$'' (or vertical bar ``$\mid$'') is read as ``such that.'' For instance,
\[
E = \{n \in \Z : n \ge 0 \text{ and } 2 \mid n\}
\]
filters the integers $\Z$ to produce the non-negative even integers $\{0, 2, 4, 6, \dots\}$.
\end{enumerate}

What happens when our filter catches nothing at all? For example, consider the set of all real numbers whose square is negative: $\{x \in \R : x^2 < 0\}$. No real number satisfies this condition. The result is the \textbf{empty set}, denoted $\emptyset$ or $\{\}$.

The empty set is a legitimate, well-defined mathematical object rather than an error. Think of an empty cardboard box. The box exists; it simply contains zero items.

An important property of the empty set is that:
\[
\emptyset \subseteq A \quad \text{for every set } A.
\]
Why? Recall the definition of subset: $\emptyset \subseteq A$ means $\forall x, (x \in \emptyset \implies x \in A)$. Because the premise $x \in \emptyset$ is always false (the empty set contains no elements), the conditional statement is \emph{vacuously true} (a principle we explored in Chapters~4 and~7). To disprove $\emptyset \subseteq A$, you would have to find a counterexample---an element belonging to $\emptyset$ that fails to belong to $A$. Since $\emptyset$ has no elements, no such counterexample can ever exist!

\subsection{The vital distinction: element versus subset}

The single most common source of early confusion in set theory is conflating \textbf{membership} ($\in$) with \textbf{containment} ($\subseteq$).

\begin{itemize}
\item \textbf{Membership ($x \in A$)}: A relation between an individual object and a container. $x$ is one of the items sitting directly inside the box $A$.
\item \textbf{Subset ($A \subseteq B$)}: A relation between two containers. $A \subseteq B$ means that \emph{every} element of $A$ is also an element of $B$:
\[
A \subseteq B \iff \forall x, \, (x \in A \implies x \in B).
\]
\end{itemize}

To see the distinction concretely, consider the set:
\[
S = \bigl\{1, \, 2, \, \{3, 4\}\bigr\}.
\]
Notice that $S$ contains exactly \emph{three} elements: the number $1$, the number $2$, and the package $\{3, 4\}$.
\begin{itemize}
\item $1 \in S$ is \textbf{True} ($1$ is an element of $S$).
\item $\{1\} \subseteq S$ is \textbf{True} (because its only element, $1$, belongs to $S$).
\item $\{1\} \in S$ is \textbf{False} (the number $1$ is inside $S$, but the singleton set $\{1\}$ is not).
\item $\{3, 4\} \in S$ is \textbf{True} (the package $\{3, 4\}$ is an element of $S$).
\item $\{3, 4\} \subseteq S$ is \textbf{False} (because $3 \notin S$ and $4 \notin S$; the numbers $3$ and $4$ are elements of the inner set, not of $S$).
\item $\bigl\{\{3, 4\}\bigr\} \subseteq S$ is \textbf{True} (a set whose sole element is the package $\{3, 4\}$).
\end{itemize}

Think of a box containing an apple, an orange, and a sealed envelope with two photographs inside. The apple is an element of the box. The envelope is an element of the box. But the photographs are \emph{not} elements of the outer box; they are elements of the envelope!

\begin{trapbox}
A frequent beginner trap is confusing the empty set $\emptyset$ with the singleton set $\{\emptyset\}$. Think of $\emptyset$ as an empty cardboard box. The set $\{\emptyset\}$ is a box that contains an empty box! The box $\emptyset$ contains zero items ($|\emptyset| = 0$), whereas $\{\emptyset\}$ contains one item ($|\{\emptyset\}| = 1$), namely the empty box. Therefore, $\emptyset \in \{\emptyset\}$ is true, but $\emptyset \in \emptyset$ is false.
\end{trapbox}

\subsection{The power set: all possible sub-collections}

Once we have a set $A$, we can ask: what are all the different sub-collections we can form from its elements?

\begin{definition}
For any set $A$, the \emph{power set} of $A$, denoted $\pow(A)$, is the set of all subsets of $A$:
\[
\pow(A) = \{X : X \subseteq A\}.
\]
\end{definition}

Notice the level-shift here: the elements of $\pow(A)$ are themselves sets!

Let us construct a power set concretely. Let $A = \{1, 2\}$. To list all subsets of $A$, we organize them by size:
\begin{itemize}
\item Size $0$: The empty set $\emptyset$.
\item Size $1$: The singletons $\{1\}$ and $\{2\}$.
\item Size $2$: The full set $\{1, 2\}$.
\end{itemize}
Putting these subsets into a single collection gives:
\[
\pow(A) = \bigl\{\emptyset, \, \{1\}, \, \{2\}, \, \{1, 2\}\bigr\}.
\]
Notice that $A$ has $2$ elements, and $\pow(A)$ has $4 = 2^2$ elements. This is no accident. 

To build any subset of a set with $n$ elements, you examine each element one by one and make a binary choice: do you include this element, or do you leave it out? For each of the $n$ elements, there are $2$ independent options:
\[
\underbrace{2 \times 2 \times \cdots \times 2}_{n \text{ choices}} = 2^n \text{ possible subsets}.
\]
Therefore, if a finite set $A$ has $n$ elements, its power set $\pow(A)$ has exactly $2^n$ elements. The notation $\pow(A)$ reflects this exponential size $2^{|A|}$.

\begin{recoverybox}
\textbf{Pause and think}: What is the power set of the empty set, $\pow(\emptyset)$?
Since $\emptyset$ has $0$ elements, its power set must have $2^0 = 1$ element. What is that single element? The only subset of $\emptyset$ is $\emptyset$ itself! Therefore,
\[
\pow(\emptyset) = \{\emptyset\}.
\]
Notice how our cardboard box intuition holds: the collection of all subsets of an empty box is a box containing an empty box!
\end{recoverybox}

\subsection{The four fundamental set operations}

Given two sets $A$ and $B$ living inside a universal set $U$, we can combine and filter them using four fundamental Boolean operations, pictured in Figure~\ref{10:fig-set-operations}:

\begin{itemize}
\item \textbf{Intersection ($A \cap B$)}: Common elements. An element belongs to $A \cap B$ if and only if it belongs to \emph{both} $A$ and $B$ simultaneously:
\[
A \cap B = \{x : x \in A \land x \in B\}.
\]
If two sets share no elements ($A \cap B = \emptyset$), we say they are \textbf{disjoint}---their containers have zero overlap.

\item \textbf{Union ($A \cup B$)}: Combined elements. An element belongs to $A \cup B$ if it belongs to $A$, to $B$, or to both:
\[
A \cup B = \{x : x \in A \lor x \in B\}.
\]
In mathematics, the word ``or'' is always inclusive unless stated otherwise.

\item \textbf{Set Difference ($A \setminus B$)}: Relative complement. Elements of $A$ that do not belong to $B$:
\[
A \setminus B = \{x : x \in A \land x \notin B\}.
\]
Notice that $A \setminus B$ is generally different from $B \setminus A$; order matters.

\item \textbf{Symmetric Difference ($A \triangle B$)}: Elements belonging to one set or the other, but \emph{not both}:
\[
A \triangle B = (A \setminus B) \cup (B \setminus A) = \{x : (x \in A \land x \notin B) \lor (x \in B \land x \notin A)\}.
\]
This corresponds precisely to the exclusive-OR (XOR) operation in logic and computer engineering.
\end{itemize}

\subsection{Cartesian products: building multidimensional worlds}

When we want to pair elements together in a specific sequence, simple set membership alone is insufficient because sets are unordered: $\{1, 2\} = \{2, 1\}$. To introduce order and direction, mathematics defines the \textbf{ordered pair} $(a, b)$, where order matters:
\[
(a, b) = (c, d) \iff (a = c \text{ and } b = d).
\]
In particular, $(1, 2) \neq (2, 1)$.

\begin{definition}
The \emph{Cartesian product} of two sets $A$ and $B$, denoted $A \times B$, is the set of all ordered pairs whose first coordinate comes from $A$ and second coordinate comes from $B$:
\[
A \times B = \{(a, b) : a \in A \text{ and } b \in B\}.
\]
\end{definition}

If $A = \{1, 2, 3, 4\}$ and $B = \{u, v, w\}$, the Cartesian product $A \times B$ forms a discrete $4 \times 3$ coordinate grid containing $|A| \times |B| = 4 \times 3 = 12$ ordered pairs, as illustrated in Figure~\ref{10:fig-cartesian-grid}.

Notice how fixing the first coordinate at $2$ isolates a vertical column:
\[
\{2\} \times B = \{(2, u), \, (2, v), \, (2, w)\}.
\]
In geometry and algebra, such a slice is called the \textbf{fiber} over $2$: fixing the first coordinate at $2$ isolates all pairs whose first component is $2$.

\subsection{Proving set equality: double containment}

How do you prove that two set expressions describe the exact same set, such as $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$?

Why can you not simply sketch a Venn diagram with overlapping circles and declare the claim obvious? A Venn diagram is an invaluable aid for your own mental model, but it has severe limitations: three circles do not capture all configurations or edge cases (such as when sets are empty or infinite), and drawing overlapping circles cannot scale to ten sets or infinite families. A diagram is a helpful guide for seeing why an identity ought to hold, but a proof must track an arbitrary element step by step through the definitions.

To prove that two sets $S$ and $T$ are identical ($S = T$), we use the method of \textbf{double containment} (or mutual containment). By the definition of set equality, $S$ and $T$ contain the exact same elements if and only if every element of $S$ belongs to $T$ and every element of $T$ belongs to $S$:
\[
S = T \iff (S \subseteq T \text{ and } T \subseteq S).
\]

This gives a two-step proof method:
\begin{enumerate}
\item \textbf{Direction 1 (Show $S \subseteq T$)}: Let $x \in S$ be an arbitrary element. Trace $x$ through the definitions and logical properties until you deduce that $x \in T$.
\item \textbf{Direction 2 (Show $T \subseteq S$)}: Let $x \in T$ be an arbitrary element. Trace $x$ through the definitions and logical properties until you deduce that $x \in S$.
\end{enumerate}

Let us see this protocol in action on a concrete structural identity.

\begin{theorem}
For any sets $A$ and $B$, $A \cap B = A \setminus (A \setminus B)$.
\end{theorem}

Before touching pencil to paper, visualize what this identity says. Start with the container $A$. The set difference $A \setminus B$ is the portion of $A$ that fails to belong to $B$. Subtracting $A \setminus B$ from $A$ removes those elements of $A$ that are not in $B$, leaving precisely the elements of $A$ that do belong to $B$, which is $A \cap B$.

Figure~\ref{10:fig-carving-identity} illustrates this geometric carving: removing the outer crescent $A \setminus B$ from the full set $A$ leaves only the shared core $A \cap B$.

\begin{proof}
We establish equality by proving both containments:

\textbf{Direction 1: Show $A \cap B \subseteq A \setminus (A \setminus B)$.}

Let $x \in A \cap B$ be arbitrary. By definition of intersection, $x \in A$ and $x \in B$.

Now consider the set $A \setminus B = \{y : y \in A \land y \notin B\}$. For an element to belong to $A \setminus B$, it must satisfy both $y \in A$ and $y \notin B$. Because our element satisfies $x \in B$, it fails the second condition. Therefore, $x \notin (A \setminus B)$.

We now have two facts about $x$: we know $x \in A$, and we know $x \notin (A \setminus B)$. By definition of set difference, these two facts together mean:
\[
x \in A \setminus (A \setminus B).
\]
Since $x$ was arbitrary, every element of $A \cap B$ belongs to $A \setminus (A \setminus B)$. This establishes the first inclusion.

\textbf{Direction 2: Show $A \setminus (A \setminus B) \subseteq A \cap B$.}

Let $x \in A \setminus (A \setminus B)$ be arbitrary. By definition of set difference, this assumption directly tells us:
\[
x \in A \quad \text{and} \quad x \notin (A \setminus B).
\]
Let us examine the second condition: $x \notin (A \setminus B)$. Recall that membership in $A \setminus B$ means $(x \in A \land x \notin B)$. To say that $x$ does not belong to $A \setminus B$ is to negate that conjunction:
\[
\neg(x \in A \land x \notin B).
\]
By De Morgan's laws of logic (Chapter~5), the negation of an ``AND'' statement is an ``OR'' statement:
\[
x \notin A \quad \lor \quad x \in B.
\]
We already know from our first condition that $x \in A$ is true. Therefore, the first branch of the ``OR'' ($x \notin A$) contradicts $x \in A$. This leaves only the second branch:
\[
x \in B.
\]
Having demonstrated that $x \in A$ and $x \in B$, by definition of intersection we conclude that $x \in A \cap B$. This establishes the second inclusion.

Having proved both $A \cap B \subseteq A \setminus (A \setminus B)$ and $A \setminus (A \setminus B) \subseteq A \cap B$, we conclude that $A \cap B = A \setminus (A \setminus B)$.
\end{proof}
